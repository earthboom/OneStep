# Vegabond Image

OneStep의 생성 또는 수정 작업에서 사용하는 이미지 전문 스킬이다. Codex에서는 내장 `imagegen` 스킬의 실행 지침에 따라 래스터 이미지를 생성하고 편집한다. 매체, 구도, 연속 장면의 일관성, 타이포그래피, 파일 조건에 추가 안내가 필요하면 [스타일과 검수 예시](references/style-and-review.kr.md)를 참고한다.

## 이미지가 보여 줘야 할 것 정하기

- 원래 요청에서 필수 요구, 선호, 위임된 선택을 파악한다. 필수 요구를 이미지에서 확인할 수 있는 짧은 기준으로 적는다. 요청에 해당하는 항목만 포함한다. 문구, 수량, 속성, 위치, 배제할 요소, 파일 조건을 정확히 유지한다. 요청이 화면 기준이면 좌우를 화면 기준으로 표시한다. 대상이 여럿이면 각 대상에 재질, 색, 수량, 위치를 연결한다.
- 장면의 내용과 렌더링 매체를 각각 파악한다. 광원과 질감, 선과 형태, 붓질, 색상, 공간 규칙처럼 눈에 보이는 특징으로 스타일을 설명한다. 사용자가 결정한 표현을 따르고, 위임받은 범위에서 선택한다. 짧고 명확한 요청은 바로 생성한다. 결과가 크게 달라지는 누락이나 충돌이 있으면 한 가지를 확인한다.
- 입력 이미지마다 역할과 반영할 특징을 적는다. 편집 원본과 정체성, 배치, 포즈, 표현, 색의 참조를 구분한다. 두 참조가 겹치면 어느 참조가 그 요소를 정하는지 명시한다. 연속 이미지에는 승인된 장면이나 공통 정체성 참조를 사용하고, 각 장면을 독립된 이미지로 지시한다. 피사체 수가 중요하면 각 장면에 등장할 수를 전체 이미지 장수와 구분해 적는다.
- 편집 전에는 바꿀 부분과 보존 조건을 적고 원본 또는 마지막 합격본을 사용한다. 정확한 구도가 필수이고 배치가 모호하다면 활용할 수 있는 스케치나 레이아웃 참조를 쓴다.

## 생성하고 결과 검사하기

1. 검수 기준을 시각적 지시로 옮긴다. 복잡한 장면은 장면과 구도, 대상과 속성의 관계, 표현 방식, 출력 조건으로 짧게 정리한다. 수량을 확인해야 하는 요소는 각각 보이게 한다. 시점이 정확해야 하면 카메라가 피사체나 표면을 바라보는 방향과 화면에 드러날 형태나 면을 함께 지정한다. 간단한 요청은 자연스러운 문장으로 작성한다. 정확한 문구의 위치와 줄바꿈을 명시한다. 표현 방향이 열려 있고 선택이 도움이 될 때만 차이가 분명한 후보를 만든다.
2. 실제 이미지를 원래의 기준과 대조한다. 각 항목을 충족, 실패, 미확인으로 판정한다. 수량, 속성 연결, 배치, 시점의 단서를 각각 확인한다. 장면 안의 피사체 수가 제한되어 있으면 전경과 배경을 모두 살핀 뒤 연속 이미지 사이의 정체성을 비교한다. 문구는 읽을 수 있을 정도로 확대한다. 편집본은 원본과 나란히 놓아 변경과 보존을 확인한다. 연속 이미지에서는 공통 참조와 앞뒤 장면에 비춰 정체성을 확인한다. 미적 완성도와 필수 요건을 각각 판단한다.
3. 요청에 따라 실제 파일의 형식, 픽셀 크기, 비율, 알파 투명도를 검사한다. 정확한 픽셀 크기를 바로 출력할 수 없으면 여백을 확보하고 캔버스 크기 또는 자르기를 조정한다. 조정 뒤 배치, 세부 정보, 투명도를 다시 검사한다. 정확한 문구가 중요하고 결과물 형식에 맞으면 글자 자리를 남기고 원문을 별도 레이어에 배치한다. 요청 형식으로 내보낸 뒤 최종 결과를 검수한다.
4. 관찰된 실패를 해결하는 데 필요한 범위만 수정한다. 일부 결함은 해당 요소를 고친 뒤 이미 통과한 항목을 다시 본다. 배치가 틀리면 구도 지시나 참조를 바꾼다. 편집 과정에서 요소가 달라지면 마지막 합격본으로 돌아가 보존 대상을 다시 명시한다. 같은 방법에서 중요한 실패가 반복되면 산출물에 맞는 제어 방식이나 배치 방법을 택한다. 남은 실패 또는 미확인 조건과 사용할 수 있는 결과물의 위치를 알린다.

그림의 의미, 채색 방식이나 핍진성이 중요한 요청에는 [시각적 의도를 정하고 읽어 보는 방법](references/style-and-review.kr.md#시각적-의도를-정하고-읽어-보는-방법)을 적용한다. 요청을 전달하는 단서 몇 개를 고르고, 사용자가 지정하지 않은 연출은 조정할 수 있도록 둔다.

표현 의도가 중요한 그림은 완성본만 보고 무엇이 전달되는지 먼저 서술한 뒤 원래 요청과 대조한다. 화면에서 근거를 짚고, 의미를 바꿀 만큼 설득력 있는 다른 해석도 기록한다. 장면에 모순이 있거나 요청한 효과가 빠졌을 때 해당 부분을 고친다. 다른 방식으로도 의도가 충분히 전달되면 그대로 채택할 수 있다.

유색 조명을 받는 큰 물체 위에서 작은 강조 요소가 먼저 보여야 한다면, 생성본과 채색 수정본을 채택하기 전에 [고유색과 첫 시선](references/style-and-review.kr.md#고유색과-첫-시선)을 함께 확인한다.

사람의 자세, 접촉, 표정 또는 피부가 중심인 그림은 [사람 그리기](references/drawing-people.kr.md)를 참고해 해당 순간을 연출하고 요청한 화풍에서 인물이 자연스러운지 검수한다.
