# Explore distinct visual ideas

Use this for an open brief that benefits from interpreting the idea in different ways, or when earlier images repeat the same solution. Direct generation and a narrow edit follow their ordinary workflow. For one image, consider a few short alternatives internally when useful, then generate the selected direction. Use a set of roughs when the user needs to compare options.

## Choose what can change

1. Write what the viewer should understand and what must stay fixed. Preserve required entities, identity, wording, medium or layout as applicable. Mark the choices the user delegated. Record one visible cue that would make each important relationship or message legible.
2. Match the change to the request. For different visual treatments of the same concept, keep the event and subjects fixed and vary the medium, lighting or mark-making. For different ideas, pick a meaningful axis such as the event shown, the evidence it leaves behind, the viewer's position, or a rule that visibly changes how the world works. State what the viewer can actually see in each version.
3. Draft two or three independent directions before committing to a polished first image. Keep each direction's key cue in its prompt. Use separate prompts for independent candidates. If camera or geometry keeps repeating, use a separate thumbnail, silhouette or layout reference that makes the intended difference visible. An identity reference can still control the same character across those directions.

## Compare the idea and its legibility

Look at each rough without its explanation. Name what happens, what leads the eye, and which cue supports the intended reading. Group candidates by their visible event or mechanism when judging concept variety. Compare the chosen axis when judging rendering variants. Then check the brief and the target viewing conditions. Assess novelty and suitability independently.

If an unusual direction loses the core message, strengthen the smallest cue that connects it to the brief. Preserve the staging or device that made the direction valuable. For example, a book that opens onto a life-size hallway can read as a magic portal. Repeat the same distinctive bracelet on the adult reader and on a child's hand inside the hallway to connect the place to the reader's past. Inspect whether viewers can see both marks, read the intended association, and still recognize how the book and hallway connect.

Choose from directions that preserve the important conditions. Carry the accepted composition and the cue that makes it work into the next edit. For an open brief with several good treatments, retain the distinctions the user wanted when presenting the options.
