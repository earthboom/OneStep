# 문구·스티커용 캐릭터

## 캐릭터와 쓰임을 정한다

결과물과 실제로 보게 될 조건을 파악한다. 마스코트 한 장, 개별 누끼 이미지 세트, 배치를 마친 스티커 시트는 확인할 항목이 다르다. 실물 치수가 주어지면 그림, 개별 재단 모양, 상품 전체 중 어느 것의 크기인지 파악한다. 디테일은 실제 인쇄 크기나 화면 표시 크기로 평가한다. 한 장의 제작 조건이 분명하면 바로 생성할 수 있다.

- “치이카와 같은 느낌의 새 마스코트”라면 아담한 윤곽, 간결한 얼굴 표시, 한눈에 읽히는 일상의 반응처럼 그릴 수 있는 특징으로 풀어 쓴다. 오리지널 마스코트의 몸체, 식별 특징, 행동은 고유하게 정한다. 결과가 참조 캐릭터와 지나치게 비슷하면 실루엣이나 얼굴과 표시의 배치를 다시 잡는다. 기존 캐릭터를 직접 그려 달라는 요청에는 제공됐거나 합의한 디자인을 외형 참조로 쓴다.
- 축소해도 남는 특징을 고른다. 장식을 더하기 전에 외곽선, 얼굴 배치, 넓은 색면, 눈에 띄는 비대칭 표시를 확인한다. 단색 실루엣으로 보았을 때 소품이 몸과 붙어 보이는지도 알 수 있다. 떨어뜨린 도서관 카드를 정성스럽게 펴는 행동처럼 평범한 상황에서 캐릭터의 성격을 드러낸다.
- 시리즈는 특징이 잘 보이는 중립 자세 한 장이나 제공된 디자인을 외형 기준으로 삼는다. 세트에 필요한 각도가 있을 때 다른 시점을 추가한다. 고정할 특징과 입, 시선, 자세, 장면의 소품처럼 바꿀 수 있는 특징을 적는다. 비대칭 요소의 좌우는 캐릭터 기준과 화면 기준 중 어느 쪽인지 명시한다.

## 변형을 만들고 검수한다

1. 그림마다 주요 반응이나 동작 하나를 정하고, 얼굴이나 몸짓에서 이를 알아볼 수 있게 한다. 얼굴이 간결한 캐릭터는 어깨를 내리고 눈매를 부드럽게 해 안도감을, 얼굴을 돌리고 손을 몸 가까이 모아 민망함을 표현할 수 있다. 어려운 포즈는 제공된 스케치를 따로 쓴다. 외형과 포즈, 배치를 각각 어느 그림에서 가져오는지 생성기에 명시한다.
2. 개별 스티커나 인쇄용 스티커 시트처럼 변형을 나눠 만들고 정확히 배치해야 하는 결과물은 공통 참조에서 각 변형을 만들거나 편집하고, 채택한 그림을 필요에 맞게 배치한다. 세트가 함께 놓였을 때의 인상을 탐색하는 데는 한 번에 생성한 시트도 쓸 수 있다. 한 부분에 문제가 생기면 해당 변형의 마지막 채택본에서 그 부분을 고치고 식별 특징과 주변 윤곽을 다시 확인한다.
3. 세트를 한눈에 보고, 개별 그림은 사용 크기에서 확인한다. 식별 특징을 디자인 참조와 대조하고 자세나 동작이 한눈에 어떻게 읽히는지 본다. 표정 세트에는 아래 검수 절차를 적용한다.

사용자가 시리즈를 이어 갈 작업이라면 채택한 중립 자세와 필요한 각도, 유지할 색과 형태, 비대칭 표시의 방향을 모델 시트에 담고 버전을 남긴다. 후속 제작에 필요한 경우 편집 가능한 원본도 보관한다.

평면적인 마스코트의 같은 시점에서 여러 반응을 제작하고 편집 원본을 쓸 수 있다면, 몸체와 식별 표시 레이어를 공유하고 얼굴, 팔다리, 소품을 바꾼다. 자세가 읽히고 바뀐 부분이 자연스럽게 이어지거나 겹치는지 본다. 새 시점이나 큰 포즈 변화가 필요하면 스케치로 실루엣과 보이는 면을 잡고, 참조 편집을 하거나 해당 시점의 레이어 원본을 따로 만든다. 시점 변경 뒤 식별 특징의 위치를 중립 자세와 대조한다.

## 작게 쓰는 표정 세트를 검수한다

1. **작업 크기에서 캐릭터 일관성을 확인한다.** 각 시안을 승인된 참조 옆에 놓고 머리와 몸의 기본 비율, 얼굴 배치, 알아보는 데 쓰이는 형태와 색면, 무늬를 비교한다. 의도한 자세와 표정 변화는 허용한다. 예를 들어 날개를 들어 윤곽이 바뀌는 것은 허용되며, 식별 특징인 가슴 무늬가 사라지면 수정이 필요하다.
2. **사용 크기에서 나란히 비교한다.** 시안들을 같은 축척으로 놓고, 배치나 바탕이 정해져 있다면 실제 사용 조건을 적용한다. 목표 크기가 정해지지 않았다면 화면 비교 크기와 그보다 작은 시험 크기를 정해 보고한다. 같은 크기의 축소판을 만들 때는 그림이 실제로 보이는 영역의 긴 변을 맞춰 투명 여백 차이를 보정한다. 100% 배율로 보고, 밝고 어두운 바탕에 모두 쓰일 수 있는 투명 이미지는 두 바탕에서 확인한다.
3. **표정 간 구분과 감정 전달을 각각 판정한다.** 감정 이름을 가린 채 각 그림이 처음 어떤 감정으로 읽히는지와 그 단서를 기록한다. 가장 작은 크기에서 서로 비슷한 표정이 구분되는지, 각 표정이 의도한 감정을 전달하는지 확인한다. 검사한 크기, 그 크기에서 남거나 사라지는 단서, 함께 떠오르는 다른 해석을 기록한다. 의도가 흐린 표정을 수정할 때는 얼굴이나 자세에서 눈에 잘 띄는 단서 하나를 분명하게 한 뒤, 캐릭터 일관성을 점검하고 가장 비슷한 표정과 같은 크기에서 다시 비교한다.

아기 도요새 화면 시험에서 48px로 줄여도 들어 올린 날개와 크게 벌린 부리에서 기쁨이 읽혔다. 크게 뜬 눈과 볼에 댄 날개는 움찔한 반응으로 보였다. 감은 눈과 내린 날개 덕분에 세 번째 자세는 구분됐고 첫인상은 편안함이었다. 안도는 113px에서 더 분명했다. 화면에서 확인한 결과는 화면 확인으로 기록한다. 인쇄물에서의 판독성은 실제 사용할 크기의 교정본에서 확인한다.

## 매체에 맞게 마무리한다

| 결과물 | 전달 전에 확인할 것 |
| --- | --- |
| 단일 누끼 또는 디지털 스티커 세트 | 투명 배경을 요청받았다면 내보낸 파일을 열어 실제 투명도를 확인한다. 밝고 어두운 바탕에서 테두리 잔색, 떨어져 나온 픽셀, 내부 표시 소실, 잘림을 본다. 해당하는 경우 픽셀 크기, 글자 가독성, 파일 용량을 대상 플랫폼 기준에 맞춰 확인한다. 마켓 제출용은 최신 제출 안내를 확인한다. |
| 인쇄 스티커 또는 스티커 시트 | 공급받은 인쇄소 템플릿에서 실물 치수, 유효 해상도, 색상 프로파일, 도련, 안전 여백과 간격을 확인한다. 정확한 배치와 필요한 칼선은 레이아웃 도구에서 만든다. 템플릿에 명시된 경우 칼선 경로가 닫혀 있는지 본다. 칼선과 그림의 테두리를 비교하고 실물 크기 교정본을 확인한다. 인쇄 적합 여부를 확인할 수 없었다면 배치 시안으로 표시한다. |
| 메모지 또는 노트 | 필기나 제목에 필요한 공간을 구성에서 확보한다. 필기 면은 실물 크기 미리보기에 대표 손글씨를 넣어 들어가는지, 충분히 읽히는지 본다. 표지는 제공된 템플릿의 재단·제본 여백을 확인한다. |
| 반복 무늬 또는 마스킹 테이프 | 경계가 맞아야 한다면 레이아웃 도구에서 반복 타일을 조립한다. 실제 테이프 너비에 연달아 놓고 연결부, 모티프의 방향과 간격을 살핀다. |

**예시.** 오리지널 북카트 마스코트 스티커 세트는 중립 자세를 기준으로 가로로 넓은 민트색 몸체, 보이는 짙은 회색 바퀴 두 개, 캐릭터 기준 왼쪽의 산호색 책갈피 탭을 유지한다. ‘책을 꽂은 뒤 안도’에는 편안한 눈매와 카트 턱에 얹은 손을 쓴다. ‘카드를 떨어뜨린 뒤 민망함’과 첫인상이 어떻게 다른지 비교한다. 인쇄 시트에서는 각 스티커를 주문한 재단 크기로 본다. 메모지 버전은 필기 면 주위에 마스코트를 배치하고 손글씨 한 줄을 올려 본다.
