# Stationery and sticker characters

## Define the character and its use

Identify the deliverable and actual viewing conditions. A single mascot drawing, a set of individual cutouts, and a laid-out sticker sheet need different checks. When a physical size is given, establish whether it describes the artwork, individual cut shape or whole product. Use the intended print size or screen size when evaluating details. A single image can go straight to generation once its brief is clear.

- For a brief such as “a new mascot with a Chiikawa-like feel,” turn the reference into drawable qualities such as a compact contour, sparse facial marks and readable everyday reactions. Give the original mascot its own body shape, identifying features and behavior. If the result strongly resembles the reference character, revisit the silhouette or feature placement. If the request names an existing character as the subject, use the supplied or agreed design reference for identity.
- Choose a few features that survive reduction. Check the contour, face placement, a large color block, or one clear asymmetrical feature before adding decoration. A flat silhouette preview can show where a prop merges with the body. Express personality through what the character does in an ordinary situation, such as carefully patting a dropped library card flat.
- For a series, use one clear neutral image or the supplied design as the identity reference. Add another view only when it resolves an angle the series needs. Record the features that stay consistent and what may change, such as the mouth, gaze, posture or scene props. Specify anatomical or screen-relative sides for asymmetric features.

## Produce and review variations

1. Give each image one primary reaction or action, with a visible cue in the face or gesture. For a sparse face, relief can read through lowered shoulders and soft eyes, while embarrassment can read through a turned face and tucked hands. Use a separate sketch for a difficult pose when available. Tell the generator which reference provides identity and which provides pose or layout.
2. For a deliverable that needs separate, precisely placed variants, such as individual stickers or an assembled print sheet, generate or edit each variant from the shared reference and lay out the accepted images as needed. Use a generated sheet for exploration when it helps reveal how the set reads together. For a local defect, edit the affected variant from its last accepted image and recheck its identifying features and nearby edges.
3. Review the set together and each image at its intended size. Compare the silhouette, face placement, color blocks and mark placement against the design reference. Before reading a caption, name the first reading of the expression or action and the cue that supports it. If the intended reading is weak, clarify the gesture or spacing before adding fine detail. Check differences between similar reactions in the set.

For a series the user will extend, keep a versioned model sheet with the accepted neutral view, needed angles, stable color and shape cues, and the side of any asymmetric mark. Keep the editable artwork if later production needs it.

When a flat mascot has several reactions from the same view and editable artwork is available, use shared layers for the body and marks and change the face, limbs or props. Review whether the pose still reads and whether the changed parts connect or overlap naturally. For a new view or a large pose change, establish the new silhouette and visible surfaces with a sketch, then use reference editing or create a separate layered master for that view. Compare the landmark placement with the neutral reference after the turn.

## Finish for the requested medium

| Deliverable | Inspect before handoff |
| --- | --- |
| Single cutout or digital sticker set | Decode the exported file to verify real transparency if requested. Preview on light and dark backgrounds for halos, detached pixels, lost interior marks and clipping. Check dimensions, legible wording and file limits against the intended platform when applicable. Consult the current submission guidance for a requested marketplace deliverable. |
| Printed sticker or sticker sheet | Follow the supplied printer template for dimensions, effective resolution, color profile, bleed, safety margins and spacing. Build exact spacing and required cut paths in a layout tool. Check closed contours where the template requires them. Compare the cut path with the printed outline and inspect a proof at physical size. Label a layout as a mockup if print readiness could not be verified. |
| Memo pad or notebook | Reserve the requested writing or title area in the composition. Place a representative handwriting sample on a preview at physical size to check fit and contrast for a writable surface. For a cover, check trim and binding clearances with the template when available. |
| Pattern or washi tape | Assemble the repeat tile in a layout tool when seams must align. Preview consecutive repeats at the intended tape width and inspect joins, motif direction and gaps. |

**Example.** For an original book cart mascot sticker set, use the neutral design to preserve the wide mint body, two visible charcoal wheels and coral bookmark tab on the character’s left. For “relief after shelving a book,” relax the eyes and rest the hands on the cart ledge. Compare its first reading with “embarrassment after dropping a card.” On a print sheet, preview each sticker at the ordered cut size. In a memo version, place the mascot around the writing area and try a short handwritten note over the proposed layout.
