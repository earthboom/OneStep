# 2D 게임 캐릭터 아트

## 플레이어가 보는 화면 선택

| 요청 자산 | 생성의 기준 | 완료 판단 |
| --- | --- | --- |
| 대화 초상화·캐릭터 일러스트 | 캐릭터 디자인, 감정이나 서사적 순간, 잘리는 범위와 초점. 대화 UI가 있으면 실제 슬롯과 텍스트 영역을 사용한다. | 최종 구도에서 의도한 태도가 읽힌다. UI를 겹친 뒤에도 시선과 얼굴, 인물 식별 특징이 보인다. |
| 인게임 캐릭터 이미지 | 게임 카메라, 향하는 방향, 화면에 표시되는 키, 주변 배경, 기존 화풍. 중립 자세나 대표 동작 한 개에서 시작한다. | 밝고 어두운 대표 배경 위에서 실제 플레이 크기로 인물·방향·동작을 알아볼 수 있고 자세 전체가 지정 영역에 들어간다. |
| 애니메이션 프레임·스프라이트 시트 | 채택한 인게임 포즈와 동작·시점·기준점·타이밍·내보내기 배치. | 임포트하거나 시트를 잘라 낸 프레임이 의도한 순서와 속도로 재생된다. 움직이는 동안 인물의 동일성, 전환, 접지, 정렬이 유지된다. |

일러스트 한 장을 의뢰받으면 그 용도의 검수에서 마친다. 같은 캐릭터로 여러 자산을 만들 때는 중요한 특징이 드러난 디자인을 기준으로 삼는다. 크기가 변해도 남길 특징 몇 가지를 적는다. 후드의 패인 모서리, 호박색 목도리, 캐릭터 본인의 왼손에 든 등불이 한 예다. 작은 화면에서 생략할 세부를 정하고 다른 참고 이미지에는 카메라·포즈·팔레트처럼 개별 역할을 준다. 결과물에 드러날 모호함이 있을 때 추가 시점을 확보한다.

## 일러스트와 인게임 자세 제작

- **일러스트.** 보는 사람이 읽을 수 있는 연기 순간을 잡는다. 시선·몸짓·주요 소품의 관계를 지정해 디자인 기준에서 생성하거나 편집한다. 최종 크롭에서 얼굴과 복식을 살핀다. 표정 세트는 채택한 중립 초상화를 편집하고 요청한 표정과 눈매·나이 인상·의상도 비교한다.
- **인게임.** 디자인 기준을 게임 카메라에서 다시 그린다. 외곽선과 큰 명암 덩어리로 형태를 정리한다. 장식을 더하기 전에 대표 배경 위에서 실제 크기로 본다. 픽셀 아트는 정한 논리 해상도의 격자에서 튀는 픽셀과 프레임 간 팔레트를 확인한다. 채색·펜화 스프라이트는 목표 크기에서 선 굵기와 의도한 반투명 가장자리를 살린다.
- **같은 등대지기의 프롬프트 예시.** 대화 일러스트라면 “등대지기 디자인을 인물 기준으로 사용. 대화창에 가슴 위까지 담고 바다 쪽 소리에 귀를 기울이는 순간. 등불이 한쪽 볼을 비추고 후드의 패인 부분은 대화 패널 위로 보이게.” 인게임이라면 “같은 등대지기 디자인과 횡스크롤 화면을 기준으로 오른쪽을 보는 전신. 플레이 중 키 약 40픽셀. 호박색 목도리와 왼손 등불이 별개의 형태로 읽히게. 투명 배경에 등불이 흔들릴 여백 확보.” 치수는 이 예시에서 선택한 값이다.

## 프레임을 늘리기 전 동작 설계

1. 행동과 플레이어가 구분해야 할 순간을 정한다. 걷기는 왼발 접지, 두 다리가 엇갈려 지나가는 자세, 오른발 접지, 반대편 통과 자세로 나눌 수 있다. 점프는 도약·정점·착지를 잡는다. 정해진 게임 상태와 이벤트 타이밍이 있으면 따르고, 어느 자세를 오래 보여줄지와 반복 여부를 정한다. 이동 주기와 캐릭터 이동 속도를 맞춘다.
2. 동작 내 카메라·키·방향·캔버스·기준점을 고정한다. 변위를 엔진에서 주는지 프레임에 그리는지 정한다. 뒤돌아도 등불은 인물 자신의 왼손에 남는다. 좌우 반전은 디자인·조명·게임플레이가 허용할 때 사용한다.
3. 정지 이미지 생성기에는 채택한 자세와 가용한 포즈 스케치를 넣는다. 동작을 구분하는 자세를 먼저 만들고 필요한 전환만 추가하거나 편집한다. 과장된 체형에서 자동 골격이 어긋나면 직접 그린 자세로 대체할 수 있다. 여러 방향과 동작에 쓸 기존 리그나 포즈열이 있다면 일관된 시점을 얻는 데 활용한다. 생성한 띠 이미지나 영상에서 프레임을 고를 때는 패킹 전에 개별 자세를 확인하고 정렬한다.
4. 의도한 크기와 속도로 재생한 후 이웃한 프레임을 넘겨 보거나 겹쳐 본다. 루프 경계, 실루엣 변화, 팔다리·소품의 좌우 교환, 의상·색의 깜빡임을 확인한다. 몸통이 오르내려도 공통 기준점은 유지한다. 접지한 발은 이동 중인 캐릭터를 **월드 좌표**에서 확인한다. 제자리 걷기를 정지 바닥 위에 재생하면 발이 그리는 궤적은 실제 이동 때와 다르다. 의도한 눌림, 공중 자세, 정지 시간은 살린다.

## 납품과 수정

픽셀화로 다음 자세를 그리는 데 필요한 특징이 사라진다면 큰 작업 크기에서 자세를 만든 다음 모든 프레임에 동일한 축소 방식과 팔레트를 적용해 본다. 목표 격자에서 직접 정리한 대표 자세와 비교해 인물과 행동이 잘 읽히는 방식을 택한다.

균일 격자로 자를 때는 같은 크기의 캔버스와 공통 기준점을 쓴다. 여백을 잘라 조밀하게 패킹했다면 원본 캔버스 크기, 잘라낸 위치, 프레임 사각형을 남겨 원래 자세를 복원할 수 있게 한다. 소비 도구에 맞는 형식으로 순서, 프레임별 시간, 반복 여부, 동작·방향 이름을 보존한다. 대비되는 배경에 올려 투명도와 셀 경계 잘림을 보고, 실제 텍스처 필터에서 인접 셀 색이 번지는지 확인한다. 또렷한 픽셀 아트는 목표 배율의 최근접 보간으로, 부드러운 그림은 프로젝트 필터로 본다. 내보낸 파일을 잘라 재생하고, 다른 미리보기까지만 가능했다면 그 범위를 밝힌다.

| 관찰한 문제 | 우선할 수정 |
| --- | --- |
| 초상화와 스프라이트가 다른 사람처럼 보인다 | 각자 표시 크기에서 특징을 나란히 비교한다. 사라진 윤곽이나 색 덩어리를 인게임 기본 자세에 복원해 후속 프레임의 기준으로 쓴다. |
| 개별 그림은 좋은데 안 움직이는 것 같거나 발이 미끄러진다 | 접지·통과 자세의 실루엣과 이동 속도 대비 발 이동량을 본다. 중간 그림을 늘리기 전에 핵심 자세나 유지 시간을 고친다. |
| 몸 전체가 떨리거나 등불이 셀 경계에서 사라진다 | 원본을 기준점에 겹치고 잘라낸 결과와 비교한다. 원본이 맞으면 정렬·여백·트림 정보를 고친다. |
| 동작은 읽히지만 목도리 색이나 픽셀 덩어리가 번쩍인다 | 문제가 되는 프레임을 기준 자세와 비교해 해당 영역을 고치거나 최종 공통 팔레트를 적용한 뒤 다시 재생한다. |
