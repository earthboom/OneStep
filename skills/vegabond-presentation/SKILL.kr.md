# Vegabond Presentation

선택한 작업 방식에 발표자료 수행 방법을 제공합니다. 기존 요약과 작업 프로필을 재사용하며, 공통 경계와 완료는 [에이전트 지침](../../agents/vegabond-agent.md)을 따릅니다. 직접 호출했다면 [scout의 공통 준비 절차](../vegabond-scout/SKILL.md#frame-and-classify)와 연결된 작업 스킬을 사용한 뒤, 분류를 다시 시작하지 않고 여기에서 계속합니다.

## 실행

현재 정보 요약을 재사용하며, 관련 청중·디자인과 형식 관례·출처 지침·과거 내용 및 렌더링 결함은 [vegabond-knowledge](../vegabond-knowledge/SKILL.md)를 사용합니다.

청중이 무엇을 이해하거나 결정해야 하는지, 발표자료를 어떻게 사용할지 정합니다. 제공된 자료, 기존 슬라이드, 템플릿, 관련 발표자 노트를 확인합니다. 요청한 개요나 대본과 완성된 편집 가능 덱을 구분합니다. 결과물을 제작하거나 편집할 때는 요청한 형식에 맞는 발표자료 스킬을 불러와 해당 제작·내보내기 절차를 따릅니다.

- **Create:** 청중의 출발점에서 의도한 결론까지 이어지는 서사를 구성합니다. 각 슬라이드에 목적과 뒷받침하는 근거를 배치한 뒤 이를 전달할 글, 도식, 표, 차트를 선택합니다. 일관된 시각적 위계로 요청한 결과물을 만들고, 편집이 필요하면 사용 가능한 원본 요소를 사용합니다.
- **Revise:** 편집 전에 기존 논지, 순서, 실제 슬라이드 내용을 확인합니다. 문제가 근거, 이야기 흐름, 문구, 시각 배치 중 어디에 있는지 판단합니다. 필요한 테마, 내용, 노트, 편집 가능성을 유지하면서 해당 수준을 고칩니다.
- **Research:** 관련 자료와 슬라이드로 주장, 청중 요구, 발표 선택지를 평가합니다. 발견 사항과 권고의 근거를 제시하며 조사 대상 덱은 바꾸지 않습니다.

## 검증

서사가 의도한 청중과 결론에 맞는지 확인합니다. 중요한 주장, 인용, 차트 값, 단위, 표기, 날짜를 원본과 대조하고 예시 데이터와 실제 결과를 구분합니다.

최종 전달 덱을 열거나 렌더링하고 모든 슬라이드의 가독성, 넘침, 잘림, 정렬, 대비, 순서를 확인합니다. 실제 내보낸 형식에서 슬라이드 수, 필요한 편집 가능 내용, 요청한 노트와 상호작용 기능을 확인합니다. 원본 미리보기만으로 내보낸 파일을 사용할 수 있다고 판단하지 않습니다. 사용한 뷰어나 렌더러와 확인하지 못한 애플리케이션별 동작을 밝힙니다.

## 수정

근거 없는 주장이나 깨진 서사는 배치를 다듬기 전에 고칩니다. 시각 문제는 의도한 의미를 유지하면서 위계, 간격, 차트 설계, 내용 밀도를 조정합니다. 수정하여 내보낸 결과를 확인하고, 영향받는 전환과 참조를 다시 검증하며, 최종 덱의 모든 슬라이드를 시각적으로 확인합니다. 결과물이나 요청한 발견 사항을 내용 근거, 시각 검수 결과, 남은 호환성 한계와 함께 반환합니다.

관찰한 내용·시각 문제, 수정, 최종 내보내기 근거, 재사용 검증을 허용된 기록과 재발 방지를 위해 vegabond-knowledge에 전달합니다.
