# Vegabond Presentation

진행 중인 작업에 발표 방법을 제공합니다. 기존 작업 요약·프로필과 [에이전트 지침](../../agents/vegabond-agent.kr.md)을 따릅니다. 직접 호출되면 [정찰 공통 설정](../vegabond-scout/SKILL.kr.md)과 연결된 작업 스킬로 부족한 맥락만 채우고 분류를 반복하지 않습니다.

## 실행

[필요한 정보의 공통 판단](../vegabond-scout/references/information-needs.kr.md)을 청중의 결정·원본 주장·비교할 집단과 단위·실제 출력 요구에 적용합니다. 조회한 주장을 슬라이드로 만들기 전에 근거 공백을 드러내고 내용만 검토하는 요청을 전체 제작으로 확대하지 않습니다.

청중이 무엇을 이해·결정해야 하고 어떻게 발표를 사용하는지 정합니다. 제공 출처·기존 슬라이드·템플릿·관련 발표자 메모를 확인합니다. 개요·대본 요청과 편집 가능한 완성 덱을 구분합니다. 실제 제작·편집에는 요청 형식에 맞는 발표 스킬을 선택해 제작·내보내기 절차를 따릅니다.

[지식 스킬](../vegabond-knowledge/SKILL.kr.md)로 청중·디자인·형식 관례·출처 지침·과거 내용 및 렌더링 문제를 조회하고 기존 정보 요약을 재사용합니다.

- 제작: 청중의 출발점에서 결론으로 이어지는 흐름을 만듭니다. 슬라이드마다 목적·근거를 정한 뒤 텍스트·도식·표·그래프를 선택합니다. 일관된 위계와 필요한 편집 가능한 원본 요소로 산출물을 만듭니다.
- 수정: 기존 논리·순서·실제 내용을 먼저 살핍니다. 근거·흐름·문구·배치 중 문제 층위를 찾고 필수 테마·내용·메모·편집성을 보존해 고칩니다.
- 조사: 관련 출처·슬라이드로 주장·청중 필요·선택지를 평가합니다. 발견·권고의 근거를 인용하고 조사한 덱은 수정하지 않습니다.

## 검증

이야기 흐름을 청중·결론과 대조합니다. 중요한 주장·인용·그래프 값·단위·라벨·날짜를 출처로 확인하고 예시 데이터와 실제 결과를 구분합니다.

최종 전달 덱을 열거나 렌더링해 모든 슬라이드의 가독성·넘침·잘림·정렬·대비·순서를 확인합니다. 실제 내보낸 형식의 슬라이드 수·필수 편집 요소·메모·상호작용을 확인합니다. 원본 미리보기만으로 내보내기 사용성이 입증되지는 않습니다. 사용한 뷰어·렌더러와 확인하지 못한 애플리케이션별 동작을 밝힙니다.

## 교정

근거 없는 주장·깨진 논리를 레이아웃보다 먼저 고칩니다. 시각 문제는 의미를 보존하며 위계·간격·그래프·내용 밀도를 조정합니다. 수정된 내보내기와 영향 전환·참조를 다시 확인하고 최종 덱의 모든 슬라이드를 시각 점검합니다. 결과나 요청한 검토에 내용 근거·시각 검증·호환성 한계를 붙입니다. 관찰한 문제·수정·최종 내보내기 근거·재사용 점검은 허용된 기록·재발 방지를 위해 지식 스킬에 전달합니다.
