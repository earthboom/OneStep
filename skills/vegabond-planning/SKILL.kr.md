# Vegabond Planning

선택한 작업 방식에 기획서 수행 방법을 제공합니다. 기존 요약과 작업 프로필을 재사용하며, 공통 경계와 완료는 [에이전트 지침](../../agents/vegabond-agent.md)을 따릅니다. 직접 호출했다면 [scout의 공통 준비 절차](../vegabond-scout/SKILL.md#frame-and-classify)와 연결된 작업 스킬을 사용한 뒤, 분류를 다시 시작하지 않고 여기에서 계속합니다.

## 실행

현재 정보 요약을 재사용하며, 관련 기획 방법·프로젝트 제약·과거 실행 가능성 및 측정 실패는 [vegabond-knowledge](../vegabond-knowledge/SKILL.md)를 사용합니다.

문서가 가능하게 해야 할 결정이나 행동을 파악합니다. 기존 근거, 이해관계자의 요구, 자원 제약을 살핍니다. 큰 템플릿을 강제하지 않고 해당 결정에 필요한 항목을 선택합니다. 서식 있는 문서나 발표자료는 이 내용 작성 방법과 함께 해당 결과물 스킬을 사용합니다.

- **Create:** 문제와 근거를 목표, 범위, 제안하는 접근법, 성공 지표로 연결합니다. 선택을 정당화해야 할 때 의미 있는 대안을 비교합니다. 관련 의존 관계, 자원, 책임, 위험, 일정으로 실행 가능성을 구체화합니다. 추정치, 제안한 담당자, 제안한 약속은 확정된 합의가 아닌 제안으로 표시합니다.
- **Revise:** 근거 없는 전제, 모호한 목표, 실현 불가능한 의존 관계, 빠진 지표, 상충하는 약속 등 현재 문서가 결정을 뒷받침하지 못하게 하는 차이를 찾습니다. 그 차이를 고치고 합의된 범위를 유지하면서 영향받는 항목에 결과를 반영합니다.
- **Research:** 명시된 기준으로 대안을 비교하거나 기존 기획을 점검합니다. 출처의 사실, 가정, 권고를 구분하고 근거가 되는 항목이나 출처를 제시합니다. 편집이 허용되지 않았다면 원본 기획서를 다시 쓰지 않고 발견 사항을 반환합니다.

## 검증

문제를 제안한 접근법과 의도한 결과까지 추적합니다. 범위, 자원, 책임, 의존 관계, 일정이 서로 모순되는 약속이 아닌 실행 가능한 순서인지 확인합니다. 중요한 합계, 비율, 예산, 추정치를 다시 계산하고 단위와 가정을 명시합니다.

성공 지표를 평가할 수 있게 만듭니다. 관련 기준선, 목표, 측정 방법, 측정 기간을 사용하고 비율은 분자와 분모를 밝힙니다. 근거를 꾸며내지 않고 미확인 사항과 제안한 목표를 표시합니다. 틀리면 권고가 바뀌는 가정과 그 영향을 살핍니다.

최종 문서를 읽고 요약, 판단 근거, 실행 상세, 지표가 일치하는지 확인합니다. 서식 있는 결과물은 해당 문서·발표자료 스킬로 최종 배치를 검수합니다. 기획을 발표자료로 전달한다면 발표자료 전용 시각 검증도 필요합니다.

## 수정

근거가 없거나 실현 불가능한 전제 중 영향이 가장 큰 것부터 해결합니다. 의존하는 범위, 추정치, 순서, 위험, 지표를 함께 갱신한 뒤 관련 실행 가능성·일관성 검증을 반복합니다. 미해결 의존 관계는 권고의 성립 조건으로 드러냅니다. 기획서나 요청한 분석을 결정 근거, 검증한 계산, 남은 가정과 함께 반환합니다.

확인한 기획 문제, 수정한 계산·의존 관계, 재검증 근거, 재사용할 의사결정 검증을 허용된 기록 갱신을 위해 vegabond-knowledge에 전달합니다.
