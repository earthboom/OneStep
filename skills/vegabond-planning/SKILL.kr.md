# Vegabond 기획

사람 전용 번역. AI는 영문 [SKILL.md](SKILL.md)를 사용한다.

제품·프로젝트·사업·운영의 기획서나 제안서를 작성·수정·평가할 때 사용한다. 단순한 작업 일정 관리만으로는 이 스킬이 필요하지 않다.

현재 작업 절차에 기획 문서 방법을 제공한다. 기존 브리프와 작업 프로필을 재사용하고, 공통 경계·완료는 [에이전트 지침](../../agents/vegabond-agent.kr.md)을 따른다. 직접 호출되면 [scout 공통 설정](../vegabond-scout/SKILL.kr.md)과 연결된 작업 스킬로 누락 맥락을 채운 뒤 분류를 다시 시작하지 않고 이어간다.

## 실행

문제를 겪는 대상, 발생 상황, 중요도, 이용 가능한 근거로 결정의 기반을 세운다. 수혜자의 필요·이해관계자 선호·요청된 해결책을 구별한다. 브리프의 목표·범위·제약과 [지식](../vegabond-knowledge/SKILL.kr.md)의 정보를 재사용하고 결정에 필요한 구획을 선택한다.

- **작성:** 문제를 의도한 성과와 실행 가능한 접근에 연결한다. 중요한 선택이면 가능한 현상 유지·최소 변경을 포함한 관련 대안을 공통 기준으로 비교한다. 핵심 가정을 근거·적정 검증법·실패 시 영향을 받는 결정에 연결한다.
- **수정:** 유용한 결정을 가로막는 전제·선택·의존성·지표·약속을 고치고 합의 범위를 유지하며 영향을 전파한다.
- **조사:** 명시된 기준으로 대안을 비교하거나 기획을 검토한다. 사실·가정·권고를 구별하고 근거를 제시하며 무단 수정 없이 결과를 반환한다.

중요한 기획 선택을 후속 작업의 근거로 삼거나 결과를 전달하기 전에 [기획 검토](references/review.kr.md)의 관련 구획을 적용한다. 상세한 문제 근거·대안·가정·실행 가능성·측정·결정 전달 점검은 이 참조가 담당한다. 작고 근거가 충분한 변경은 영향을 받는 점검만 적용하며, 의무 양식 대신 기존 브리프나 문서를 사용한다.

## 검증과 반환

최종 기획을 근거·보존 조건과 대조해 읽는다. 중요한 추정치를 재계산하고 범위·가용 역량·책임·의존성·일정이 일치하는지 확인한다. 미확정 비용 추정·담당·목표·약속은 제안으로 표시한다. 문서 일관성, 입증된 실행 가능성, 측정된 성과를 구별하고 미해결 전제를 의존하는 결정에 연결해 둔다.

추천안·이유·비용과 상충점·중요한 조건·다음 결정이나 행동을 첫머리에 제시한다. 근거와 검증 상세는 아래에서 볼 수 있게 둔다. 서식 문서나 덱은 해당 산출물 스킬을 사용해 최종 배치를 확인하고, 발표자료는 발표용 검증도 적용한다.

## 수정 대응

가장 중요한 미입증·실행 불가능 전제를 먼저 바로잡는다. 영향을 받는 선택·범위·추정·순서·위험·지표를 함께 갱신하고 무효가 된 점검을 반복한다. 유효한 결정은 보존하며 미해결 의존성을 드러낸다.

확인된 문제·수정·재검토 근거·재사용할 결정 점검을 지식 스킬에 반환해 허용된 범위에 저장한다.
