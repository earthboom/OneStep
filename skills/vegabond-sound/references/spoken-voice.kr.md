# 말소리

## 대본과 연기 준비

현지화, 재녹음, 연동을 위해 발화마다 고정된 대사 ID를 둔다. 정확한 텍스트, 상대, 말하는 의도, 톤과 강도, 시간 제약, 중요한 발음 메모를 기록한다. 본문과 지시·발음 힌트를 분리한다. 다르게 읽힐 수 있는 이름, 숫자, 단위, 약어, 혼합 표기도 표시한다.

한국어는 높임법과 인물 관계를 확인하고 실제 속도로 자연스럽게 읽어 본다. 받침과 연음, 한자어 수와 고유어 수, 한국어와 외국어가 섞인 이름의 발음을 점검한다. 이름의 정확한 발음이 중요한 경우 제공된 표기를 쓰거나 확인한다. 확정된 대사는 그대로 두고 TTS 발음용 변형 표기는 별도 필드에 둔다.

## 녹음·합성·편집

- **녹음과 후시 녹음.** 조용한 위치에서 같은 마이크와 게인으로 룸톤을 짧게 녹음한다. 마이크 방향, 거리, 팝 필터 위치를 일정하게 두고, 본 녹음 전에 일반 대사와 가장 큰 강도의 대사를 확인한다. 후시 녹음은 영상과 발화 시작, 입이 닫히는 시점, 호흡, 연기 의도를 비교한다. 재녹음에 대비해 원본이나 편집 전 사본을 보관한다.
- **TTS.** 선택한 서비스의 언어, 제어 기능, 출력 형식, 허용 용도를 확인한다. 음성이 지정되지 않았다면 사용처에 맞는 기본 음성을 고른다. 식별 가능한 실제 음성은 라이선스나 문서화된 이용 허락을 확인하고 적용되는 합성 음성 고지 요건을 따른다. 필요하면 연기 지시, 문맥, 지원하는 발음 마크업이나 사전을 쓴다. 일괄 생성 전에 일반 문장과 어려운 문장을 검증한다. 생성 후 대사마다 누락, 대체, 발음, 쉼, 캐릭터 일관성, 원문에 없는 발화를 듣는다. [말소리 제작 자료](sources.kr.md#말소리)
- **편집.** 먼저 테이크를 선택하고 정렬한다. 클립 게인, 짧은 페이드, 어울리는 룸톤으로 이어 붙인다. 거슬리는 파열음, 입소리, 험은 해당 위치를 손본다. 노이즈 감쇄는 약하게 적용해 비슷한 레벨의 원본과 비교하고 자음, 호흡, 문장 끝을 확인한다. 디에서나 다이내믹 처리는 실제 문제가 들릴 때 사용하고 음악과 효과음이 함께 나오는 조건에서 명료도를 다듬는다.

일괄 납품은 고정 대사 ID와 요청된 변주를 사용한다. 후속 편집자가 필요로 하는 룸톤이나 편집 여유 구간을 포함한다. 솔로와 장면 안에서 정상 속도로 듣고 특히 짧은 대사의 시작과 끝, 강조 음절, 이름을 확인한다. 텍스트 대조는 누락을 찾는 데 쓸 수 있다. 알아듣기 쉬운지, 감정과 발화가 자연스러운지는 실제 청취로 확인한다.
