# Vegabond 소설

현재 작업 흐름 안에서 소설을 쓰고 수정한다. scout가 제공한 작업 요약과 프로필을 재사용하고 문서 경계·검증·수락에는 [에이전트 지침](../../agents/vegabond-agent.kr.md)을 따른다. 직접 호출되면 scout의 [공통 준비](../vegabond-scout/SKILL.kr.md)와 연결된 작업 스킬을 사용하며 분류를 처음부터 반복하지 않는다.

## 관련 작품 맥락 조회

실제 장면과 수정에서 필요한 질문은 공통 [정보 필요성 판단](../vegabond-scout/references/information-needs.kr.md)으로 도출한다. 장르 이름뿐 아니라 인과·정보·공개의 의존성을 살핀다. 조회한 자료를 채택할 때 정본, 저자 선호, 인물의 믿음, 임시 창작을 구별한다.

장면을 쓰거나 고치기 전에 기존 정보 요약을 재사용해 [vegabond-knowledge](../vegabond-knowledge/SKILL.kr.md)에 범위가 정해진 맥락을 요청한다. 작품과 개정본, 장·장면, 이야기 시간, 시점, 관련 인물과 별칭, 장소, 알려진 의도 사건을 식별한다. 빠진 값은 빈틈이며 사실을 만들어 채우라는 뜻이 아니다.

기존 설정 문서, 인물·관계 메모, 연표, 관련 원고, 저자 결정을 출처로 쓴다. knowledge의 범위별 색인→상세 조회를 따르며 작품과 개체 이름·별칭, 장면·시간, 관련 질문으로 검색한다. 연결된 인물이나 사건은 실제 의존성이 있을 때 확장한다. 행동이 중요한 조연도 포함하며 서사적 비중만으로 관련성을 판단하지 않는다. 유효한 맥락을 재사용하고 장면마다 설정 전체를 다시 읽지 않는다.

장면에 필요한 사실을 출처 위치·적용 조건·빈틈과 함께 기존 정보 요약에 반환한다.

| 맥락 | 관련될 때 조회·확인할 내용 |
| --- | --- |
| 세계와 장소 | 규칙·예외, 능력과 비용, 지리·이동, 장면의 제약. |
| 인물 | 정체, 이름·별칭, 역할, 목표, 성향, 목소리, 능력, 현재 신체·감정 상태. |
| 관계 | 누가 누구에게 무엇을 느끼고 믿고 빚지고 아는지, 방향과 변화 및 발효 시점. 상호 감정이나 대칭적인 지식을 가정하지 않는다. |
| 시간과 공개 | 사건 순서, 해당 장면의 위치·상태, 인물의 지식과 습득 경로, 독자에게 공개된 정보, 계획된 공개. |
| 문체 참조와 수정 | 이 작품·서술자·인물에 관한 저자 작성·선택 구절, 명시적 문체 선택, 검증된 전후 수정. 출처와 예외를 보존한다. 작품의 목소리 기준과 영감으로 참고하는 외부의 좋은 대사를 구별한다. |

이 참조로 기존 요약 안에 짧은 목소리 기준을 둔다. 서술자가 주목하거나 생략하는 것, 감정 설명 정도, 대화·행동·묘사의 비중, 어휘·이미지·호흡, 독자가 추론할 여백을 포함한다. 관찰한 패턴과 저자가 확인한 선호를 구별한다. 기준이 없으면 요청과 현재 작품의 짧은 표본에서 임시 방향을 세우고 관행적인 승인 단계를 더하지 않으면서 저자 피드백으로 다듬는다. 기준은 선택을 돕는 것이며 모든 장면에 같은 문장 패턴을 강요하지 않는다.

중요한 요약은 원문에 대조한다. 명시적 저자 결정과 선언된 출처 권한을 따르며 가장 최근 파일이라는 이유만으로 충돌을 해결하지 않는다. 확정 정본, 임시 계획·새 창작, 인물의 믿음·소문, 미확인을 구분한다. 미래 사건이나 관계를 앞선 장면에 적용하지 않으며 저자 지식이 인물·독자 지식으로 조용히 바뀌지 않게 한다. 충돌한 사실과 영향을 받는 장면을 표시해 조사하거나, 다른 독립 작업은 계속하면서 실제로 중요한 미해결 의도를 확인한다.

기존 작품 설정집을 재사용하고 경쟁하는 복사본을 만들지 않는다. 허용된 지식 저장이 유용하면 기존 fiction 분야와 저장 형식을 사용한다. `scope`에 작품 경계, `keywords`에 이름·별칭, `context`나 본문에 개정·시간 조건을 둔다. 전체 프로필을 복제하기보다 원출처에 연결한다. 활성 지식 항목만으로 저자가 확정한 정본이 성립하지 않는다. 작품 자료가 없을 때 설정 항목을 지어내지 않는다.

## 저장된 작법 자료 적용

설계·집필·수정의 중요한 선택에서는 [에이전트 지침](../../agents/vegabond-agent.kr.md#지식과-문제-기록)의 공유 참조 범위 안에서 작법 조사 안내 (`knowledge/fiction/K-FIC-CRAFT-GUIDE.kr.md`)를 [vegabond-knowledge](../vegabond-knowledge/SKILL.kr.md)의 조회 경로로 사용한다. 현재 작품의 출처와 목소리 기준이 맥락을 제공하며, 안내는 이야기의 사실이 아닌 검토할 방법을 제공한다.

1. **결정할 것을 정한다.** 실제 문제나 원하는 효과와 작품·서사 단위·장면의 범위를 밝힌다. 관련되는 장르·분위기·인물의 목표와 관계·시점·보존 조건을 포함한다. 관계의 전환과 문장 리듬은 서로 다른 근거가 필요하다.
2. **선별해 조회한다.** 안내의 주제 연결과 구체적인 조회어로 관련 상세·출처·적용 조건·예외·점검을 살핀다. 설계와 집필 사이에 유효한 정보 요약을 재사용한다. 실제 의존성이나 빈틈이 생기면 확장하며 열두 분야 전체나 모든 외부 출처를 매번 다시 읽지 않는다. 중요한 주장이나 출처 변경으로 필요해지면 원근거를 재확인한다.
3. **맞춰 적용하거나 채택하지 않는다.** 유용한 방법을 이 작품의 구체적인 선택에 연결하고 장르·분위기·인물 목소리·장면 기능에 맞게 바꾼 점을 설명한다. 출처가 뒷받침하는 주장, 편집적 절차, 의도한 효과를 구별한다. 중요한 채택·조건부 사용·비채택은 참조 ID와 함께 기존 요약에 남긴다. 맞지 않는 모델은 거절할 수 있으며 막의 수·갈등·변화·엄격한 마법·특정 문체는 보편적인 의무가 아니다.
4. **실제 결과에 적용해 점검한다.** 실제 개요·장면·문단·수정본에 해당 점검을 쓴다. 구조적 선택이 필요하면 채택한 참조 ID·적용 판단·계획한 점검을 [fiction-design](../vegabond-fiction-design/SKILL.kr.md)에 전달하고 같은 요약을 집필로 가져온다. 반환 전에 [작법 적용 검수](references/review.kr.md#적용한-작법-방법)를 따른다. 확립한 사실이나 의도한 체험과 결과가 충돌하면 방법을 조정하거나 설계로 돌아간다. 체크리스트나 출처 인용만으로 독자 효과가 입증되지는 않는다.

기존 요약과 검토 흐름 안에서 결정의 규모에 맞게 수행한다. 별도 보고서·반복적인 전체 저장소 조회·모든 장면의 의무 기법을 추가하지 않는다.

## 선택한 대사 참고 자료 응용

대사를 쓰거나 고치기 전에 장면의 필요를 [vegabond-knowledge](../vegabond-knowledge/SKILL.kr.md)를 통해 선택된 대사 참고 자료와 연결한다. 작업 프로젝트의 관련 모음과 [에이전트 지침](../../agents/vegabond-agent.kr.md#지식과-문제-기록)에서 사용을 허용한 저자 선택 공유 모음을 활용한다. 아래 판단은 기존 장면 요약 안에서 간결하게 수행하며 별도 작업지나 영구적인 사용 이력은 요구하지 않는다.

1. **장면의 필요를 정한다.** 화자·청자·관계·당장의 목적·극적 기능·의도한 정서 효과를 파악한다. 좋은 대사를 고르기 전에 실제 작품과 목소리 기준으로 장르·분위기·표현 밀도를 정한다.
2. **기능과 감성으로 조회한다.** 애정과 강압, 동맹 내부의 불안과 외부 위협, 아름다운 것을 잠시 가까이 들이는 감각처럼 관련된 긴장으로 검색한다. 필요하면 출처 이름이나 장르도 쓰지만 장르 이름만으로 선택하지 않는다. 해당 해설·응용 조건·한계를 읽는다. 유효한 조회는 재사용하고 맞는 후보가 없으면 적용하지 않고 진행한다. 대사를 넣기 위해 장면을 만들거나 모든 장면에 인상적인 연설을 요구하지 않는다.
3. **작동 원리를 평범한 말로 추출한다.** 원문의 표현을 잠시 내려놓고 어떤 관계·선택을 드러내는지, 어떤 감정·미해결 긴장을 담는지, 관찰자의 태도는 무엇인지, 어떤 이미지·호흡이 효과를 전하는지 짚는다. 현재 장면에 필요한 부분을 선택한다. 저장된 해설은 읽기의 한 방식이며 확정된 원작 의도나 새 이야기에서 승인해야 할 교리가 아니다. 중요한 채택·조정·비채택은 참조 ID와 함께 기존 요약에 남긴다.
4. **새 이야기의 재료로 쓴다.** 화자의 경험·직업·문화·알고 있는 정보·현재 주변 환경에서 이미지와 말을 고른다. 어투·비유 밀도·멈춤·직접성은 인물, 상대, 장면의 압박, 작품의 분위기에 맞춘다. 장르는 맥락이며 고정된 소품이나 옛말 목록이 아니다. 유용한 극적 원리를 새 표현으로 구현한다. 원문의 고유한 이미지 배열이나 문장 흐름을 유지하면서 명사나 동의어만 바꾸는 것은 충분한 응용이 아니다.
5. **장면 안에서 검토한다.** 주변 행동과 청자의 반응을 포함해 새 대사를 읽고 [응용 대사 점검](references/review.kr.md#응용한-대사)으로 원문과 비교한다. 이 장면과 목소리에서 역할을 하는 표현을 남긴다. 가져온 대사라는 느낌이 남거나 장면을 흐트러뜨리는 응용은 다시 쓰거나 버린다. 출처 문구는 참고 기록에 보존하되 응용한 원고에 기본적으로 그대로 삽입하지 않는다.

## 설계 깊이 선택

새 작품·서사 단위, 연결 장면, 인물의 동기·변화, 시점·공개, 배치·회수, 구조적 수정에 중요한 서사 선택이 필요하면 [vegabond-fiction-design](../vegabond-fiction-design/SKILL.kr.md)을 사용한다. 기존 요약, 관련 정본·원고, 목소리 기준, 제약, 열린 질문을 전달한다. 유효한 설계를 재사용하며 근거가 달라진 선택만 다시 검토한다. 명확한 국소 장면이나 문장 수정은 목적과 보존 조건을 짧게 밝히고 별도 설계 없이 진행할 수 있다. 탐색 집필로 임시 설계를 다듬을 수 있으며 모든 구절에 완성된 줄거리나 고정된 서사 공식을 요구하지 않는다.

설계는 같은 흐름 안에 선택과 의도한 효과를 반환하며 두 번째 독립 작업 흐름이 아니다. 설계 전용 요청은 요청하지 않은 원고 대신 설계를 산출하고 끝낸다. 기존 작품 맥락은 앞의 조회 절차로 가져오며 경쟁하는 설정집을 만들지 않는다.

## 집필·수정

요청과 관련 출처에서 장르·독자·현실성·시점·시제·서술 신뢰성·의도한 불확실성을 확립한다. 작품의 기준과 범위가 정해진 저자 선택을 적용하며 확정 사실과 제안한 창작을 구별한다. 문장을 판단하거나 수정하기 전에 [원고 검수와 수정](references/review.kr.md)을 읽고 실제 최종 원고를 반환하기 전에 적용한다.

- **제작:** 설계 또는 간결하게 정한 장면 목적·인물 의도·압박·변화를 필요에 맞게 쓴다. 요청한 목소리와 시점으로 행동·대화·설명을 쓰며 의도한 모호함과 형식을 존중한다. 발견이 예정된 흐름이나 효과를 실질적으로 바꾸면 정본을 조용히 고치지 않고 fiction-design에 돌려보낸다.
- **수정:** 구조·장면·연속성·문장 수준에서 진단한다. 요청 범위와 사실, 효과적인 구절을 보존하며 확인된 가장 앞선 인과 문제를 고친다. 연결된 서사 선택이 바뀌면 의존 집필 전에 관련 설계를 갱신한다. 검수 문서의 발견 분류와 수정 반복을 따르며 설명을 늘리는 것이 언제나 개선은 아니다.
- **조사·비평 전용:** 구절에 근거해 발견을 설명하고 문구의 근거·해석·제안한 창작을 구별한다. 분석을 검증하되 원문을 고치거나 해석을 정본으로 승격하지 않는다.

## 반환

요청한 원고나 분석, 중요한 선택, 검토·수정 근거, 미해결 조건을 현재 작업 흐름에 반환한다. 상세 점검·불확실한 판단·문체·재발 근거·최종 재독은 검수 문서가 담당한다. 유용한 발견은 기존 쓰기 범위 안에서 knowledge로 보내며 별도 문체 저장소나 새 기록 형식을 만들지 않는다. 공통 지침에 따라 AI 검토와 vagabond의 독립적인 수락을 구별한다.

## 2026-11-17 집필 자료 선택 보완

작법 안내와 지식 스킬의 자연어 재탐색 절차를 사용합니다. 복합 요청은 중요한 작법 결정별로 나누고 각 요구가 답변되었는지 확인합니다. 검색 성공이나 상위 세 결과만으로 전체 요구를 다뤘다고 판단하지 않습니다. 한국어 표현은 한국어 표현 안내, 연구와 평가는 학술 연구 안내 및 구절에 근거한 원고 평가로 연결합니다. 원래 요청으로 놓친 주제는 집중 검색어나 안내의 지정 항목으로 재탐색하고 공백을 드러냅니다. 유효한 브리프를 재사용하며 매번 전체 자료나 외부 원문을 읽지는 않습니다. 현재 작품의 사실·목소리를 우선하고 선택한 원리의 실제 적용을 원고에서 확인합니다.


## 장면에서 성격을 드러내기

인물의 성격을 드러낼 대목에서는 [설계에서 정한 선택](../vegabond-fiction-design/SKILL.kr.md#성격이-드러나는-선택을-설계하기)을 이어받는다. 국소적인 대목이라면 필요한 선택을 그 자리에서 짚는다. 장면과 시점에 맞는 단서를 고른다. 먼저 하는 일과 하지 않고 두는 일, 대사로 상대에게서 얻으려는 반응, 지문에서 먼저 알아차리고 해석하는 대상이 단서가 될 수 있다. 직접적인 서술도 작품의 목소리나 완급에 도움이 될 수 있다. 인접한 설명이 단서만으로는 남는 의미를 더하는지 확인한다.

대사로 인물을 구별해야 한다면 각자가 이 상대에게 무엇을 원하고 그것을 어떻게 얻으려 하는지 정한다. 작품의 문체 근거에 맞춰 어휘·리듬·직접성·침묵을 고른다. 한국어 대사에서는 호칭과 종결어미, 확신을 드러내는 정도가 관계와 배석자, 말투가 달라지는 계기에 맞는지 살핀다. 청자의 반응까지 읽고 집필한 대목에 [성격 묘사 검수](references/review.kr.md#성격-묘사-검수)를 적용한다.

## 공통 리뷰 시점

[공통 리뷰 시점](../vegabond-review/SKILL.md#review-checkpoints)을 적용합니다. 새롭거나 변경된 서사 선택은 후속 집필 전에 fiction-design 기준으로 검토하고 유효한 기존 설계 리뷰는 재사용합니다. 전달 전 실제 최종 원고에 fiction 기준을 적용하며 위의 원고 검토를 같은 과정에 포함합니다. 정본, 지식·문제 ID, 근거를 이어받고 구조적 결함은 설계로 돌려 영향받는 구절과 의존성만 재검토합니다.
