# Vegabond Fiction

진행 중인 작업 안에서 소설을 집필·수정합니다. 기존 요약·프로필과 [에이전트 지침](../../agents/vegabond-agent.kr.md)을 따릅니다. 직접 호출되면 [정찰 공통 설정](../vegabond-scout/SKILL.kr.md)과 연결 작업 스킬로 부족한 맥락만 채우고 분류를 반복하지 않습니다.

## 관련 이야기 맥락 수집

[필요한 정보의 공통 판단](../vegabond-scout/references/information-needs.kr.md)으로 실제 장면·편집에서 질문을 도출하고 장르명에 드러나지 않은 인과·지식·공개 의존성도 필요할 때 확인합니다. 조회 자료를 적용할 때 설정·저자 취향·인물 믿음·잠정 창작을 구분합니다.

장면 집필·수정 전에 [지식 스킬](../vegabond-knowledge/SKILL.kr.md)에 집중된 맥락을 요청하고 기존 정보 요약을 재사용합니다. 알려진 작품·버전·장과 장면·작중 시간·시점·등장인물과 별칭·장소·의도한 사건을 식별합니다. 모르는 값은 공백이며 사실을 만들 이유가 아닙니다.

작품의 기존 설정·인물과 관계·연표·원고 구간·저자 결정을 원본으로 사용합니다. 작품·인물명·별칭 다음 장면·시간·질문으로 목록→상세 제한 조회를 합니다. 실제 의존성·충돌에 필요한 인물·사건만 확장하며 조연도 행동이 중요하면 포함합니다. 비중이 관련성을 결정하지는 않습니다. 유효한 맥락을 재사용하고 장면마다 설정 전체를 다시 읽지 않습니다.

기존 정보 요약에 관련 사실·원본 위치·조건·공백을 반환합니다.

| 맥락 | 관련될 때 조회·확인할 내용 |
| --- | --- |
| 세계와 장소 | 규칙·예외·능력·비용·지리·이동·장면 제약. |
| 인물 | 정체·이름과 별칭·역할·목표·성격·목소리·능력·현재 신체 및 감정 상태. |
| 관계 | 누가 누구에 대해 느끼고 믿고 빚지고 아는지, 방향·변화·적용 시점. 감정·지식의 대칭을 가정하지 않습니다. |
| 시간과 공개 | 사건 순서·위치·상태·인물 지식과 획득 경로·독자 공개 정보·예정된 공개. |
| 목소리 참고와 수정 | 저자 작성·선택 구간, 명시 문체 선택, 해당 작품·화자·인물의 관련 전후 수정과 검증 근거·예외. |

기존 요약에 짧은 목소리 기준을 둡니다. 화자가 주목·생략하는 것, 감정 설명 정도, 대화·행동·묘사 비율, 어휘·이미지·리듬·독자 추론 여지를 살핍니다. 관찰 패턴과 저자 확인 취향을 구분합니다. 기준이 없으면 요청과 작품의 짧은 샘플에서 잠정 방향을 정하고 피드백으로 보완하되 일상 승인 관문을 더하지 않습니다. 기준은 선택을 돕지 문장 패턴을 복제하지 않습니다.

중요한 요약은 원문으로 확인하고 명시 저자 결정과 정해진 원본 권한을 따릅니다. 최신 파일만으로 충돌을 해결하지 않습니다. 확립 설정·잠정 계획과 창작·작중 믿음 및 소문·미확인을 구분합니다. 미래 사건·관계를 이전 장면에 적용하거나 저자 지식을 인물·독자 지식으로 옮기지 않습니다. 충돌 사실·장면을 표시하고 필요한 근거 조사·의도 확인 뒤 의존 집필을 하되 독립 작업은 계속합니다.

기존 설정집을 재사용하고 경쟁 사본을 만들지 않습니다. 허용된 저장이 유용하면 기존 fiction 형식을 쓰고 작품 경계는 scope, 이름·별칭은 keywords, 버전·시간 조건은 context·본문에 둡니다. 프로필 전체를 복제하지 않고 원본을 연결합니다. active 지식이 저자 확인 설정은 아니며 이야기 자료 없이 설정 항목을 만들지 않습니다.

## 설계 깊이 선택

새 작품·이야기 줄기·연결 장면·동기와 변화·시점과 공개·복선과 회수·구조 수정의 중요한 선택은 [소설 설계](../vegabond-fiction-design/SKILL.kr.md)를 사용합니다. 기존 요약·설정·원고·목소리 기준·제약·질문을 전달하고 유효한 설계는 재사용합니다. 명확한 로컬 장면·문장 편집은 목적·보존 조건만 명시할 수 있습니다. 탐색 집필은 잠정 설계를 도울 수 있으며 모든 구간 전에 완성 줄거리·공식을 요구하지 않습니다.

설계는 같은 흐름에 선택과 의도한 효과를 반환하며 설계 전용 요청에 원고를 덧붙이지 않습니다. 위 맥락 조회를 재사용하고 경쟁 설정집을 만들지 않습니다.

## 집필과 수정

요청·원본으로 장르·독자·현실성·시점·시제·화자 신뢰도·의도한 불확실성을 확인합니다. 확정 사실과 제안 창작을 구분하고 작품 기준·저자 선택을 적용합니다. 문장을 판단·수정하기 전에 [원고 검토와 교정](references/review.kr.md)을 읽고 최종 본문에 적용합니다.

- 제작: 설계·장면 목적·인물 의도·압력·변화를 필요에 따라 사용합니다. 요청한 목소리·시점·의도한 모호성·형식을 존중하며 행동·대화·설명을 씁니다. 순서·효과를 바꾸는 발견은 설정을 조용히 고치지 않고 설계에 반환합니다.
- 수정: 구조·장면·연속성·문장 층위에서 진단합니다. 요청 범위에서 최초의 확인된 인과 문제를 고치고 사실·유효 구간을 보존합니다. 연결 선택이 바뀌면 의존 재작성 전에 설계를 갱신합니다. 발견 분류·교정 반복을 따르며 설명 증가를 자동 개선으로 취급하지 않습니다.
- 조사·비평 전용: 원문 근거·해석·제안 창작을 나눕니다. 원고를 고치거나 해석을 설정으로 승격하지 않고 분석을 검증합니다.

## 반환

요청 본문·분석, 중요한 선택, 검토·교정 근거, 미해결 조건을 반환합니다. 상세 점검·불확실한 판단·문체 및 재발 근거·최종 재독은 검토 참고 문서를 따릅니다. 유용한 발견은 허용 범위에서 지식 스킬에 전달하고 별도 문체 저장소·새 기록 스키마를 만들지 않습니다. AI 검토와 vagabond의 독립 수용을 구분합니다.
