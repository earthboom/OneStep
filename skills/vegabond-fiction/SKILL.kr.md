# Vegabond Fiction

현재 작업 안에서 소설을 집필하고 수정합니다. 기존 요약과 프로필을 재사용하며 공통 경계와 완료 기준은 [에이전트 지침](../../agents/vegabond-agent.md)을 따릅니다. 직접 호출되면 [scout의 공통 준비](../vegabond-scout/SKILL.md#frame-and-classify)와 연결된 작업 스킬을 사용하고 분류를 다시 시작하지 않습니다.

## 관련 작품 맥락 조회

장면을 집필하거나 수정하기 전에 현재 정보 요약을 재사용하면서 [vegabond-knowledge](../vegabond-knowledge/SKILL.md)에 필요한 맥락을 요청합니다. 알려진 작품·개정, 장·장면, 작품 시간, 시점, 관련 인물과 별칭, 장소, 예정 사건을 식별합니다. 빠진 값은 빈틈이며 사실을 만들어내라는 뜻이 아닙니다.

기존 설정 문서, 인물·관계 메모, 시간표, 관련 원고 구절, 저자 결정을 출처로 사용합니다. 지식 스킬의 범위 제한 색인→상세 조회를 따르고 작품·이름·별칭에서 장면·시간·질문으로 좁힙니다. 의존성이나 충돌이 있을 때만 연결 인물과 사건으로 넓힙니다. 행동이 중요한 조연도 포함하며 서사적 비중만으로 관련성을 정하지 않습니다. 장면마다 모든 설정 파일을 다시 읽지 말고 유효한 맥락을 재사용합니다.

현재 정보 요약에 장면 관련 사실과 출처 위치, 적용 조건, 빈틈을 반환합니다.

| 맥락 | 관련될 때 조회·점검할 내용 |
| --- | --- |
| 세계와 장소 | 규칙, 예외, 능력과 비용, 지리, 이동, 장면의 제약. |
| 인물 | 정체, 이름·별칭, 역할, 목표, 성향, 말투, 능력, 현재 신체·감정 상태. |
| 관계 | 누가 누구를 어떻게 느끼고 믿고 빚지고 알고 있는지, 방향·변화·발효 시점. 감정이나 지식의 대칭을 가정하지 않습니다. |
| 시간 순서와 공개 정보 | 사건 순서, 해당 장면의 위치·상태, 인물 지식과 획득 경로, 독자에게 공개한 정보, 예정된 공개. |
| 문체 참조와 수정 | 저자 작성·선택 구절, 명시적 문체 선택, 작품·서술자·인물에 적용되는 확인된 수정 전후 사례와 출처·예외. |

이 참조로 기존 요약에 짧은 문체 기준을 둡니다. 서술자가 보고 생략하는 것, 감정 설명의 정도, 대화·행동·묘사 비중, 어휘와 심상, 리듬, 독자 추론 여지를 포함합니다. 관찰한 패턴과 저자 확인 선호를 구별합니다. 기준이 없으면 요청과 현재 작품의 짧은 예시에서 임시 방향을 만들고 일상적인 승인 단계를 추가하지 말고 실제 저자 피드백으로 다듬습니다. 기준은 선택을 돕는 것이며 모든 장면의 문장 패턴을 같게 만드는 규칙이 아닙니다.

중요한 요약은 원래 구절과 대조합니다. 명시적 저자 결정과 정해진 출처 권위를 따르고 최신 파일이라는 이유만으로 불일치를 해결하지 않습니다. 정본, 임시 계획·새 창작, 작품 속 믿음·소문, 미확인을 구별합니다. 미래 사건·관계를 앞선 장면에 적용하거나 저자 지식을 인물·독자 지식으로 바꾸지 않습니다. 충돌한 사실과 장면을 밝히고 조사하거나 중요한 미해결 의도를 의존 집필 전에 확인하되 독립 작업은 계속합니다.

경쟁하는 설정집을 만들지 않고 기존 것을 재사용합니다. 허용된 지식 저장이 유용하면 기존 소설 분야와 형식을 사용합니다. `scope`에 작품 경계, `keywords`에 이름·별칭, `context`나 본문에 개정·시간 조건을 둡니다. 전체 프로필 대신 원출처에 연결합니다. active 지식 항목만으로 저자 확인 정본이 되는 것은 아닙니다. 작품 자료가 없다고 설정 항목을 꾸며내지 않습니다.

## 설계 깊이 선택

새 작품·에피소드, 연결 장면, 인물 동기·변화, 시점·공개 정보, 복선·회수, 구조 수정에 중요한 서사 선택이 필요하면 [vegabond-fiction-design](../vegabond-fiction-design/SKILL.md)을 사용합니다. 기존 요약, 관련 정본·원고·문체 기준, 제약, 질문을 전달합니다. 유효한 설계를 재사용하고 근거가 바꾼 선택만 재검토합니다. 방향이 분명한 국소 장면이나 문장 수정은 목적과 보존 조건만 짧게 적고 별도 설계 없이 진행할 수 있습니다. 탐색적 집필로 임시 설계를 다듬을 수 있으며 매번 완성 플롯이나 고정 공식을 요구하지 않습니다.

설계는 현재 작업 안에서 선택과 의도한 효과를 반환하며 별도 실행 반복을 만들지 않습니다. 설계만 요청받으면 원고를 추가하지 않고 그 결과로 끝냅니다. 위 절에서 기존 맥락을 조회하고 설계가 경쟁하는 설정집을 만들지 않게 합니다.

## 집필 또는 수정

요청과 관련 출처에서 장르, 독자, 사실성, 시점, 시제, 서술자 신뢰도, 의도한 불확실성을 파악합니다. 작품 기준과 범위가 정해진 저자 선택을 적용하고 확정 사실과 창작 제안을 구별합니다. 문장을 판정하거나 수정하기 전에 [원고 검수와 수정](references/review.md)을 읽고 인계 전 실제 최종 원고에 적용합니다.

- **Create:** 설계나 장면 목적, 인물 의도, 압박, 변화를 형식에 맞게 사용합니다. 요청된 문체·시점으로 행동·대화·설명을 집필하고 의도한 모호함과 형식을 존중합니다. 예정 순서나 효과를 크게 바꾸는 발견은 정본을 조용히 바꾸지 말고 fiction-design에 반환합니다.
- **Revise:** 구조·장면·연속성·문장 수준에서 진단합니다. 요청 범위에서 가장 앞선 확인된 인과 문제부터 고치고 사실과 효과적인 구절을 보존합니다. 연결된 서사 선택이 바뀌면 의존 수정 전에 해당 설계를 갱신합니다. 참조 문서의 발견 분류와 수정 반복을 사용하며 설명 추가가 곧 개선은 아닙니다.
- **조사·비평만:** 구절에 근거하여 사실·해석·창작 제안을 구별합니다. 원출처를 다시 쓰거나 해석을 정본으로 만들지 말고 분석을 검증합니다.

## 결과 반환

요청한 원고나 분석, 중요한 선택, 검수·수정 근거, 미해결 조건을 현재 작업 스킬에 반환합니다. 상세 점검, 불확실한 판단, 문체·재발 근거, 최종 다시 읽기는 검수 참조 문서가 담당합니다. 기존 쓰기 범위에서 유용한 발견을 지식 스킬로 보내며 별도 문체 저장소나 기록 스키마를 만들지 않습니다. 공통 지침에 따라 AI 검토와 vagabond의 독립 수락을 구별합니다.
