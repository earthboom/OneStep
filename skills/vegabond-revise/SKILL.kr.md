# Vegabond Revise

의도한 제약을 지키면서 기존 결과를 개선합니다. scout가 제공한 요약과 작업 프로필을 재사용합니다. 직접 호출했다면 [scout의 공통 준비 절차](../vegabond-scout/SKILL.md#frame-and-classify)로 맥락을 채우되 다시 분기하지 않으며, 문서 경계, 검증, 수용은 [에이전트 지침](../../agents/vegabond-agent.md)을 따릅니다.

## 수정 작업 구체화

scout의 정보 요약을 재사용하며, 관련 과거 실패·유지할 계약·수정 검증은 [vegabond-knowledge](../vegabond-knowledge/SKILL.md)를 사용합니다. 확인한 발견 사항과 수정 전후 근거는 허용된 기록 갱신을 위해 반환합니다.

공통 프로필과 원본 맥락을 사용해 결함 수정과 의도적인 개선을 구분하고 영향받는 의존 관계를 파악합니다. [scout의 공통 연결](../vegabond-scout/SKILL.md#connect-steps-to-skills-and-checks)을 사용하여 해당 전문 스킬의 revise·검증·수정 방법을 아래 단계 안에 적용합니다. 공통 판단을 반복하지 않고 수정에 필요한 누락된 세부사항만 보완합니다.

분석과 피드백만 요청한 경우와 편집이 허용된 경우를 구분합니다. 발견 사항만 요청했다면 원본을 고치지 않고 반환합니다. 기존 범위와 규모를 유지하며, 새로운 의존 관계를 발견하면 밝힙니다.

## 수정

1. 현재 상태와 목표의 차이를 확인하고 의미 있는 비교 기준을 마련합니다. 필요한 경우 기존 이력이나 비파괴적인 비교 방법을 통해 원본 상태에 계속 접근할 수 있게 합니다.
2. 결함은 수정 전에 재현하고 원인을 추적합니다. 편집을 통한 개선은 요청한 기준에 연결합니다. 일관성을 갖춘 최소한의 변경을 수행하고 관련 없는 다듬기는 범위에서 제외합니다.
3. 수정 전후를 비교하여 의도한 개선과 유지할 조건을 확인합니다. 영향받는 의존 대상이나 주변 내용을 살피고, 유지하려던 사항에서 불가피하게 벗어난 부분은 설명합니다.

수정한 결과물 또는 허용된 발견 사항, 의미 있는 변경 내용, 비교 근거, 미해결 사항을 반환합니다. 바뀌었다는 사실만으로 개선의 근거가 되지는 않습니다.
