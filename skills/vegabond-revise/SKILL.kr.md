# Vegabond Revise

의도한 제약을 보존하며 기존 결과를 개선합니다. 정찰의 작업 요약·프로필과 [에이전트 지침](../../agents/vegabond-agent.kr.md)을 재사용합니다. 직접 호출되면 [정찰 공통 설정](../vegabond-scout/SKILL.kr.md)으로 누락 맥락만 채우고 정찰로 되돌아가지 않습니다.

## 수정 과제 구체화

[필요한 정보의 공통 판단](../vegabond-scout/references/information-needs.kr.md)을 실제 변경·보존 계약·영향받는 후속 부분에 적용합니다. 초기 질문이 중요한 조건을 놓쳤는지 확인하고 과거 사건의 수정책을 옮기기 전에 기전을 비교합니다.

[지식 스킬](../vegabond-knowledge/SKILL.kr.md)로 과거 실패·보존 계약·수정 점검을 조회하고 기존 요약을 재사용합니다. 확인한 발견과 전후 근거는 허용된 기록 갱신에 반환합니다.

공통 프로필과 원래 맥락으로 결함 수정과 의도적 개선을 구분하고 영향 의존성을 찾습니다. [정찰 역량 연결](../vegabond-scout/SKILL.kr.md)을 통해 필요한 전문 스킬의 수정·검증·교정 방법을 적용합니다. 공통 평가를 반복하지 않고 빠진 수정 세부만 보완합니다.

분석 전용 피드백과 허용된 편집을 구분합니다. 검토 결과만 요청됐다면 원본을 고치지 않습니다. 기존 범위·규모를 유지하고 새 의존성이 드러나면 알립니다.

## 수정

1. 현재 상태와 목표 차이, 의미 있는 비교 기준을 정합니다. 필요하면 기존 이력이나 비파괴 비교로 원래 상태를 보존합니다.
2. 결함은 재현·원인 추적 뒤 고치고, 편집 개선은 요청 기준과 연결합니다. 가장 작은 일관된 변경을 하며 무관한 정리는 범위 밖에 둡니다.
3. 전후를 비교해 개선과 보존 조건을 확인하고 주변 내용·의존 부분을 검사합니다. 의도한 보존에서 벗어나야 했다면 필요한 이유를 설명합니다.

수정 결과나 허용된 검토, 중요한 변경, 비교 근거, 미해결 사항을 반환합니다. 달라졌다는 사실만으로 개선이 입증되지는 않습니다.
