# Vegabond Revise

Improve the existing result while preserving the intended constraints. Reuse the brief and task profile supplied by scout. If invoked directly, use [scout's shared setup](../vegabond-scout/SKILL.md#frame-and-classify) without rerouting, and follow the [agent instructions](../../agents/vegabond-agent.md) for document boundaries, verification, and acceptance.

## Refine the revision task

Apply the shared [information-needs judgment](../vegabond-scout/references/information-needs.md) to the actual change, preserved contract and affected dependents. Recheck whether initial questions missed a material condition; compare a prior incident's mechanism before transferring its correction.

Use [vegabond-knowledge](../vegabond-knowledge/SKILL.md) for relevant prior failures, preserved contracts, and correction checks, reusing scout's information brief. Return confirmed findings and before/after evidence for authorized record updates.

Use the shared profile and original context to distinguish defect repair from intentional improvement and identify affected dependencies. Apply the relevant specialist's revise, verification, and correction methods within the steps below, using [scout's shared mapping](../vegabond-scout/SKILL.md#connect-steps-to-skills-and-checks). Refine only missing revision details rather than repeating the shared assessment.

Distinguish analysis-only feedback from an authorized edit. If only findings are requested, return them without rewriting the source. Keep the established scope and scale; surface new dependencies when discovered.

## Revise

1. Establish the current-to-target gap and a meaningful comparison. Preserve access to the original state through existing history or a non-destructive comparison method where needed.
2. For a defect, reproduce it and trace its cause before repair. For editorial improvement, tie edits to the requested criteria. Make the smallest coherent change; keep unrelated polish outside scope.
3. Compare before and after for the intended improvement and preserved constraints. Inspect affected dependents or surrounding content, and explain any necessary departure from what was intended to remain intact.

Hand back the revised artifact or authorized findings, the meaningful changes, comparison evidence, and unresolved issues. A changed result is not by itself evidence of improvement.
