# 근거 기반 서사 설계 검수

서사 설계를 인계하거나 의존 장면을 집필하기 전에 적용합니다. 기존 요약이나 설계 결과물을 사용합니다. [설계 스킬](../SKILL.md)은 서사 선택을, [소설 맥락 조회](../../vegabond-fiction/SKILL.md#gather-the-relevant-story-context)는 출처 준비를, [원고 검수](../../vegabond-fiction/references/review.md)는 실제 문장의 평가·수정을 담당합니다. 다른 해석과 오류·가설·선호의 구분을 포함한 기존 [편집 판단 규칙](../../vegabond-fiction/references/review.md#judge-uncertain-findings)을 재사용하고 별도 점수 체계를 만들지 않습니다.

## 중요한 선택에 근거 연결

중요한 선택마다 **선택·의도한 효과 → 출처 구절과 적용 조건 → 뒷받침하는 해석 → 제안한 배치·변경 → 원고 점검 또는 미해결 질문**을 연결합니다. 같은 원인을 공유하는 요소는 묶습니다. 개연성 확인이라는 표기만 있는 행은 판단이 아닙니다. 짧게 인용하거나 출처·절·장면의 정확한 위치를 제시하고 작품 개정과 작품 시간을 보존합니다. 선택마다 모든 설정을 다시 읽지 말고 실제 의존성·충돌·중요한 빈틈이 있을 때만 확장합니다.

명시적 정본·저자 지시, 실제 원고가 보여 준 내용, 편집적 추론, 새 창작을 구별합니다. 진술을 사실로 보기 전에 출처 권위, 시점, 서술자 신뢰도를 확인합니다. 그럴듯한 요약, 뒤의 장, 여러 AI가 반복한 해석으로 앞선 근거의 부재를 채우지 않습니다. 원고가 없으면 제공된 제약을 제안의 근거로 삼고 미래 원고에서 확립할 사항을 표시합니다. 구절을 꾸며내거나 부재 자체를 모순으로 삼지 않습니다.

허용된 창작에 새 동기·사건·규칙이 필요하면 준비와 결과를 갖춘 임시 설계 선택으로 제시합니다. 원문에 이미 확립됐다고 표현하거나, 입증된 빈틈을 숨은 과거로 변호하거나, 선호한 줄거리를 살리려고 정본을 덮어쓰지 않습니다. 충돌하는 제약을 드러내고 어떤 의존 선택에 출처 조사나 저자 의도가 필요한지 밝힙니다. 무관한 자료의 부재가 독립 작업을 막지는 않으며 모든 창작을 일상적으로 승인받을 필요는 없습니다.

## 인과·공개 정보·요소 간 관계 검토

중요한 결정과 감정 전환을 인물의 목표, 사용 가능한 정보, 수단, 압력, 결과로 추적합니다. 이 작품에서 이 시점의 전환을 무엇이 뒷받침하며 텍스트가 지지하는 다른 해석은 무엇을 뜻하는지 묻습니다. 비합리적이거나 뜻을 굽히지 않는 인물 묘사와 논리 결함을 구별합니다. 동기나 반응이 제안에 불과하면 이미 설득력 있다고 선언하지 말고 확립할 장면·단서를 밝힙니다.

세계와 관련 인물 각각의 위치에서 중요한 사건 순서를 확인한 뒤 해당 시점의 독자 정보로 다시 봅니다. 지식 획득, 관계·상태 변화의 발효, 행동을 허용하는 능력·비용, 단서가 의미를 얻는 시점을 추적합니다. 편리한 해결, 근거 없는 감정 반전, 이른 공개, 접근 불가능한 단서에 기대는 회수를 검토합니다. 일반 경고 대신 문제를 드러내는 구체적인 순서나 구절을 제시합니다. 의도한 불확실성을 보존합니다. 미스터리는 답을 감출 수 있지만 현재 행동을 따라가는 데 필요한 연결은 제공할 수 있습니다.

선택한 요소들의 실제 상호작용을 살핍니다. 설명은 이해를 돕지만 긴장을 깨뜨릴 수 있고, 빠른 전환은 감정 준비를 잃게 하며, 새 반전은 규칙을 깨뜨리고, 정돈된 주제 결말은 의도한 열림을 지울 수 있습니다. 선택한 독자 효과와 근거 있는 절충을 설명합니다. 20개 칸을 채우려고 갈등·변화·설명·새로움·종결을 추가하지 않습니다. 모든 세부가 줄거리를 진전시켜야 하는 것은 아니며 리듬·분위기·모호함도 형식에 기여할 수 있습니다.

## 수정과 인계 검수

설명 문장을 추가하기 전에 가장 앞선 근거 있는 구조 원인을 고칩니다. 제안한 변경을 영향받는 장면, 인물 지식·관계, 시간, 복선·회수, 시점·목소리까지 추적합니다. 최종 설계의 선택과 정보 공개 순서를 맞추고 범위 안에서 출처·맥락 참조와 점검을 갱신하되 임시 상태와 미해결 출처 충돌을 보존합니다. 무효화된 결정만 재검토하며 작품 전체를 다시 시작하거나 효과 진단 없이 재작성을 계속하지 않습니다.

중요한 의도 효과마다 자기 점수 대신 독자에게 공개된 정보와 구체적인 장면 선택으로 실제 원고에서 확인할 내용을 밝힙니다. 작품 문체·저자 방향과 비교하고 판단을 제한하는 다른 해석이나 없는 장을 명시합니다. 변경에는 기존 발견 분류를 적용하며 선호는 확인된 결함이 아닙니다. 설계 검수는 논거를 뒷받침할 수 있지만 관련 독자 근거 없이 다수 독자의 개연성·만족도·독창성·여운을 입증하지 못합니다.

인계 전에 최종 설계를 인용한 출처와 보존 조건에 맞춰 읽습니다. 근거 있는 설계 결정, 임시 추가, 어떤 의존 집필을 막는 미해결 전제, 원고나 독자 피드백에서 확인할 효과를 구별합니다. 20개 표가 채워졌다고 점검 수행이 입증되지는 않습니다. 가능한 경우 한계가 드러난 유용한 범위 한정 제안을 반환하며 부분 개요로 작품 전체나 독자 검증을 주장하지 않습니다. 이는 문서 검수이며 문학적 품질이나 자동 강제의 입증이 아닙니다.
