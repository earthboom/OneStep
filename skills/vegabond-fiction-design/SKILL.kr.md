# Vegabond 소설 설계

호출한 작업 흐름 또는 [vegabond-fiction](../vegabond-fiction/SKILL.kr.md)에 필요한 서사 구조와 의도한 효과를 선택한다. 기존 요약·관련 출처·목소리 기준을 재사용한다. [에이전트 지침](../../agents/vegabond-agent.kr.md)을 따르며 설계가 다른 작업 흐름을 시작하거나 독자 합의를 확립하는 것은 아니다. 직접 호출되면 [scout의 공통 준비](../vegabond-scout/SKILL.kr.md)와 [소설 맥락 조회](../vegabond-fiction/SKILL.kr.md#관련-작품-맥락-조회)로 빠진 맥락을 채운다.

정본·저자 결정·임시 창작·인물의 믿음·미확인을 구별한다. 기존 출처와 [knowledge](../vegabond-knowledge/SKILL.kr.md)가 맥락과 저장을 담당하며 프로필이나 설정집을 복제하지 않고 연결한다. 설계 전용 요청은 원고를 요청 없이 고치는 대신 설계를 산출한다. 요청한 탐색 표본으로 방향을 시험할 수 있으나 창작 내용과 관찰 효과가 자동으로 정본이나 독자 근거가 되지는 않는다.

중요한 설계 선택을 확정하기 전에 작법 조사 안내 (`knowledge/fiction/K-FIC-CRAFT-GUIDE.kr.md`)와 [소설 스킬의 작법 선택 절차](../vegabond-fiction/SKILL.kr.md#저장된-작법-자료-적용)로 현재 결정에 필요한 참조를 knowledge에서 조회한다. 작업을 넘겨받았을 때뿐 아니라 직접 호출되어도 적용하며 유효한 조회는 재사용한다. 작품의 장르·분위기·인물·관계·장면 목적에 맞게 방법을 고르거나 조정한다. 참조 ID·적용 판단·계획한 원고 점검을 기존 요약·설계에 전달하고, 방법에 맞추려고 저자 제약을 바꾸기보다 맞지 않는 방법을 채택하지 않는다. 열두 작법 분야와 스무 설계 요소는 상호 보완적인 질문이며 두 개의 의무 체크리스트가 아니다.

## 서사 구성

공통 [정보 필요성 판단](../vegabond-scout/references/information-needs.kr.md)을 중요한 서사 선택, 이를 뒷받침하는 구절, 영향받는 공개에 적용한다. 국소 설계에 작품 전체 맥락을 강요하거나 작법 지침을 정본으로 승격하지 않으면서 빠뜨린 조건을 재확인한다.

1. 기존 요약에서 범위(작품·서사 단위·장면), 독자·장르·효과, 보존 조건을 확인한다. 결정할 선택과 중요한 빈틈을 식별하고 작업을 바꿀 미해결 의도만 확인한다. 유효한 설계 결정과 맥락은 재사용한다.
2. 작품 전체 설계에서는 아래 스무 요소를 검토한다. 서사 단위·장면·국소 수정에서는 기능과 실제 의존성에 영향이 있는 요소를 고른다. 중요한 유보나 없는 맥락은 답을 지어내지 않고 밝힌다. 스무 개의 의무 장치·점수·별도 스킬이 아닌 연결된 질문으로 쓴다. 정적인 인물, 조용한 장면, 우연, 모호함, 열린 결말도 의도일 수 있으며 변화·갈등·종결을 일률적으로 강요하지 않는다.
3. 목적 → 인물의 욕망·정보·압박 → 선택·사건 → 결과·변화 → 시점 인물과 독자가 아는 정보의 연결을 만든다. 이에 맞춰 장면·공개·배치·회수를 배열하고 명료성과 서스펜스, 속도와 감정 준비 같은 교환 조건을 식별한다. 결정에 영향을 줄 때만 대안을 비교하며 고정된 플롯 공식 대신 탐색 집필을 존중한다.
4. 설계를 반환하거나 의존 집필을 진행하기 전에 [근거 기반 설계 검수](references/review.kr.md)를 읽고 적용한다. 이 검수는 중요한 선택과 설정·원고의 연결, 인과·공개에 대한 반문, 요소의 교환 조건, 영향받는 수정을 담당한다. 스무 이름을 채운 것만으로 설계가 작동한다고 볼 수 없다. 근거를 지어내거나 저자 제약을 바꾸거나 의도한 미스터리를 일찍 풀지 않으면서 확인된 모순을 고치고 중요한 빈틈을 드러낸다.

## 스무 설계 요소

| 요소 | 의미 | 설계 질문 |
| --- | --- | --- |
| 개연성 | 주어진 상황에서 사건·행동이 일어날 법한 정도. | 독자가 여기서 왜 이런 일이 가능한지 이해할 수 있는가? |
| 핍진성 | 허구의 세계와 사람이 실제처럼 느껴지는 정도. | 이 세계 안에서 인물과 행동이 살아가는 사람처럼 느껴지는가? |
| 인과성 | 원인과 결과의 연결. | 앞선 사건과 선택이 다음 일을 어떻게 만드는가? |
| 일관성 | 설정·인물·규칙의 연속성. | 확립한 것을 조용히 모순시키지 않고 변화를 뒷받침하는가? |
| 인물 동기 | 행동의 이유와 욕망. | 왜 이 사람이 이것을 원하고 지금 이 행동을 택하는가? |
| 인물 깊이 | 기능적인 역할을 넘어서는 여러 면과 내적 긴장. | 무엇이 이 사람을 줄거리의 기능 이상으로 만드는가? |
| 인물 변화 | 경험과 선택이 사람에게 미치는 영향. | 생각·태도·관계가 무엇을 바꾸거나 의미 있게 바꾸지 않는가? |
| 갈등 | 목표에 맞서는 목적·압박·장애. | 무엇이 인물을 막으며 어떤 선택을 요구하는가? |
| 긴장 | 결과를 기다리게 하는 관심·우려·불확실성. | 성공·실패에 무엇이 걸려 있거나 어떤 답을 기다리게 하는가? |
| 구성 | 사건과 정보의 배열. | 의도한 효과를 위해 어떤 순서로 체험해야 하는가? |
| 배치와 회수 | 앞선 단서가 이후 결과나 의미를 얻음. | 중요한 해결과 전환이 적절하게 준비되었는가? |
| 속도와 완급 | 압박·휴식의 속도·압축·확대·교대. | 어디에 머물고 서두르며 조이고 풀어 주는가, 그 이유는 무엇인가? |
| 시점 통제 | 누구의 지각이 서술과 정보의 한계를 정하는가. | 각 공개가 시점과 서술 신뢰성에 맞는가? |
| 정보 전달 | 이해에 필요한 정보의 시기와 양. | 독자가 필요한 연결을 따라가며 의도한 질문은 열린 채 남는가? |
| 감정적 설득력 | 감정과 감정 전환을 뒷받침하는 근거. | 이 사람의 경험과 상황 중 무엇이 지금의 감정을 지지하는가? |
| 주제 | 사건과 선택으로 탐구하는 질문과 시각. | 강요한 해설 대신 어떤 질문이 이야기에서 나오는가? |
| 문체와 가독성 | 의도한 목소리의 고유한 표현과 이해 가능성. | 어휘·호흡·서사 거리가 선택한 효과를 어떻게 돕는가? |
| 독창성 | 익숙한 소재에 대한 작품 고유의 해석. | 억지 새로움 없이 사람·시각·조합에 무엇이 고유한가? |
| 결말 만족감 | 쌓인 기대에 응답하거나 의도적으로 다시 묻는 결말. | 의도한 열림까지 포함해 지금껏 쌓은 것에 맞는가? |
| 여운 | 읽은 뒤 남는 감정과 질문. | 무엇이 남아야 하며 어떤 선택이 이를 뒷받침하는가? |

## 설계 반환

결과를 구성하고 전달할 때 [독자가 이해하기 쉬운 설계 설명](../../agents/references/design-communication.kr.md)을 적용한다. 먼저 무슨 일이 일어나는지, 인물이 왜 선택하는지, 독자가 무엇을 알고 기다리는지 설명한다. 그다음 출처·장면 위치, 요소 판단, 교환 조건, 원고 점검을 그 선택에 연결한다. 독자가 장면을 이해하기 위해 스무 요소의 분석 전체를 먼저 공부해야 해서는 안 된다. 임시 추가를 밝히고 바뀐 결정은 영향받는 장면·인물·연표·공개에만 전파한다.

출처로 확인한 연속성 제약, 근거 있는 편집적 선택, 의도한 독자 효과를 구별한다. 설계는 효과의 근거를 마련할 수 있지만 실제 독자가 경험함을 입증하지 않는다. 제안한 만족감·독창성·여운은 측정 결과가 아니다. 원고에서 무엇을 봐야 하며 필수 주장에 어떤 독자 근거가 빠졌는지 밝힌다. 중요한 정본 사실이 없으면 그에 의존하는 집필만 차단하고 독립적인 설계는 계속할 수 있다. 호출한 흐름이 실제 원고를 집필·수정하고 [원고 검수](../vegabond-fiction/references/review.kr.md)를 적용하며 서사 선택이 달라질 때만 설계로 돌아온다. 설계를 완성한 것처럼 보이게 하려고 정본이나 저자 제약을 덮어쓰지 않는다.

## 2026-11-17 설계 단계의 자료 선택 보완

직접 호출과 집필 중 인계 모두 작법 안내와 집필 스킬의 자료 선택 절차를 사용합니다. 복합 자연어 요청을 중요한 결정별로 나누고 빠진 주제는 안내나 집중 검색어로 재탐색한 뒤 요구를 다뤘다고 판단합니다. 작법 안내는 학술 연구·한국어 표현·구절에 근거한 평가도 연결합니다. 필요한 결정에 맞춰 선택하고, 실제 적용 조건·자료 ID·예정 확인을 기존 설계에 전달합니다. 작법 주제와 스무 설계 요소는 보완적인 질문이며 두 개의 필수 점검표가 아닙니다.

## 장편 소설 전체 설계 — 2026-11-19 보강

장편 설계 국제 연구 (`knowledge/fiction/K-FIC-RESEARCH-AI-NOVEL-OUTLINE.kr.md`)에서 해당 작품의 결말 역설계, 서브플롯 교차, 인물과 세계 상태 갱신에 필요한 방법을 조회한다. 적용한 자료와 작품에 맞춘 선택, 본문과 독자 검토에서 확인할 점을 설계에 붙인다.

결말 또는 의도적으로 열어 둔 질문까지 시놉시스를 쓰고, 고유한 장 ID를 붙여 시점·선택·상태나 독자 정보의 변화를 기록한다. 주요 사건의 전제, 각 서브플롯이 다른 줄거리를 바꾸는 순간과 종결 또는 유보, 단서가 처음 보이고 해석되고 회수되는 위치를 확인한다. [설계 검토](references/review.kr.md)를 참조한다.


## 성격이 드러나는 선택을 설계하기

장면이 인물의 성향을 드러내거나 바꾸는 역할을 맡았다면 기존 작업 개요에 짧게 이어 적는다. 인물이 무엇을 알아차리거나 어떻게 짐작하는지, 무엇을 우선하는지, 무엇을 하거나 하지 않는지, 독자가 그 선택과 결과에서 무엇을 볼 수 있는지 적는다. 그럴듯한 선택지가 둘 이상 맞서면, 택한 방법으로 무엇을 지키고 어떤 대가를 치르는지 살핀다. 그 순간 인물이 실제로 아는 정보와 상대와의 관계를 바탕으로 판단한다.

차이가 중요하다면 같은 인물을 다른 상대나 압박에 놓아 보거나, 두 인물에게 같은 목표를 준다. 둘의 대응을 바꿔도 성립한다면 대사를 고치기 전에 각자가 무엇을 알아차리고 중시하며 어떤 위험을 감수하는지 살핀다. 후속 선택이 앞선 행동 양상에서 벗어나면 정보·압박·우선순위 가운데 무엇이 달라졌는지 살피고, 독자가 언제 앞선 선택과 연결할 수 있을지 정한다. 계획한 단서와 기대하는 해석은 [집필](../vegabond-fiction/SKILL.kr.md#장면에서-성격을-드러내기)에 넘긴다. 중요한 선택에는 [캐릭터 설계 연습과 근거](../../knowledge/fiction/K-FIC-CRAFT-CHARACTER.kr.md)를 활용한다.
