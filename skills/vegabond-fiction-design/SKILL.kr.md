# Vegabond Fiction Design

호출한 작업 스킬이나 [vegabond-fiction](../vegabond-fiction/SKILL.md)을 위해 서사 구성과 의도한 효과를 선택합니다. 기존 요약, 관련 출처, 문체 기준을 재사용합니다. [에이전트 지침](../../agents/vegabond-agent.md)을 따르며 설계는 별도 작업 흐름을 시작하거나 독자 합의를 입증하지 않습니다. 직접 호출되면 [scout의 공통 준비](../vegabond-scout/SKILL.md#frame-and-classify)와 [소설 맥락 조회](../vegabond-fiction/SKILL.md#gather-the-relevant-story-context)로 부족한 맥락만 채웁니다.

정본 설정, 저자 결정, 임시 창작, 인물의 믿음, 미확인을 구별합니다. 기존 출처와 [지식 스킬](../vegabond-knowledge/SKILL.md)이 맥락·저장을 담당하므로 프로필이나 작품 설정집을 복제하지 않고 연결합니다. 설계만 요청받았으면 요청하지 않은 원고 수정 대신 설계를 제공합니다. 요청된 탐색적 집필 예시로 방향을 확인할 수 있지만 그 창작과 관찰 효과가 자동으로 정본이나 독자 반응 근거가 되지는 않습니다.

## 서사 구성

1. 기존 요약에서 작품·에피소드·장면 범위, 의도한 독자·장르·효과, 보존 조건을 확인합니다. 확정할 선택과 중요한 맥락 부족을 식별하고 작업을 바꾸는 미해결 의도만 확인합니다. 유효한 설계 결정과 맥락은 재사용합니다.
2. 작품 전체 범위에서는 아래 20개 요소를 검토합니다. 에피소드·장면·국소 수정은 기능과 실제 의존성에 영향을 주는 요소를 선택하고 중요한 유보 항목이나 없는 맥락은 답을 만들어내지 말고 밝힙니다. 이들은 서로 연결된 질문이며 필수 장치 20개, 점수표, 별도 스킬이 아닙니다. 변하지 않는 인물, 조용한 장면, 우연, 모호함, 열린 결말은 의도일 수 있으므로 모든 곳에 변화·갈등·종결을 강제하지 말고 작품에 맞춰 이유를 설명합니다.
3. 관련 선택을 목적 → 인물의 욕망·정보·압력 → 선택·사건 → 결과·변화 → 시점 인물과 독자에게 주어진 정보로 연결합니다. 이에 따라 장면, 공개 정보, 복선·회수를 배치합니다. 명료함과 서스펜스, 속도와 감정 준비 같은 중요한 절충을 밝힙니다. 결정에 영향을 줄 때만 대안을 비교하고 고정 플롯 공식 대신 탐색적 집필을 존중합니다.
4. 설계를 반환하거나 의존 집필을 진행하기 전에 [근거 기반 설계 검수](references/review.md)를 읽고 적용합니다. 중요한 선택과 설정·원고 구절의 연결, 인과·공개 정보의 반박 검토, 요소 간 절충, 영향받는 수정은 이 검수가 담당합니다. 20개 요소의 이름은 질문이며 설계가 작동한다는 증거가 아닙니다. 근거를 꾸며내거나 저자 제약을 바꾸거나 미스터리를 미리 풀지 말고, 검수를 통해 근거 있는 모순을 고치고 중요한 빈틈을 밝힙니다.

## 설계 요소 20개

| 요소 | 의미 | 설계 질문 |
| --- | --- | --- |
| 개연성 | 주어진 상황에서 사건이나 행동이 일어날 법한 정도. | 왜 여기서 이런 일이 일어날 수 있는지 독자가 이해할 수 있는가? |
| 핍진성 | 허구의 세계와 사람이 실제처럼 느껴지는 정도. | 이 세계의 인물과 행동이 그곳에서 살아온 것처럼 느껴지는가? |
| 인과성 | 원인과 결과의 연결. | 앞선 사건과 선택이 뒤의 일을 어떻게 만들어 내는가? |
| 일관성 | 확정된 설정·인물·규칙의 연속성. | 변화에 근거가 있으며 앞서 확정한 내용을 조용히 뒤집지 않는가? |
| 인물의 동기 | 행동의 이유와 욕구. | 왜 이 사람은 이것을 원하며 지금 이 행동을 선택하는가? |
| 인물의 입체성 | 기능적인 역할을 넘는 여러 면과 내적 긴장. | 단순한 줄거리 장치 이상의 사람으로 보이게 하는 것은 무엇인가? |
| 인물의 변화 | 경험과 선택이 인물에게 남기는 영향. | 생각·태도·관계의 무엇이 바뀌거나 의미 있게 변화를 거부하는가? |
| 갈등 | 목표에 맞서는 충돌하는 의도·압력·장애물. | 무엇이 가로막으며 어떤 선택을 요구하는가? |
| 긴장감 | 결과에 대한 관심·걱정·불확실성. | 성공과 실패에 무엇이 걸려 있거나 어떤 답을 기다리게 하는가? |
| 구성 | 사건과 정보의 배치. | 의도한 효과를 위해 어떤 순서로 이야기를 경험하게 할 것인가? |
| 복선과 회수 | 앞선 단서가 뒤에서 결과나 의미를 갖는 연결. | 중요한 해결이나 전환에 적절한 준비가 있는가? |
| 전개 속도와 완급 | 진행 속도, 압축·확장, 압박·휴식의 조절. | 어디서 머물고 서두르며 조이거나 풀어 주고, 그 이유는 무엇인가? |
| 시점의 통제 | 누구의 지각으로 서술하고 어디까지 알 수 있는지의 관리. | 공개되는 정보가 시점과 서술자의 신뢰도에 맞는가? |
| 정보 전달 | 이해에 필요한 정보의 시기와 양. | 의도한 질문을 남기면서 독자가 지금 필요한 연결을 따라갈 수 있는가? |
| 감정의 설득력 | 감정과 그 전환을 뒷받침하는 근거. | 이 사람의 경험과 상황에서 지금 이 감정을 뒷받침하는 것은 무엇인가? |
| 주제 의식 | 작품이 탐구하는 질문이나 관점. | 설명을 강요하지 않고 사건과 선택을 통해 어떤 질문이 드러나는가? |
| 문체와 가독성 | 의도한 목소리 안의 개성 있는 표현과 이해 가능성. | 어휘·리듬·서술 거리가 선택한 효과에 어떻게 기여하는가? |
| 독창성 | 익숙한 소재에서도 드러나는 작품 고유의 해석. | 억지 새로움 없이 인물·관점·조합의 무엇이 고유한가? |
| 결말의 만족도 | 축적한 기대에 답하거나 의도적으로 재구성하는 방식. | 의도한 열린 결말까지 포함하여 앞선 이야기에 어울리는가? |
| 여운 | 읽고 난 뒤 남는 감정이나 질문. | 독자에게 무엇이 남기를 바라며 어떤 선택이 이를 뒷받침하는가? |

## 설계 반환

선택한 내용, 출처·장면 위치, 장면·사건 또는 정보 공개 순서, 이유·절충, 원고 점검 계획, 미해결 의존성을 기존 요약이나 요청된 결과물에 둡니다. 고정 양식, 새 파일, 일상적인 승인 단계는 필수가 아닙니다. 임시 추가 사항을 명시하고 바뀐 결정은 영향받는 장면·인물·시간 순서·공개 정보에만 전파합니다.

출처로 확인한 연속성 제약, 근거를 갖춘 편집 선택, 의도한 독자 효과를 구별합니다. 설계는 효과를 뒷받침할 수 있지만 실제 독자가 경험한다고 입증하지는 않습니다. 제안한 만족도·독창성·여운은 측정 결과가 아닙니다. 집필자가 실제 원고에서 확인할 내용과 필수 주장에 부족한 독자 근거를 밝힙니다. 중요한 정본 사실이 없으면 그 사실에 의존하는 집필만 막고 독립적인 설계는 계속할 수 있습니다. 호출한 스킬이 집필·수정하고 실제 원고에 [원고 검수](../vegabond-fiction/references/review.md)를 적용하며 서사 선택이 바뀔 때만 여기로 돌아옵니다. 확정 정본을 덮어쓰거나 설계가 끝난 것처럼 보이도록 저자의 제약을 약화하지 않습니다.
