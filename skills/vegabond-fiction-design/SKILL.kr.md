# Vegabond Fiction Design

호출한 작업이나 [소설 스킬](../vegabond-fiction/SKILL.kr.md)을 위해 이야기 구조·의도한 효과를 선택합니다. 기존 요약·원본·목소리 기준과 [에이전트 지침](../../agents/vegabond-agent.kr.md)을 따릅니다. 새 작업 흐름이나 독자 합의를 만들어내지 않습니다. 직접 호출되면 [정찰 공통 설정](../vegabond-scout/SKILL.kr.md)과 [소설 맥락 조회](../vegabond-fiction/SKILL.kr.md)로 부족한 부분만 채웁니다.

설정·저자 결정·잠정 창작·인물 믿음·미확인을 구분합니다. 기존 원본과 [지식 스킬](../vegabond-knowledge/SKILL.kr.md)이 맥락·저장을 담당하며 프로필·설정집을 복제하지 않습니다. 설계 전용 요청에는 원고를 덧붙이지 않습니다. 요청된 탐색 샘플로 방향을 시험할 수 있지만 그 창작·관찰 효과가 자동으로 설정·독자 근거가 되지는 않습니다.

## 이야기 구성

[필요한 정보의 공통 판단](../vegabond-scout/references/information-needs.kr.md)을 중요한 선택·근거 구간·영향 공개에 적용합니다. 로컬 설계에 작품 전체 맥락을 강요하거나 작법 조언을 설정으로 승격하지 않고 빠진 조건을 확인합니다.

1. 작품·이야기 줄기·장면 범위, 독자·장르·효과, 보존 조건을 기존 요약에 연결합니다. 정할 선택과 중요한 공백을 식별하고 작업을 바꾸는 의도만 확인합니다. 유효한 설계·맥락을 재사용합니다.
2. 작품 전체는 아래 20요소를 고려하되 줄기·장면·로컬 수정은 기능·실제 의존성에 관련된 것만 선택합니다. 중요한 보류·접근 불가 맥락을 표시하고 답을 만들지 않습니다. 요소는 연결 질문이며 20개 장치·점수·스킬이 아닙니다. 정적인 인물·조용한 장면·우연·모호함·열린 결말도 의도적일 수 있습니다. 모든 곳에 변화·갈등·결말을 강요하지 않습니다.
3. 목적→인물 욕망·정보·압력→선택·사건→결과·변화→시점 인물과 독자가 아는 내용을 연결합니다. 장면·공개·복선과 회수를 배치하고 명확성 대 긴장, 속도 대 감정 준비 같은 상충을 식별합니다. 결정에 영향이 있을 때만 대안을 비교하며 탐색 집필을 존중하고 줄거리 공식을 강요하지 않습니다.
4. 반환·의존 집필 전에 [근거 기반 설계 검토](references/review.kr.md)를 적용합니다. 중요한 선택과 설정·원문, 인과·공개 반례, 요소 상충·변경 영향을 추적합니다. 요소 이름이 설계 성공의 증거는 아닙니다. 근거 있는 모순을 고치고 중요한 공백을 드러내되 근거·설정·제약을 꾸미거나 의도한 미스터리를 미리 풀지 않습니다.

## 설계 20요소

| 요소 | 의미 | 설계 질문 |
| --- | --- | --- |
| 개연성 | 상황 안에서 사건·행동이 가능한 정도. | 독자가 여기서 왜 가능한지 이해하는가? |
| 핍진성 | 세계와 인물이 실제로 살아 있는 느낌. | 이 세계에서 사람과 행동이 살아 있는가? |
| 인과성 | 원인과 결과의 연결. | 앞선 선택·사건이 이후를 어떻게 만드는가? |
| 일관성 | 설정·인물·규칙의 연속성. | 변화에 근거가 있고 조용한 모순이 없는가? |
| 인물 동기 | 행동의 이유·욕망. | 왜 지금 이것을 원하고 선택하는가? |
| 인물 깊이 | 기능적 역할 이상의 여러 면과 내적 긴장. | 줄거리 기능 이상의 인물인가? |
| 인물 변화 | 경험·선택이 인물에 주는 영향. | 생각·태도·관계에서 무엇이 변하거나 의미 있게 버티는가? |
| 갈등 | 충돌 목표·압력·장애. | 무엇이 막으며 어떤 선택을 요구하는가? |
| 긴장감 | 결과에 대한 관심·걱정·불확실성. | 성공·실패에 무엇이 걸리거나 어떤 답을 기다리게 하는가? |
| 구성 | 사건·정보의 배치. | 원하는 효과를 위해 어떤 순서로 경험하는가? |
| 복선과 회수 | 앞선 단서가 이후 결과·의미를 얻음. | 중요한 해결·전환이 적절히 준비됐는가? |
| 속도와 완급 | 압축·확장·압력과 휴식의 교대. | 어디서 머물고 서두르고 조이고 풀며 왜 그런가? |
| 시점 통제 | 지각 주체와 정보 한계. | 공개가 시점·화자 신뢰도와 맞는가? |
| 정보 전달 | 이해에 필요한 정보량과 시점. | 필요한 연결을 이해하면서 의도한 질문은 열려 있는가? |
| 감정 설득력 | 감정·전환의 뒷받침. | 경험·상황이 지금 감정을 지지하는가? |
| 주제 | 작품이 탐구하는 질문·관점. | 강제 설명보다 사건·선택에서 어떤 질문이 드러나는가? |
| 문체와 가독성 | 의도한 목소리의 표현·명료성. | 어휘·리듬·거리감이 효과에 어떻게 기여하는가? |
| 독창성 | 익숙한 소재도 작품만의 해석을 가짐. | 억지 새로움 없이 인물·관점·조합이 무엇이 다른가? |
| 결말 만족감 | 축적 기대를 답하거나 의도적으로 재구성함. | 열린 결말을 포함해 쌓아온 내용에 맞는가? |
| 여운 | 독후에 남는 감정·질문. | 무엇이 남기를 바라며 어떤 선택이 돕는가? |

## 설계 반환

[독자 중심 설계 전달](../../agents/references/design-communication.kr.md)을 따릅니다. 무슨 일이 왜 일어나고 인물이 왜 선택하며 독자는 무엇을 알거나 기다리는지 먼저 설명합니다. 이후 원본·장면 위치, 요소 판단·상충·원고 점검을 연결합니다. 장면을 이해하려고 20요소 분석 전체를 공부하게 만들지 않습니다. 잠정 추가를 명시하고 영향 장면·인물·연표·공개에만 변경을 전파합니다.

원본 확인 연속성 제약·근거 있는 편집 선택·의도한 독자 효과를 구분합니다. 효과를 지지하는 설계가 실제 독자 체험의 증명은 아니며 만족감·독창성·여운 제안은 측정 성과가 아닙니다. 원고에서 확인할 것과 필요한 독자 근거의 공백을 명시합니다. 중요한 설정 누락은 의존 집필만 막고 독립 설계는 계속할 수 있습니다. 호출자가 실제 원고를 집필·수정하고 [원고 검토](../vegabond-fiction/references/review.kr.md)를 적용하며 연결 선택이 바뀔 때만 돌아옵니다. 설계를 완성된 것처럼 보이게 하려고 설정·저자 제약을 덮거나 약화하지 않습니다.
