# Vegabond 조사

요청한 범위 안에서 근거를 갖춘 답변을 제공합니다. Scout가 전달한 작업 개요와 프로필을 재사용합니다. 직접 호출된 경우에는 분류를 다시 시작하지 않고 [Scout의 공통 준비](../vegabond-scout/SKILL.md#frame-and-classify)를 사용합니다. 문서 경계, 검증, 인수 기준은 [에이전트 지침](../../agents/vegabond-agent.md)을 따릅니다.

## 조사 질문 구체화

[공통 정보 필요성 판단](../vegabond-scout/references/information-needs.md)을 사용해 조사 질문이 실제 결정과 관련 반증을 다루는지 확인합니다. 출처의 적용 범위와 남은 공백을 전달합니다. 서로 일치하는 요약문이나 성공한 검색만으로 독립된 증거나 전체 범위의 확인을 주장하지 않습니다.

[지식 스킬](../vegabond-knowledge/SKILL.md)을 통해 기존 출처, 주장과 알려진 공백을 확인하고 Scout의 정보 개요를 재사용합니다. 해당 질문과 현재 근거에 비추어 다시 판단합니다. 읽기 전용 작업에서는 조사 결과와 함께 지식 갱신안을 전달합니다.

공유 프로필로 결정할 문제와 비교 기준을 좁힙니다. [Scout의 공통 매핑](../vegabond-scout/SKILL.md#connect-steps-to-skills-and-checks)을 통해 관련 전문 스킬의 조사 방법과 주장별 검사를 적용합니다. 근거가 부족하면 추론과 답을 바로잡습니다. 조사 대상 원문은 보존합니다. 사용자가 제공한 자료와 외부 근거를 이용할 수 있으며, 웹 검색은 질문에 따라 선택합니다. 공통 평가를 되풀이하지 말고 부족한 조사 맥락만 채웁니다.

다른 작업을 지원하는 조사라면 요청한 단계의 질문에 답합니다. 제작이나 수정 전체를 넘겨받지 않습니다. 답변이나 보고서를 요청한 것이 조사 대상의 구현을 바꿀 권한을 뜻하지는 않습니다.

지식 조회에서 답을 찾지 못해 넘어온 질문은 이미 확인한 공백과 조건을 그대로 사용합니다. 같은 조회로 되돌리지 않습니다. 결정에 필요한 개념과 전제부터 조사하고 근거를 검토하다 중요한 의존성이 드러난 경우에 범위를 넓힙니다.

## 조사 수행

1. 결정을 내리는 데 답이 필요한 하위 질문이나 비교 기준을 정하고 범위를 한정합니다.
2. 이용 가능한 1차 자료의 날짜, 버전과 적용 조건을 확인합니다. 중요한 결론은 근거와 연결하고, 상충하는 근거와 추론을 구분합니다. 필요한 자료에 접근할 수 없다면 그 한계를 남깁니다.
3. 기준에 따라 답이나 권고안을 종합합니다. 각 질문에 근거가 있거나 남은 공백이 명확하면 마칩니다. 추가 조사가 결론을 바꿀 수 있을 때 더 찾습니다. 해결되지 않은 인수 조건은 미검증 상태로 전달합니다.

답변 또는 요청받은 보고서와 함께 출처, 판단 이유, 중요한 불확실성을 전달합니다. 근거로 확인한 결론과 가정 또는 추가 확인이 필요한 결론을 구분합니다.

재사용할 조사 결과를 저장할 때는 [지식 통합 절차](../vegabond-knowledge/references/storage.md#capture-consolidate-and-promote)로 바로 보냅니다. 다음 작업에서 같은 질문에 답할 항목이 있으면 보강하고, 독립된 결정을 지원하는 내용이면 새 항목으로 저장합니다. 지침에 출처 링크, 적용 조건과 근거의 한계를 함께 둡니다. 일회성 질문은 대화에서 답변으로 마쳐도 됩니다.

`docs/research/`는 보고서 자체를 요청받았거나 별도 자료가 구체적인 용도에 쓰일 때 사용합니다. 예를 들어 원시 기준값으로 벤치마크를 재현하거나, 상충하는 출처를 비교해 결정을 내린 과정을 다시 확인해야 할 때입니다. 관련된 지식 항목이 있다면 거기에서 근거 파일로 연결합니다. 원자료는 원래 형식으로 보존합니다. 이 폴더에 남기는 보고서는 영문 원본과 사람용 한국어 번역 `<stem>.kr.md`를 함께 제공하고, AI용 문서에서는 영문 경로를 인용합니다. 번역문을 열지 않고 파일 쌍의 존재를 확인합니다.

지식 공백을 채워 인계할 때는 원문이 뒷받침하는 내용, 호출 측에서 환경이나 결과물로 확인해야 할 내용, 재사용 후보와 적용 조건을 밝힙니다. 호출한 단계와 [지식 공백 처리 흐름](../vegabond-knowledge/SKILL.md#close-a-knowledge-gap)에 전달합니다. 전문 스킬은 실제 적용을 검증하고 지식 스킬은 기존 쓰기 권한 안에서 필요한 내용만 저장합니다. 자료를 조사한 사실만으로 실행 결과를 인증하거나 매번 새 항목을 만들 필요는 없습니다.
