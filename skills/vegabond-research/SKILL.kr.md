# Vegabond Research

요청된 범위에서 근거에 기반한 답변을 제공합니다. scout가 전달한 작업 요약과 프로필을 재사용합니다. 직접 호출되었으면 [scout의 공통 준비 절차](../vegabond-scout/SKILL.md#frame-and-classify)로 필요한 정보를 채우되 다시 라우팅하지 않습니다. 문서 경계, 검증, 수락은 [에이전트 지침](../../agents/vegabond-agent.md)을 따릅니다.

## 조사 질문 구체화

[vegabond-knowledge](../vegabond-knowledge/SKILL.md)에서 기존 출처, 주장, 알려진 빈틈을 확인하며 scout의 정보 요약을 재사용합니다. 질문과 현재 근거에 맞는지 확인합니다. 읽기 전용 작업에서는 저장소를 바꾸지 말고 발견 사항과 함께 지식 갱신안을 반환합니다.

공통 프로필을 활용하여 질문이나 결정, 비교 기준을 구체화합니다. [scout의 공통 연결 절차](../vegabond-scout/SKILL.md#connect-steps-to-skills-and-checks)를 통해 관련 전문 스킬의 조사 방법과 주장별 점검을 적용합니다. 근거가 부족한 추론이나 답변을 수정하며 조사 대상 원출처는 수정하지 않습니다. 출처는 제공된 자료 또는 외부 근거일 수 있으며 웹 검색이 항상 필요한 것은 아닙니다. 공통 평가를 반복하지 않고 부족한 조사 정보만 구체화합니다.

다른 작업을 지원하는 조사라면 생성·수정 작업 전체를 맡지 말고 호출한 단계의 질문에 답합니다. 조사 대상 출처는 유지합니다. 요청된 답변이나 보고서를 만든다고 구현 변경 권한이 생기지는 않습니다.

지식 검색에서 미해결 질문을 전달받았다면 그 빈틈과 조건을 바로 사용하고 같은 검색으로 다시 보내지 않습니다. 판단에 필요한 개념과 선행 지식만 조사하며 근거에서 중요한 의존성이 드러날 때 범위를 넓힙니다.

## 조사

1. 질문을 답할 수 있는 하위 질문이나 비교 기준으로 나눕니다. 요청된 답변이나 결정에 필요한 범위로 조사를 제한합니다.
2. 가능한 경우 일차 출처를 살펴보고 날짜, 버전, 적용 조건을 확인합니다. 중요한 결론을 근거에 연결하고 모순을 다루며 뒷받침된 사실과 추론을 구별합니다. 구할 수 없는 근거는 한계로 남깁니다.
3. 기준에 따라 답변이나 권고를 취합합니다. 질문이 근거로 뒷받침되거나 남은 근거 부족이 명시되면 조사를 마칩니다. 결론을 실질적으로 바꿀 가능성이 있을 때만 추가 검색합니다. 미해결 완료 조건을 검증된 것으로 표현하지 않습니다.

답변 또는 요청된 보고서, 뒷받침하는 출처 참조, 논거, 중요한 불확실성을 반환합니다. 어떤 결론이 확인되었고 어떤 결론이 가정이나 부족한 근거에 의존하는지 밝힙니다.

지식 부족을 해소하는 조사에서는 출처가 입증하는 내용, 호출한 스킬이 자기 환경이나 결과물에서 점검해야 할 내용, 재사용 후보와 조건을 밝힙니다. 이를 호출한 단계와 [지식의 빈틈 해소 절차](../vegabond-knowledge/SKILL.md#close-a-knowledge-gap)에 반환합니다. 전문 스킬이 적용 결과를 검증하고 지식 스킬이 기존 쓰기 범위 안에서 선별 저장을 담당합니다. 조사만으로 실행이 인증되거나 새 항목 저장이 의무가 되지는 않습니다.
