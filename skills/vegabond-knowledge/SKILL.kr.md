# Vegabond Knowledge

진행 중인 작업에 필요한 지식과 문제 기록을 조회하고 관리합니다. 정찰 스킬의 작업 프로필을 재사용하며, 호출한 작업·전문 스킬이 적용 가능성을 판단하고 실제 결과를 검증합니다. [에이전트 지침](../../agents/vegabond-agent.kr.md)의 문서 경계와 완료 조건을 따릅니다. 이 스킬은 정보를 공급하며 제작·수정·조사를 대신하거나 다른 에이전트를 생성하지 않습니다.

## 요청과 반환

[필요한 정보의 공통 판단](../vegabond-scout/references/information-needs.kr.md)에 따라 질문을 뒷받침할 결정과 연결하고 조회 중 발견한 전제 누락을 드러냅니다. 후보 근거와 한계를 반환하며, 사용하는 전문 스킬이 중요한 채택·조건부 사용·제외·보류를 기록하고 행동을 검증합니다. 검색 포함 정도는 필요한 정보의 완전성 판단이 아닙니다.

요청에는 작업 프로젝트, 질문, 관련 분야, 대상과 제약, 필요한 환경·버전·이야기 맥락을 포함합니다. 기존 작업 요약을 재사용합니다. 저장 요청에는 발견 사항, 근거, 해결 결과, 재사용할 점검, 재사용 조건과 실제 검증 맥락도 제공합니다.

간결한 정보 요약을 반환합니다.

- 적용할 지식: 중요한 주장마다 출처 ID와 경로·링크를 제시합니다.
- 조건과 예외: 적용 범위, 과거 사건과의 일치 이유, 원인 확신도·검증 맥락, 현재 요청·원본과의 충돌을 밝힙니다.
- 점검: 구체적 예방·수용 점검에 원래 기록 ID, 예방 상태와 근거를 연결합니다. 사건 해결만으로 예방이 검증되지는 않습니다.
- 공백: 누락·오래됨·충돌·미확인 정보와 남은 질문을 밝힙니다.

## 찾고 취합하기

1. 질문·범위·조회 내용·원본이 유효한 동안 기존 정보 요약을 재사용합니다. 달라지거나 새 근거가 공백을 드러낼 때 다시 검색합니다. 필요한 경우 작업 근거에 조회 ID와 버전·해시를 남기되 프로젝트 사실의 전역 캐시를 만들지 않습니다.
2. 작업 프로젝트의 저장소부터 사용합니다. 이 저장소의 기본 경로는 [지식](../../knowledge/index.kr.md)과 [문제 기록](../../records/index.kr.md)입니다. 다른 프로젝트에서는 그 프로젝트 경로와 적합한 기존 시스템을 사용합니다. OneStep의 공유 자료는 명시적으로 설정되거나 요청된 경우의 추가 출처이며 무관한 프로젝트는 검색하지 않습니다.
3. 프로필에 맞는 분야를 선택하고 복합 작업은 분야를 조합합니다. [검색 도구와 취합 절차](references/retrieval.kr.md)로 질문·식별자·범위·맥락·상태에 따라 두 저장소를 검색하고, 짧은 일치 이유와 본문 위치를 받습니다. 도구는 관리되는 한영 동의어를 확장하고 `*.kr.md`를 제외합니다. 엄격한 읽기 전용 작업은 `--no-cache`를 사용합니다. 도구를 쓸 수 없거나 기존 시스템이 더 적합하면 같은 조건으로 영문 정본 목록·본문을 제한 검색하고 기능 공백을 보고합니다. 최신성보다 적용 가능성을 우선하고, 실제로 관련된 공통 질문에만 shared를 조회합니다.

   작업 전에는 증상을 몰라도 계획한 행동과 조건으로 문제 기록의 `trigger`를 검색합니다. 실패 뒤에는 `symptom`과 정확한 식별자를 검색하고 조건·원인 근거를 비교합니다. 해결된 사건도 후보에 남깁니다. 알려진 비호환 범위는 제외하되 호환 여부가 불명확하면 주의사항으로 유지합니다. 증상 일치가 원인 일치를 입증하지는 않습니다. 발생 조건 부재는 조회 공백입니다. 어휘 검색 순위는 적용 가능성이나 근거의 품질을 입증하지 않습니다.

4. 선택한 저장소를 합쳐 관련 상세 문서 최대 3개부터 시작하고 헤더와 필요한 절을 먼저 읽습니다. 적용 조건을 확인하고 필요한 원본 근거를 따릅니다. 요약은 증명이 아닙니다. 출처 사실·확인된 수정·저자 및 프로젝트 선택·편집 판단·가설을 구분합니다. 열린 사건은 위험, 예전 목록과 미기록 원인·예방 정보는 미검증 상태입니다. 제안된 점검을 검증된 예방책으로 표현하지 않으며 무효화된 점검은 다시 조사합니다. 폐기되거나 버전이 맞지 않는 항목을 조용히 적용하지 않습니다. 목록이 없거나 오래되었음이 확인되면 해당 분야의 메타데이터를 표적 조회하고 공백을 보고합니다. 갱신은 허용된 쓰기 범위에서만 합니다.
5. 중요한 답변마다 ID·원본 근거·조건·점검을 연결해 위 정보 요약으로 취합합니다. 관련된 양방향 관계와 본문 링크를 따라가며 불일치를 유지하고, 결론에 의존하기 전에 잘린 충돌·대체 후보를 확인합니다. 큰 질문은 하위 질문마다 답변됨·조건부·충돌·누락으로 마감합니다. 미답 질문·의존 관계·충돌·실패에 따라 조회를 확장하며 최초 문서 수는 완료 한도가 아닙니다. 유용한 결과가 없으면 대체 표현이나 가까운 범위를 한 번 시도한 뒤 공백을 보고합니다. 검색 실패로 부재를 추론하지 않습니다. 추가 조사는 진행 중인 작업의 조사 단계에 전달합니다.

등록된 `SRC-...` 원본이 필요한 주장에는 [이식 가능한 출처 절차](references/storage.kr.md)를 적용합니다. 필요한 ID만 허용 범위에서 확인하고 ID·구간·내용 동일성 및 접근 결과·공백을 반환합니다. 목록 링크만으로 원본이 검증되지는 않습니다. 조회 중 로컬 설정이나 역사적 근거를 바꾸지 않습니다.

## 지식 공백 메우기

빈 저장소나 불충분한 일치는 정상적인 출발점입니다. 현재 결정에 필요한 최소 질문과 조건·필요 근거로 정리해 진행 중인 작업의 [조사 단계](../vegabond-research/SKILL.kr.md)에 전달합니다. 기존 요약을 재사용하고 정찰이나 동일 조회를 다시 시작하지 않습니다. 모델 기억은 검색어를 제안할 수 있지만 확인된 출처 근거는 아닙니다.

결과를 출처로 뒷받침되는 주장, 실제 작업에서 확인한 방법, 추론·미해결 질문으로 나누어 요약에 반영합니다. 출처 기반 참고 지식은 구현을 기다리지 않고 저장할 수 있지만 출처 확인이 로컬 실행의 증거는 아닙니다. 호출한 전문 스킬이 실제 결과에 적용·검증하고 근거·예외를 반환합니다. 필수 근거가 빠졌다면 공통 규칙에 따라 의존 작업을 진행하지 않습니다.

저장 전에는 다시 찾을 가치가 있는 결정·비용 큰 조사·제약·점검을 선택합니다. 문제 없는 성공 방법도 포함할 수 있습니다. 다른 작업의 일치 조건에서 유용하면 재사용할 수 있으며 보편적으로 유효할 필요는 없습니다. 하나의 독립적 질문에 답하는 항목을 선호하고 필요한 선행 조건만 연결합니다. 모든 용어나 보고서를 복제하지 않고 저장 지침의 통합 기준을 따릅니다. 근거 없는 후보는 작업 결과에 남기되 추적이 필요한 가설은 범위를 한정해 기록합니다. 읽기 전용 작업은 저장 제안만 반환합니다. 출처 확인과 실제 작업 검증을 Evidence에서 구분합니다.

다음 관련 작업에서도 질문·조건에 따라 조회하고 적용 가능성을 확인해 구체적 행동·점검에 반영합니다. 기존 작업 근거에 ID·해시·결정·공백·잘못된 일치를 기록합니다. 확인된 누락이나 부적합 결과를 근거로 요약·동의어·범위·경로를 개선하고 [검색 평가 사례](tests/retrieval_cases.json)를 확장합니다. 전역 사용 장부를 만들거나 매 작업 뒤 전체 저장소를 다시 읽지 않습니다. 목록 검증만으로 검색 유용성이 입증되지는 않습니다.

## 저장과 유지보수

항목을 쓰거나 재구성할 때 [저장 및 수명주기](references/storage.kr.md)를 읽습니다. 먼저 포착·통합 기준으로 재사용할 내용, 기존 항목에 합칠 내용, 원본·작업 이력에 남길 내용을 구분합니다. 이 문서가 형식·근거·중복 제거·승격·폐기와 목록 생성·검사 절차의 단일 기준입니다. 일상 조회마다 전체 목록을 다시 만들거나 검사하지 않습니다.

허용된 범위에서만 기록합니다. 읽기 전용·검토 전용 작업은 저장소 수정 대신 제안 항목을 반환합니다. 저장이 허용되면 정본과 사람용 번역을 갱신하고, 영향을 받는 목록을 생성하고, 변경된 영문 목록의 번역을 재작성한 뒤 검사합니다. 새 분야는 최상위 경로에도 반영합니다. 생성된 행을 직접 고치거나 과거 메타데이터를 추정하지 않습니다. 조회만을 위해 빈 저장소나 가짜 초기 지식을 만들지 않습니다.
