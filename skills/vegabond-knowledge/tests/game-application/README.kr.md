# 게임 요청에서 적용 판단까지의 평가

게임 근거 활용 규칙과 이를 사용하는 스킬을 검사한다. 공통 평가 방법에 게임별 입력 자료를 추가했다. 사례는 합성이며 실제 게임 사건이나 엔진 실행이 아니다.

## 독립 실행

실행 전에 사례·평가 기준과 영문 지침·지식의 해시를 고정한다. 각 요청과 첨부 자료를 Git에서 제외되는 개별 실행 폴더에 둔다. 해당 자료가 사례의 프로젝트 사실이며 OneStep 지식·문제 기록은 허가된 참고 자료다. 사람용 번역은 입력으로 복사하거나 읽지 않는다.

새 수행자에게 자기 사례 폴더·스킬·공통 영문 지침·저장소 위치만 준다. 검색어는 요청·자료에서 도출한다. 평가 기준·기대 ID·다른 사례·이전 결론·기존 예행 답안은 공개하지 않는다. 사례마다 독립 맥락을 사용한다. 외부 서비스·엔진 실행·제품 변경 없이 해당 사례의 답변·추적 기록만 쓴다.

요청한 범위의 답변과 실제 검색어·반환 ID, 읽은 절, 결정에 중요한 질문, 채택·조건부·기각, 남은 공백, 예정·실행 검사를 남긴다. 오탈자 수정에 긴 조사를 강요하지 않는다.

## 의미 평가와 보완

실행 후 실제 답변·근거·조회 기록을 고정한 평가 기준과 비교한다. 근거가 행동을 적절히 바꿨는지, 중요한 조건을 다뤘는지, 매력적이지만 틀린 처방을 기각했는지 판단한다. 기대 ID 인용만으로 통과하지 않는다. 동등하게 타당한 근거·검색 경로도 인정하며 검색 실패·적용 판단 실패·불필요 조회를 나눠 기록한다.

누락 질문·잘못된 전이·과신·범위 초과·한계·구체적 행동을 사례별로 남긴다. 답변에 맞추려고 기준을 완화하지 않는다. 필수 보장이 없으면 그에 의존한 확정만 조건부로 두고 가능한 독립 분석은 완료한다.

실제로 드러난 부족한 점만 고친다. 같은 입력·기준으로 영향을 받은 사례를 새 맥락에서 다시 실행한다. 답을 공개한 뒤의 반복은 블라인드 평가가 아니다. 일반화를 검사하려면 정답을 주지 않은 변형 사례도 추가한다. 문서 정체성·조회 기록·전후 결과·한계를 한정된 보고서에 남기고 합성 사실은 실제 지식·사건에 섞지 않는다.

실패한 실제 검색어를 별도 ID 검색 회귀 사례로 고정할 수 있다. 이는 기록된 필터·개수에서의 어휘 검색을 검사하며 의미 평가는 별도다. 목록 유효성·출처 조사·가상 판단·런타임 성능을 구분한다.

## 사례

점프 입력 손실, 이미 인스턴싱된 GPU 병목 숲, 롤백 선행 조건, 체크섬이 통과한 저장 식별 오류와 중단 복구, 총구 차폐와 별도 지연 증상, 게임 메뉴 오탈자만 고치는 대조군을 다룬다. 제한된 표본이며 미래 모든 검색·판단의 정확성을 보장하지 않는다.

[2026-11-07 평가 보고서](evaluation-results.kr.md)는 초기 답변 6개, 새 맥락 재평가 4개, 가까운 검색 오탐 수정과 최종 회귀 결과를 보존한다. retrieval-cases.json은 별도의 어휘 검색 검사이며 작성자가 아는 변형 문구를 미공개 의미 평가로 취급하지 않는다.

[확장 평가](extended-evaluation-results.kr.md)는 남은 기술 32개를 새 상황 10개로 검토했다. 별도 입력·기준·검색 대조군, 정확한 계약이 없는 경우와 복수 원리, 새 맥락 재평가 3개 및 이후 가중치 흐름장 반례·변형 검사를 보존한다. 실제 게임 런타임 검증과 구분한다.
