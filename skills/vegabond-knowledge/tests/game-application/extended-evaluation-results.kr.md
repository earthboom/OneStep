# 추가 게임 개발 상황 평가 — 2026-11-07

이전 6개 독립 적용 평가에서 열람하지 않았던 **32개 기술을 새 상황 10개로 평가**했다. 두 평가를 합쳐 기술 43개 모두의 가상 적용 판단을 검토했다. 이는 지식 활용 범위이며 43개 구현·실제 게임·엔진이 검증됐다는 뜻은 아니다.

## 검색이 없거나 후보가 여러 개인 경우

사내 API·포맷을 가정한 이름 3개는 정확명 검색이 **0건**이다. 이를 미지원·부존재의 증명으로 삼지 않았다. 넓힌 검색의 일반 길찾기·콜백·메모리 자료도 특정 업체 계약으로 인정하지 않았다. 필요한 버전·스레드·수명·문법·길이·엔디언·오프셋 문서를 명시하고, 그 계약에 의존하는 구현만 보류하며 독립 분석은 완료했다.

여러 후보는 검색 순위로 고르지 않고 **어떤 결정을 해결하는지, 필요한 입력·권한·비용·한계가 무엇인지** 비교했다. 활용 규칙에도 무결과의 제한된 재검색과 근거 공백 처리, 복수 후보의 결정별 분해를 명시했다. 원래도 관찰된 올바른 판단을 더 분명하게 기록한 것이며 보편적인 추론 능력을 입증한 것은 아니다.

군중·연막/물·레트로 3개는 같은 입력·기준으로 새 맥락에서 다시 평가해 통과했다. [재평가 기록](extended-retest-run.json)과 단순 검색 재실행을 구분한다.

## 보완한 부족한 점

- 초기 한국어 양성 검색은 14개 중 3개만 필요한 항목을 찾았다. 가까운 음성 대조 6개를 포함하면 **8/20**이었다. 관찰된 누락에 한정한 한영 용어·복수 조건 확장을 추가했다. 단순 별칭 단계는 12/20이었고, 복수 주제 검색에서 확률 보상 후보가 밀리는 문제도 추가로 수정했다.
- 일반 실내 음악 질문에 가상 방 렌더링이 섞였다. INTERIOR의 한국어 키워드를 장식·비진입 창문과 인테리어 매핑으로 좁혔다. 수면 시간·반사신경·배열 원소·메모리 파편화 등을 해당 그래픽·원소 기술로 오인하지 않는 대조군도 유지했다.
- 최종 검색은 **20/20**, 이전 검색 묶음은 11/11과 23/23으로 통과했다. 정확한 미확인 계약 3개는 여전히 0건이다. 작성자가 알고 있는 유한 회귀 사례이며 미래 모든 자연어 질의의 정확도를 뜻하지 않는다.

## 가중치 흐름장 설명의 추가 보완

후속 검토에서 PATH의 “비용이 줄어드는 방향으로 이동”이라는 설명이 가중치가 다른 그래프에서 잘못 옮겨질 수 있음을 발견했다. 원래 기준에 숫자 반례는 없었으므로 기존 통과를 소급 변경하지 않았다. 초기 수행자는 간선 비용을 명시했지만 첫 재평가 요약은 거칠게 남아, 실제 게임 결함이 아닌 저장 설명의 모호함을 보완했다.

원저자의 이동 비용·흐름장 설명을 다시 확인하고 다음 이동을 **c(u,v)+T(v)**로 비교하도록 명시했다. 방향을 뒤집어 탐색할 때 원래 비용을 유지하고, 0비용 동률에는 진행이 보장되는 다음 이동 정책을 요구했다. 이는 출처에서 도출한 공학 설명이며 업체의 직접 보장이 아니다.

[그래프 반례](weighted-flow-cases.json)는 잘못된 비용 101과 최적 3, 0비용 순환, 방향별 다른 비용을 검사한다. 수정 뒤 새 수행자에게 다른 숫자의 입력을 줬고 다음 이동 Q/Z/L, 총비용 **8/4/5**를 올바르게 계산했다. [실제 답변·독립 재계산](weighted-followup-run.json), [반복 가능한 수학 검사](check_weighted_flow.py)는 엔진 경로·충돌 검증과 별개다.

## 근거와 한계

[입력](extended-cases.json)·[기준](extended-rubric.json)을 먼저 고정했다. 수행자에게 기대 ID·기준·다른 답안을 주지 않았으며 [초기 기록](extended-baseline-run.json)의 정본 148개는 실행 중 변경되지 않았다. [의미 평가](extended-semantic-review.json)는 실제 판단을 AI가 검토한 것으로 자동 키워드 점수나 사람의 플레이 평가가 아니다.

[최종 검사 기록](extended-validation-results.json)에 검색·필터·결과 재실행, 문서 정체성, 무결과, 목록·번역 존재·링크, 검색 단위 검사 **33/33**, 그래프 검사 3개와 변형 재계산을 보존했다. 이전의 Windows 심볼릭 링크·정션 권한 한계는 이번에 재검사하거나 해결했다고 선언하지 않았다. 합성 사내 API·파일 규격을 실제 지식으로 추가하지 않았다. 실제 런타임·성능·플레이 검증은 별도다.
