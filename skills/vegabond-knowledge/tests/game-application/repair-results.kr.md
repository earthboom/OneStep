## 롤백 업적·보상

[ROLLBACK](../../../../knowledge/game/K-GAME-TECH-ROLLBACK.kr.md)에 복원할 시뮬레이션 상태, 취소 가능한 표시, 되돌릴 수 없는 외부 효과를 구분했다. 예측 이벤트는 중복을 막았더라도 외부 지급 근거가 아니다. 자격 조건과 이벤트가 프로토콜의 신뢰 가능한 경계에서 확정되어야 한다. 피어 확정에 서버가 반드시 필요한 것은 아니다. 이벤트·수령자·경기를 구분하는 안정적인 키와 외부 서비스의 영속 전달 계약도 별도로 명시했다.

실제 검색어 `롤백 예측 KO가 방어로 보정될 때 업적 보상 확정과 재전송 중복을 어떻게 처리할까`에서 ROLLBACK이 상위 5개 중 첫 결과였다. 적용 판단은 방어로 보정된 KO·미확정·신뢰하지 않는 이벤트는 지급 0건, 확정된 적격 이벤트는 멱등 전달이다. 서버 필수를 추론하지 않았다. 작성자가 확인한 회귀 판단이며 미공개 작업의 에이전트 성능 평가는 아니다.

[통제된 추적 8개](rollback-reward-cases.json)가 [계약 검사](check_rollback_rewards.py)를 통과했다. 재실행·재시도, 같은 틱의 다른 이벤트, 다른 경기·수령자, 확정되었지만 자격 없는 이벤트를 다룬다. 중복 제거만 하는 음성 대조군 2개는 잘못 지급했다. 모델은 주어진 확정 플래그를 신뢰하고 키를 메모리에만 저장한다. SDK·게임·네트워크·재시작·DB·수신 서비스·결정성·성능은 실행하거나 입증하지 않았다. Photon 공식 문서는 취소 가능한 예측과 검증된 이벤트의 구분을 뒷받침하며 외부 전달 지침은 공학적 종합이다.

## 검색어 확장

`transparent-dark-edge`가 `검`을 허용해 `검토·검사·검증`까지 블렌딩으로 오확장했다. 수정 전 세 검색어가 모두 단위 회귀 검사에 실패했다. 이제 `검은·검게·검정·검다` 또는 기존의 어두움·번짐 증상으로 제한한다.

같은 세 음성 질의는 가상 저장소와 실제 저장소 검사에서 BLEND를 반환하지 않는다. 기존 `검은`, 추가한 `검게·검정` 양성 질의는 계속 BLEND를 찾는다. [확장 검색 사례](extended-retrieval-cases.json)에 인접 대조 사례를 추가했고 고정된 의미 평가 요청·기준은 바꾸지 않았다. 국소적인 어휘 보완이며 일반적인 한국어 이해·완전성·정밀도를 보장하지 않는다.

## 빌드와 독립적인 재분석

기존 Traffic·Stream은 Git에서 제외된 EXE·DLL이 없으면 중단했고 원본·Dynamic은 바이너리 확인을 조용히 생략했다. 수정 전 빌드 없는 통합 검사는 누락 중단, 검증 차원 부재, 무시되는 인수와 자동 요약 덮어쓰기를 재현했다.

네 분석기는 기본적으로 보관 보고서·소스 식별자를 확인하고 바이너리 결과를 별도 표시한다. 새 `--output`을 지정하지 않으면 표준 출력만 한다. `missing`을 명시하고 `--require-binaries`는 누락도 실패시킨다. 존재하는 파일의 불일치·접근 불가는 양쪽 정책에서 실패한다. `--binary-root`는 보관 경로를 지원하며 실행별 예상 해시가 다르면 실패한다. 기존 소스·해시·수치·파일럿 보관 검사도 유지했다. 범위·상태·명령은 [분석 계약](../../../../prototypes/TechniqueLab/ANALYSIS.kr.md)에 있다.

빌드를 제외한 복사본에서 네 분석기 모두 통과했다. 엄격 모드 누락, 잘못된 바이너리, Traffic 소스 변경과 보관 동작 검사 실패를 탐지했고 기존 출력 덮어쓰기를 막았다. 모든 과거 측정 필드가 정확히 일치했다. 로컬 보관 파일도 원본 EXE, Dynamic 어셈블리, Traffic·Stream의 EXE·어셈블리 엄격 검사를 모두 통과했다. 엄격 재분석 중 과거 요약 4개의 바이트 해시와 수정 시각을 유지했다. Unity 소스와 과거 Results 파일은 바뀌지 않았다. 분석·출처 검증이며 새 엔진 실행이나 전체 빌드 인증은 아니다.
