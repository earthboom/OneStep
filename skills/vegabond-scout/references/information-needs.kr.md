# 정보 필요성 및 적용 판단

작업에 필요한 정보와 조회 자료가 행동을 지배할 수 있는지 판단하는 공통 절차다. 정찰·지식·작업 절차·전문 스킬은 기존 작업 요약을 공유하며 별도 흐름, 만능 점검표, 사용 장부를 만들지 않는다. [지식 절차](../../vegabond-knowledge/SKILL.md)는 조회·저장을, [조회 참고 문서](../../vegabond-knowledge/references/retrieval.md)는 검색 방법을 관리한다.

## 작업에서 질문 도출

키워드나 넓은 분야명보다 요청 결과와 실제 제공 자료에서 시작한다. 어떤 정보의 누락·오판이 행동을 바꾸거나 보존 조건을 깨거나 수락 검사를 무효화하는지 확인한다.

- 의도한 결과, 사용자·독자, 명시 조건과 이미 결정한 사항.
- 실제 입력과 상태, 호출자·소비자, 소유권, 시간·판본, 경계를 넘는 의존성.
- 개연성 있는 실패, 상충 근거, 최종 검사가 관찰해야 하는 것.

이는 모든 작업에 채울 필드가 아니라 사고를 돕는 관점이다. 요청이 모든 의존성을 설명한다고 가정하기 전에 가까운 권위 있는 입력을 확인한다. 철자 수정이 작품 설정 전체를 요구하지는 않으며 일반 판타지 장면에도 정보 공개와 공정한 단서 검토가 필요할 수 있다. 분야·기술·장르명만으로 관련성을 판단하지 않는다.

기존 요약에 **결정·행동 → 질문과 필요 이유 → 지배하는 출처·맥락 → 근거 상태 → 영향받는 검사·결과**를 연결한다. 작은 작업은 한 문장이면 충분하다. 여러 결정이 얽힐 때만 짧은 표를 쓰며 빈칸을 채우려고 사실을 만들지 않는다.

필수 선행 정보, 현재 선택에 유용한 정보, 보류·범위 밖 정보를 구분한다. 필수란 공백이 계약·의미·정본 보존 또는 안전한 확정을 무효화할 수 있다는 뜻이다. 선호와 선택적 개선은 자동으로 필수가 되지 않는다. 질문을 보류할 때 경계나 재검토 계기를 남기며, 구하기 어렵다는 이유로 필수 의존성을 보류하지 않는다.

## 실행 전문가와 정교화

정찰은 초기 질문과 유용한 맥락을 마련한다. 전문가는 실제 코드·호출부, 원고, 기획, 슬라이드 등을 확인한 뒤 주요 결정과 의존성이 포함됐는지 검토한다. 새 필요를 추가하되 유효한 기존 답변은 재사용한다. 전문 스킬을 직접 호출해도 별도 정찰 대화를 요구하지 않고 같은 판단을 적용한다.

분야별 의무 목록이 아닌 선택적 정교화 예시:

| 작업 | 실제 자료가 드러내는 질문 |
| --- | --- |
| 콜백 도우미 단순화 | 무엇이 무엇보다 오래 살아남는가? 어느 스레드와 종료 단계인가? 보존할 동작은? |
| 증언·폭로 장면 수정 | 각 인물과 독자가 어느 관찰로 무엇을 아는가? 아직 공개하면 안 되는 정보는? |
| 전투 시간·보상 변경 | 가정하에서 보상률·성장·소모처·세션 경험·콘텐츠 수요는 어떻게 바뀌는가? |
| 비교 차트 수정 | 기간·모집단·분모·단위가 비교 가능한가? 최종 요청 형식은? |

중요한 선택 전에 **어떤 누락 조건이 이 행동을 틀리게 하며, 어떤 출처나 검사로 드러낼 수 있는가?**를 묻는다. 모든 가상 위험이 아니라 구체적 의존성이나 반례를 따른다. 새 근거·요구 변경·가정 무효화가 드러낸 부분만 반복하고 유효한 작업을 유지한다.

## 근거 요청과 조회

작업 프로젝트, 실제 결정과 질문, 관련성, 맥락, 필요한 근거와 공백을 지식에 전달한다. 증상이 없어도 예정 행동·발생 조건으로 지식과 문제 기록을 찾는다. 카탈로그 무일치는 원본 확인이나 집중 조사를 요구할 수 있다. 빠진 질문을 찾는 대신 검색만 반복하지 않는다.

지식은 원본 위치, 조건, 충돌, 근거·예방 상태와 공백이 붙은 후보를 반환하며 누락 전제를 드러낼 수 있다. 적용 판단과 결과 검증은 소비하는 전문가가 담당한다. 검색 점수나 지식 요약은 작업 전체의 충분성을 인증하지 않는다. 맥락 미상은 미상으로 유지하고 관련·파생 자료를 독립 증거로 세지 않는다.

원본 접근, 내용 동일성, 주장의 검증을 분리한다. 항목 날짜·해시는 최신 원본 검사가 아니다. 등록 출처는 접근 불가·잘못된 ID까지 요청한 모든 ID의 결과를 대조한다. 루트 설정이 없으면 먼저 이미 허용된 작업 경로나 알려진 프로젝트 메타데이터를 활용하고, 경로를 추측하거나 무관한 디렉터리를 찾지 않는다. 영구 설정 요청이 없으면 이번 조회에만 임시 루트를 쓴다. 접근 가능한 무버전 원본은 현재 읽기에 쓸 수 있지만 과거 판본을 인증하지 못하며, 이 한계를 요약과 최종 검증에 남긴다.

## 행동을 지배할 자료 판단

중요 후보는 실제 작업과 출처의 프로젝트·작품, 판본·시점, 행위자, 작동 원리, 제약과 입증 근거를 비교한다. 필요한 원본을 확인한다. 사용자 지시, 계약·정본, 사실 근거, 선호와 잠정안의 권한은 질문에 따라 다르다. 최신성·동의하는 요약 수·active 표시는 권위를 결정하지 않는다.

기존 요약에 유용한 결론을 남긴다.

- **채택:** 확립된 맥락에서 출처가 행동을 뒷받침하며 실제 행동·검사를 명시한다.
- **조건부:** 미해결 조건과 허용할 잠정 사용을 밝히고 사실로 승격하지 않는다.
- **이 행동에서는 기각:** 범위·원리·권한·근거의 불일치를 밝힌다.
- **보류:** 현재 경계에서는 불필요하며 중요하면 재검토 시점을 남긴다.

이는 모든 검색 결과의 장부가 아니다. 같은 증상이 같은 원인을, 다른 작가의 선택이 보편 문체 규칙을, 제안 예방이 검증을, 과거·미래 설정이 현재 인물 지식을 뜻하지 않는다. 실제 원리와 조건을 추적한 뒤 적용한다.

사실·지지되는 추론·가정·충돌·근거 공백을 나눈다. 필수 답변이 없으면 정당화할 수 없는 종속 행동과 최소 필요 근거를 밝히고 독립 검토나 경계가 명확한 제안을 계속한다. 중요한 의도만 질문하고 일상적 승인을 요구하거나 빈 저장소 때문에 무관한 작업을 막지 않는다.

## 검색이 아닌 실제 작업을 기준으로 마무리

인계 전에 중요 결정을 근거·적용 행동·실제 수락 검사 결과와 연결한다. 결과물이 새 상태·의존성·사실 주장을 도입했는지 확인한다. 질문을 답변됨·조건부·충돌·공백으로 닫고, 유효한 보류를 답변 완료로 세지 않는다. 미해결 한계와 무효화된 근거 및 영향을 보존한다. 검색 coverage는 일치한 용어 수이지 정보 필요성의 완전성이 아니다.

스킬 유지보수에는 [요청부터 적용까지의 평가 사례](../../vegabond-knowledge/tests/information-needs/evaluation.md)를 사용한다. 질문 누락·잘못된 전이·근거 없는 확신·과잉 조회를 구조 검사와 질의→ID 검사와 별도로 평가한다. 유한 사례로 미래의 모든 누락·오판 부재를 증명할 수 없다.
