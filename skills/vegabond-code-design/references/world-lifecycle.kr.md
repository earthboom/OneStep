# 게임 데이터와 월드 런타임 설계

기존 설계 브리프에 해당 항목을 적용한다. 현재 게임 규칙, 엔진 제약, 대표 부하를 기준으로 방법을 고른다. 기능 구성에는 [게임플레이 프레임워크 및 콘텐츠 설계](gameplay-framework.md), 인수 조건과 반례에는 [설계 검토](review.md)를 참고한다.

## 변경 뒤에도 유지될 사항을 정한다

- 저작 정의, 파생 빌드 산출물, 가변 게임 상태, 영속 진행 상태의 수명이 다르면 각 소유자를 지정한다. 외부에 저장되는 게임 대상에는 수명이 정의된 ID를 사용한다. 달라질 수 있는 표시 객체 식별자, 이름, 엔진 경로는 따로 둔다.
- 추가 시 기본값·검증·허용 의존성을 정한다. 변경 시 기존 세이브와 현재 세션 중 새 값을 적용할 대상을 정한다. 폐기 시 해당 정의를 참조하는 기존 저장·퀘스트·복제·모드를 파악하고, 유지·명시적 교체·계약에 따른 대체·진단을 동반한 거부 중 선택한다. 지원 데이터가 폐기 ID를 포함할 동안 예약한다. 미확인·미래 버전·잘못된 데이터 처리와 검증된 카탈로그나 마이그레이션 저장의 공개 시점을 정의한다.
- 라이브 카탈로그 변경 경계, 세션에서 고정할 버전, 네트워크 버전 일치 조건을 정한다. 씬이나 셀 언로드, 월드 종료, 프로세스 재시작에 걸쳐 보존할 상태를 구분하고 그 수명을 가진 소유자를 둔다. 실제 이전 입력과 기대 결과를 검증에 넘긴다. [버전 저장](../../../knowledge/game/K-GAME-TECH-SAVE.md) · [Factorio 마이그레이션](https://lua-api.factorio.com/latest/auxiliary/migrations.html)

## 예산과 상주 방식을 선택한다

- 플레이 경로, 빌드, 대상 기기, 품질 설정, 프레임·메모리·준비 시간 예산을 명시한다. 기준 캡처로 게임 스레드, 렌더 제출, GPU 패스, 로드·활성화 지연을 구분한다. 관찰한 비용을 기준으로 렌더링 변경을 고르고 유지할 시각·게임플레이 상세를 정한다. 드로우 수와 에셋 크기를 시간 및 체감 품질과 함께 본다. [성능 측정](../../../knowledge/code/K-CODE-PERFORMANCE-MEASUREMENT.md) · [식생 절충](../../../knowledge/game/K-GAME-TECH-FOLIAGE.md)
- 재사용 빈도, 지연, 피크 메모리, 무효화 비용을 기준으로 즉시 생성, 상한을 둔 풀, 파생 결과 캐시, 베이크, 미리 읽기, 상주를 고른다. 로드 요청, 상주 자원, 활성 객체, 재사용 결과의 소유자를 구분한다. 취소한 로드의 결과 해제, 풀 재사용 초기화, 오래된 콜백 차단, 준비 시한을 놓친 지역의 동작을 정한다. 임곗값을 바꾸기 전에 경계 왕복의 비용을 살핀다. [Object Pool](https://gameprogrammingpatterns.com/object-pool.html) · [스트리밍 사례](https://www.gdcvault.com/play/1022268/Streaming-in-Sunset-Overdrive)

## NPC 갱신 수준의 전이를 정한다

- 관찰 가능한 행동과 중단 상황부터 시작한다. 실패나 갱신 정책이 다른 감지·결정·이동·행동 실행의 책임을 구분한다. 명시적 모드는 상태 머신, 저작 우선순위와 중단은 행동 트리, 점수 비교는 유틸리티, 행동 순서 재구성은 계획법을 게임 요구에 맞게 선택한다. 비싼 쿼리·계획의 시간이나 작업량을 제한하고 경로 실패, 취소, 디버깅에 필요한 상태를 포함한다. [군중 행동과 경로](../../../knowledge/game/K-GAME-TECH-CROWD.md)
- 렌더링, 애니메이션, 충돌, AI, 복제, 언로드를 각각 판단한다. 거리와 가시성에 전투·퀘스트·소리·권한·관련 관찰자를 함께 고려한다. 상태를 유지할 NPC와 장식용 객체를 구분한다. 표시 객체가 없는 동안의 행동까지 포함해 결과를 보존하는 최소 갱신 수준을 고른다. 각 전이에서 넘길 상태와 시간 기준, 쓰기 권한, 빠른 왕복 방지, 부작용 중복 없는 따라잡기를 정의한다. 실제 언로드·재진입과 지원할 경우 전이 중단도 확인 경로에 넣는다. [시뮬레이션 LOD](https://pages.cs.wisc.edu/~schenney/research/culling/chenney-gdc2001.pdf) · [Mass LOD](https://dev.epicgames.com/documentation/unreal-engine/overview-of-mass-gameplay-in-unreal-engine)

선택한 정책, 중요 대안의 판단, 버전·권한 가정, 대표 입력과 기대 결과, 예산이나 측정 범위를 반환한다. 관련 [런타임 확인 절차](../../vegabond-code/references/world-lifecycle-verification.md)를 구현에 전달한다.
