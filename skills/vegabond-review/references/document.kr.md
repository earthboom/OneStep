# 문서 리뷰

사람용 번역입니다. AI 기준 문서는 `document.md`입니다.

독자, 목적, 장르, 요청 매체에 비추어 비문학 문서를 평가합니다. 이 분야는 일반 문서를 포함하며 기존 document 제작 스킬은 취업 지원서에 특화되어 있습니다.

- 독자가 요점을 찾고 논리를 이해해 의도된 행동을 할 수 있는지 확인합니다. 세부 수준과 용어를 독자에게 맞춥니다.
- 중요한 주장·인용·수치·권고를 근거에 연결합니다. 근거 부족과 입증된 거짓을 구분합니다. 날짜, 단위, 합계, 참조, 반복된 진술을 대조합니다.
- 해석이나 행동을 바꾸는 누락·모호성을 확인합니다. 저자의 의미와 목소리를 보존하며 선택적 문체 취향을 사실 오류로 취급하지 않습니다.
- 레이아웃·표·페이지·접근성·출력 충실도가 중요하면 실제 파일이나 렌더링을 확인합니다. 원문 텍스트는 내용 검토만 뒷받침합니다. 실제 제출 제한과 알려진 계산 규칙을 적용합니다.

지원서에는 [지원서 작성 기준](../../vegabond-document/references/job-application-writing.md)과 공고·양식을 적용합니다. 참여를 리더십으로 부풀리거나 성과 수치를 만들지 않습니다. 다른 문서에는 채용 기준을 적용하지 않습니다.

제안서의 실행 가능성·약속에는 [planning](planning.kr.md), 기술 메커니즘에는 [code-design](code-design.kr.md)을 적용합니다. 정확한 문구와 독자에게 미치는 영향을 제시합니다. 접근할 수 없는 자료는 근거 공백으로 남기고 추측으로 대체하지 않습니다.
