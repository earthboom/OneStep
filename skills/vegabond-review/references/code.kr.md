# 코드 리뷰

사람용 번역입니다. AI 기준 문서는 `code.md`입니다.

구현된 동작을 계약과 비교합니다. 변경 버전·차이와 관련 호출자, 데이터 소유권, 실행 환경을 확인하고 실제 의존성이 있을 때 변경 줄 밖으로 확장합니다. 변경분 리뷰에서는 새 결함과 관련된 기존 결함을 구분합니다.

- 입력, 상태 전이, 출력, 오류, 정리를 추적합니다. 이 코드에서 도달 가능한 경계값·반복 호출·부분 실패·동시성을 검토합니다.
- 실제 용도에 비추어 호환성, 보안 경계, 자원 수명, 성능을 확인합니다. 구체적인 유발 조건과 영향을 제시합니다. 마음에 들지 않는 패턴이나 가상 부하만으로 결함을 단정하지 않습니다.
- 테스트가 관찰 가능한 동작과 의미 있는 실패를 다루는지 봅니다. 통과한 테스트의 근거 범위는 실제 실행한 부분입니다. 테스트 부재만으로 동작 결함이 입증되지는 않습니다.
- 필요하고 허용된 경우 집중된 재현이나 테스트를 수행합니다. 정적 추론과 실행 근거를 구분합니다. 리뷰를 끝내기 위해 외부 부작용이 있는 낯선 코드를 실행하지 않습니다.

실행 검사를 고를 때 [소프트웨어 검증](../../vegabond-code/references/verification.md)의 관련 범위만 적용합니다. 미구현 메커니즘이나 구조적 보장이 쟁점이면 [설계 기준](code-design.kr.md)을 추가합니다.

지적에는 경로·줄·심볼, 유발 조건, 기대와 실제 동작, 영향을 담습니다. 원인을 고치는 방향을 제안하되 임의로 구현하지 않습니다. 정적 검토로 빌드 성공이나 실행 동작·성능 측정을 주장하지 않습니다.
