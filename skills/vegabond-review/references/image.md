# Image review

Inspect the actual image at its intended display size and at a useful detail scale. Establish purpose, target context, reference image and preservation constraints. A generation prompt supplies intent, not evidence of visual quality.

- Assess hierarchy, focal point, silhouette, composition, contrast, color and readability by intended use. Judge stylistic departures against the brief; stylized anatomy or perspective is not automatically an error.
- Inspect relevant anatomy, contact, overlap, geometry, text, repeated motifs and unwanted artifacts. Cite the visible region and consequence rather than generic advice to improve quality.
- For edits or a series, compare source and final images for required identity, pose, proportions, palette and consistency. Review only requested preservation conditions, not pixel equality by default.
- For delivery, check dimensions, crop, actual alpha channel and export when required. A checkerboard-looking background does not establish transparency. Inspect edges against useful backgrounds when alpha quality matters.

Use applicable sections of [style and visual review](../../vegabond-image/references/style-and-review.md) for deeper criteria, without starting generation. If only a thumbnail, prompt or description is available, say exactly which judgments it supports and which require the actual image. Do not infer unseen details, user-study results or production-ready asset quality from metadata.
