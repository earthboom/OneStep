# 이미지 리뷰

사람용 번역입니다. AI 기준 문서는 `image.md`입니다.

실제 이미지를 의도된 표시 크기와 유효한 확대 수준에서 확인합니다. 목적, 사용 맥락, 참조 이미지, 보존 조건을 파악합니다. 생성 프롬프트는 의도이며 시각 품질의 근거가 아닙니다.

- 용도에 따라 위계, 초점, 실루엣, 구도, 대비, 색, 가독성을 평가합니다. 스타일 변형을 요청 기준으로 판단하며 과장된 해부·원근을 자동으로 오류 처리하지 않습니다.
- 관련 신체 구조, 접촉, 겹침, 형태, 글자, 반복 모티프, 원치 않는 흔적을 봅니다. 막연한 품질 개선 대신 보이는 영역과 영향을 제시합니다.
- 편집·시리즈에서는 정체성, 포즈, 비율, 팔레트, 일관성 등 요구된 보존 조건으로 원본과 최종본을 비교합니다. 기본적으로 픽셀 일치를 요구하지 않습니다.
- 필요한 경우 크기, 잘림, 실제 알파 채널, 내보내기를 검사합니다. 체크무늬 배경처럼 보인다고 투명한 것은 아닙니다. 알파 품질이 중요하면 적절한 배경 위에서 경계를 봅니다.

깊은 기준은 [스타일과 시각 리뷰](../../vegabond-image/references/style-and-review.md)의 관련 부분을 사용하며 생성을 시작하지 않습니다. 썸네일·프롬프트·설명만 있으면 가능한 판단과 실제 이미지가 필요한 판단을 밝힙니다. 메타데이터로 보지 못한 세부, 사용자 조사 결과, 완성 품질을 추론하지 않습니다.
