# 음향 리뷰

사람용 번역입니다. AI 기준 문서는 `sound.md`입니다.

역할, 재생 환경, 길이·동기화, 보존할 소스·문구, 납품 조건을 파악합니다. 청감 주장은 실제 출력물을 듣고 판단하며 청취·측정·실행 맥락 검사를 구분합니다.

- **효과음·환경음:** 신호 식별, 시작·잔향, 클릭·잡음, 변주, 레이어, 실제 사운드 환경과의 상호작용을 확인합니다.
- **BGM·적응형 음악:** 음악적 기능, 전환, 반복 청취 시 루프 경계, 스템 정렬, 맥락 내 마스킹을 봅니다. 길이가 맞다고 매끄러운 루프가 입증되지는 않습니다.
- **음성:** 실제 문구, 발음, 타이밍, 명료도, 호흡, 처리를 정상 속도로 확인하고 가능하면 실제 믹스에서도 듣습니다. 대본은 청취 명료도를 입증하지 않습니다.
- **노래:** 후렴, 프레이징, 음역·표현, 편곡, 가사 전달을 요청과 비교합니다. 취향·장르 기대와 기술 결함을 구분합니다.
- **납품:** 실제 출력의 채널, 샘플레이트, 비트 깊이·인코딩, 길이, 경계, 관련 레벨·피크 측정을 목적지 요구와 비교합니다. 목적지 기준 없이 보편적인 음량 목표를 강제하지 않습니다.

세부 검사는 [vegabond-sound](../../vegabond-sound/SKILL.md)의 관련 절차만 사용하며 제작 권한으로 해석하지 않습니다. 청감 지적은 실제 시간 범위와 청취 맥락을 제시합니다. 메타데이터·파형·악보·제작 메모로 없는 음원을 들은 것처럼 판단하지 않습니다. 청취할 수 없으면 가능한 기술·명세 검토를 반환하고 청감 검사를 차단으로 표시합니다.
