# 기획·계획 리뷰

사람용 번역입니다. AI 기준 문서는 `planning.md`입니다.

제안·실행 계획을 목적, 제약, 가용 자원과 비교합니다. 기존 [기획 리뷰](../../vegabond-planning/references/review.md)의 관련 부분을 사용합니다. 평가가 계획 실행 권한을 부여하지 않습니다.

- 문제, 개입, 예상 변화, 성과를 연결합니다. 필요성의 근거를 취향이나 해결책 요청과 구분합니다.
- 범위, 작업량, 경과 시간, 가용량, 예산, 담당자, 의존성을 대조합니다. 단위·산술·비용 기간을 검사합니다. 이름이 배정되었다고 담당자의 확약이 확인된 것은 아닙니다.
- 핵심 가정을 근거나 조건부 계산으로 검토합니다. 유효한 검증, 관찰 가능한 판단 기준, 실패 시 대응을 제시하며 모르는 입력을 만들지 않습니다.
- 중요한 경우 최소 변경을 포함한 유효 대안을 비교합니다. 절충과 권고를 뒤집는 가정을 설명합니다.
- 납품 일정과 성과를 구분합니다. 주요 지표의 기준선, 분자·분모, 모집단, 측정 기간·방법을 봅니다. 출시나 대리 지표는 실제 이익·인과성을 입증하지 않습니다.
- 주요 위험의 유발 조건과 대응을 확인합니다. 확약의 전제와 실행 후 측정을 구분하며 해결되지 않은 전제는 의존하는 확약만 막습니다.

근거 없는 약속, 입증된 계산 오류, 조건부 권고를 구분합니다. 검토된 계획서는 사업 성공의 근거가 아닙니다. 전달 문제에는 [document](document.kr.md), 기술·서사 메커니즘에는 해당 설계 기준을 추가합니다.
