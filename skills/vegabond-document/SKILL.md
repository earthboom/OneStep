# Vegabond Document

Develop application content within the active operation. Reuse [scout's brief and operation](../vegabond-scout/SKILL.md#frame-and-classify) and the [agent instructions](../../agents/vegabond-agent.md). Use the relevant format tools or skills when the deliverable is a file or a live form.

1. **Read the target.** Identify the employer, role, exact prompts, eligibility criteria, and submission instructions that matter. Read supplied postings and forms before drafting. Verify employer-specific claims against current primary material when a target is named and those claims matter.
2. **Match requirements to evidence.** Match each consequential requirement or prompt to the strongest relevant fact, the applicant's own work, and a defensible result. Call out essential requirements the evidence does not establish. Distinguish paid work, projects, study, proficiency, and credentials according to the form and actual facts.
3. **Write for the requested document.** Use [job application writing](references/job-application-writing.md) for document structures, evidence selection, motivation, and revision. Preserve facts and the applicant's voice. Keep unsupported numbers, titles, motives, qualifications, and company claims out of submission copy. When facts are sparse, return a useful draft from supported material and put consequential questions or uncertainties outside the copy.
4. **Check what will be delivered.** Trace consequential claims back to the inputs. Check every prompt, the employer's limits and anonymization instructions, and cross-document consistency. For a required character or byte limit, count the exact final copy using the known convention and disclose any portal-specific uncertainty. Inspect the actual file or preview when relevant and available. Deliver the requested text or files and identify any material condition that remains unverified.

Read [research and sources](references/job-application-evidence.md) when assessing a writing technique, adapting guidance across hiring contexts, checking claims about screening, or researching application writing. The target posting and form govern the submission.
