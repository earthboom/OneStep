# Vegabond Create

요청한 새 결과를 실제로 제작합니다. 정찰 스킬의 작업 요약과 프로필을 재사용하고 [에이전트 지침](../../agents/vegabond-agent.kr.md)의 공통 경계·완료 조건을 따릅니다. 직접 호출되면 [정찰 공통 설정](../vegabond-scout/SKILL.kr.md)으로 빠진 맥락만 채운 뒤 되돌아가지 않고 계속합니다.

## 제작 과제 구체화

[필요한 정보의 공통 판단](../vegabond-scout/references/information-needs.kr.md)으로 중요한 제작 선택과 보존 조건을 근거에 연결합니다. 전문 스킬이 실제 입력에서 빠진 질문을 보완하게 하고 유효한 답을 재사용하며 최종 결과에 어떻게 적용됐는지 확인합니다.

[지식 스킬](../vegabond-knowledge/SKILL.kr.md)에서 필요한 참고·관례·수용 점검을 가져오고 정찰의 정보 요약을 재사용합니다. 새 출처 기반 방법이나 확인한 수정은 허용된 범위에서 저장할 수 있도록 반환합니다.

제공 자료와 새로 만들어야 할 내용을 나눕니다. 초안·개요·편집 가능한 산출물·실행 가능한 기능 등 요구한 완성도를 확인합니다. 개요만으로 완성된 발표나 영상이 되지는 않습니다.

[정찰의 역량 연결](../vegabond-scout/SKILL.kr.md)에 따라 선택한 방법을 아래 제작 단계로 옮기고 전문 스킬의 제작·검증·수정 방법을 적용합니다. 새 근거가 요구하지 않으면 기존 범위·규모를 보존하고 누락 세부만 보완합니다.

## 제작

1. 적합한 관례·참고·제공 사실을 재사용해 결과의 구성 방식을 정합니다.
2. 검증되지 않은 방향이 큰 재작업을 유발할 수 있으면 대표 개요·샘플·프로토타입으로 핵심 가정을 먼저 점검합니다. 그렇지 않으면 바로 제작합니다.
3. 요청한 결과물로 발전시키고 미완성 부분·자리표시자를 해결합니다. 새 부분 사이의 일관성과 창작 내용·근거가 필요한 사실 주장을 구분합니다.

실제 산출물, 사용에 영향을 주는 선택, 수용 근거, 미해결 사항을 반환합니다. 성공한 샘플이 전체 결과의 필수 점검 통과를 입증하지는 않습니다.
