# Vegabond Create

요청한 새로운 결과를 만듭니다. scout가 제공한 요약과 작업 프로필을 재사용합니다. 직접 호출했다면 [scout의 공통 준비 절차](../vegabond-scout/SKILL.md#frame-and-classify)로 맥락을 채우되 다시 분기하지 않으며, 문서 경계, 검증, 수용은 [에이전트 지침](../../agents/vegabond-agent.md)을 따릅니다.

## 제작 작업 구체화

scout의 정보 요약을 재사용하며, 필요한 참고자료·관례·수용 검증은 [vegabond-knowledge](../vegabond-knowledge/SKILL.md)를 사용합니다. 새롭게 근거를 확보한 방법이나 확인하여 수정한 문제는 해당 작업의 쓰기 범위 안에서 저장하도록 전달합니다.

공통 프로필을 사용해 제공된 자료와 새로 작성할 부분을 구분합니다. 요청한 완성 수준이 초안, 개요, 편집 가능한 결과물, 실행 가능한 기능 또는 다른 결과인지 확인합니다. 개요는 완성된 발표자료나 영상이 아닙니다.

선택한 수행 방법을 아래 제작 단계로 구체화하며, [scout의 공통 연결](../vegabond-scout/SKILL.md#connect-steps-to-skills-and-checks)에서 해당 전문 스킬의 create·검증·수정 방법을 사용합니다. 제작에 필요한 누락된 세부사항만 보완하고, 새로운 증거로 갱신이 필요해지지 않는 한 기존 범위와 규모를 유지합니다.

## 제작

1. 적용할 수 있는 관례, 참고자료, 제공된 사실을 재사용하여 결과에 필요한 구성 방식을 선택합니다.
2. 검증되지 않은 방향이 큰 재작업을 초래할 수 있다면 대표 개요, 샘플, 프로토타입으로 핵심 가정을 확인한 뒤 확장합니다. 그렇지 않으면 바로 제작합니다.
3. 그 구성을 요청한 결과물로 완성합니다. 미완성 부분이나 임시 내용을 해결하고 새 부분 사이의 일관성을 확인하며, 창작 내용과 근거가 필요한 사실 주장을 구분합니다.

실제 결과물, 사용에 영향을 주는 주요 선택, 수용 근거, 미해결 사항을 반환합니다. 샘플이 성공했다고 전체 완성 결과가 필요한 검증을 통과한 것은 아닙니다.
