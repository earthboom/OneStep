# Vegabond Create

Produce the requested new result. Reuse the brief and task profile supplied by scout. If invoked directly, use [scout's shared setup](../vegabond-scout/SKILL.md#frame-and-classify) without rerouting, and follow the [agent instructions](../../agents/vegabond-agent.md) for document boundaries, verification, and acceptance.

## Refine the creation task

Use [vegabond-knowledge](../vegabond-knowledge/SKILL.md) for needed references, conventions, and acceptance checks, reusing scout's information brief. Pass new source-backed methods or confirmed corrections back for storage within the task's write scope.

Use the shared profile to separate supplied material from what must be authored. Confirm the requested degree of completion: a draft, outline, editable artifact, executable capability, or another result. An outline is not a delivered presentation or video.

Translate the chosen method into the production steps below, using the relevant specialist's create, verification, and correction methods from [scout's shared mapping](../vegabond-scout/SKILL.md#connect-steps-to-skills-and-checks). Refine only missing creation details; preserve the established scope and scale unless new evidence requires an update.

## Produce

1. Choose the organizing shape the result needs, reusing applicable conventions, references, and supplied facts.
2. If an untested direction could cause substantial rework, make a representative outline, sample, or prototype and check the load-bearing assumption before extending it. Otherwise produce directly.
3. Develop that shape into the requested deliverable. Resolve unfinished sections or placeholders, check consistency across the new parts, and distinguish authored content from factual claims needing support.

Hand back the actual deliverable, key choices that affect its use, acceptance evidence, and unresolved issues. A successful sample does not establish that the completed result passes its required checks.
