# 무기 위치와 길게 유지된 인사 자세의 해제 명료화

- ID: R-FIC-N2-HAND-STATE-20261106
- 요약: 002 붕대 장면의 뽑힌 검 상태와 003의 늦은 인사 자세 해제를 명료화했습니다. 원래 행동이 불가능하다고 단정하지 않았습니다.
- 종류: suggestion
- 상태: resolved

- 원인 확신도: confirmed
- 발생 조건: 행동에서 처치로, 인사에서 대화로 전환하는 부분을 수정할 때
- 증상: 붕대를 감는 동안 검이 어디 있는지 또는 여러 대화 동안 포권을 유지하는 이유를 독자가 보충해야 함
- 예방 점검: 손의 점유, 임시 배치, 해제와 회수를 다음 행동까지 추적

## 기대와 관찰

002는 사망 확인까지 검을 뽑은 상태로 두고, 천을 찢어 팔을 묶은 뒤에야 검을 넣습니다. 003은 긴 대화 뒤에 인사 자세를 풉니다. 이는 명료성 문제이며 물리적 불가능성이 입증된 것은 아닙니다.

## 원인과 해결

관찰된 누락은 중간 소품 상태와 늦은 자세 갱신입니다. 002는 사망 확인 후 검을 발치에 두고 동료가 마당을 맡으면 다시 집도록 했습니다. 003은 자기소개 뒤 손을 내리고 나중의 중복 해제를 제거했습니다.

## 재점검과 예방

사망 확인 전 무기 준비, 처치 중 소품 위치, 검집에 넣기 전 회수와 인사 대화의 연속성을 장 전체에서 다시 읽었습니다. 두 편집 수정은 해결 상태입니다. 미래 장면의 점검은 제안 상태이며 보편적인 자세 지속 시간이나 무기 취급 규칙을 추론하지 않습니다.

예방 상태는 제안입니다. 현재 수정이나 기록된 위험이 미래의 자동 강제를 입증하지 않습니다. 점검은 같은 행위자·작업·정보 맥락을 조건으로 합니다.
