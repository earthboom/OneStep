# Suno 연결에서 채팅·메모리 제외

- ID: R-CODE-SUNO-CONTEXT-BOUNDARY
- 종류: 개선 제안과 실제 해결 기록. 개인정보 유출이 관찰된 사건은 아닙니다.
- 상태: 해결. 독립적인 사용자 수락 여부와는 별개입니다.
- 확인일: 2026-11-10
- 범위: OneStep 전용 클라이언트의 수정되지 않은 소스와 명시적으로 검토된 입력
- 환경: Windows, Node.js 22.19.0, PowerShell 7, 공식 MCP 클라이언트 SDK 2.4.0
- 예방 상태: 해당 클라이언트 경로에서 검증됨

## 기대와 관찰

사용자는 기존 대화나 메모리를 보내지 않고 가사·음악 지시문만 전송하도록 검증한 뒤 직접 Suno에 연결하도록 요청했습니다. ChatGPT 플러그인의 관련 문맥 공유 안내를 거절했으며, 실제 유출은 관찰되지 않았습니다.

별도 클라이언트가 필수 인증·프로토콜 통신만으로 인증에 성공했고 도구 41개와 암호화된 인증 정보 재사용을 확인했습니다. 대화 기록, 메모리 API, 모델 입력이나 파일시스템 루트를 제공하지 않았습니다. 실제 Suno 생성 스키마에서 lyrics와 style 외 필수 필드가 없음을 확인했습니다. 곡 생성이나 계정·보관함 도구는 실행하지 않았습니다.

## 원인과 해결

일반 플러그인의 문맥 처리는 요청한 제외 조건을 충족하지 못했습니다. 도구 이름만 제한하면 가사 필드에 사적인 내용을 섞을 수 있으므로 충분하지 않습니다. 훅은 오류 시 통과 가능성과 실행 환경별 지원 차이가 있어 유일한 경계로 사용하지 않았습니다.

[전용 클라이언트](../../prototypes/SunoRestricted/README.kr.md)는 선택적 기능을 비운 공식 SDK를 사용합니다. 네트워크 전송 직전의 검사에서 고정 프로토콜과 필수 인증을 허용하고, 생성은 검토된 파일 및 SHA-256과 정확히 같은 audio-create 요청 한 번만 허용합니다. 콘텐츠 필드는 lyrics와 style뿐입니다. 변경된 값, 추가 필드, 다른 메서드, 쿼리·추가 헤더·리다이렉트를 차단합니다. 문맥 제공 핸들러나 모델이 없어 서버의 추가 요청으로 대화·메모리를 조회할 수 없습니다.

인증 정보는 Git에서 제외된 로컬 저장소에 Windows 사용자별 DPAPI로 암호화합니다. 기존의 제한 없는 MCP 항목은 비활성화했고, 클라우드 플러그인은 미연결로 유지했습니다.

구현 중 SDK가 자동으로 추가하는 application_type: native가 차단됐습니다. SDK 소스로 원인을 확인하고 먼저 실패하는 검사를 만든 뒤 이 고정값만 허용했습니다. 구형 PowerShell의 보안 모듈·어셈블리 문제는 가짜 토큰 검사로 진단했고 PowerShell 7에서 암호화 왕복이 성공했습니다. 평문 저장으로 대체하지 않았습니다. 이 로컬 실패 진단에 외부 인증 반복은 필요하지 않았습니다.

## 재확인과 예방

[최종 검사 9개](../../prototypes/SunoRestricted/verification-tests.txt)가 모두 통과했습니다. 차단 기능이 없는 상태에서 먼저 실패를 관찰했습니다. 실제 로컬 HTTP 수신기에 금지된 문자열이 도달하지 않는지, 정상 가사 필드에 바뀐 사적 내용을 넣어도 차단하는지, 공식 SDK가 승인된 모의 요청만 전송하는지, 추가 문맥·헤더·쿼리와 리다이렉트를 차단하는지, 인증 정보를 암호화·복호화하는지 확인했습니다. [증거 파일](../../prototypes/SunoRestricted/verification.json)에 소스 해시와 실제 인증·도구 조회, 콘텐츠 호출 0회를 기록했습니다.

이 제한은 해당 전용 경로에만 적용됩니다. 셸·코드를 임의 수정할 수 있는 사용자의 우회 방지, 다른 앱, 컴퓨터 전체의 통신 격리를 보장하지 않습니다. 해시는 무결성을 검사하며 사람의 신원이나 내용의 사생활 여부를 판정하지 않습니다. 승인된 가사에 직접 넣은 개인정보는 전송됩니다. 필수 OAuth와 프로토콜 메타데이터는 제작 콘텐츠 제한의 예외입니다. 실제 곡 생성과 결과 상태 조회는 이번 점검에서 실행하지 않았습니다. SDK나 코드 변경 후 다시 검증해야 합니다.
