# 정확한 정책 끝점과 실제 컴포넌트 갱신을 혼동한 문제

## 기대와 관찰

이징 정책은2초/400cm에 정확히 도달했지만 실제 컴포넌트는399.9999445cm에 남았다.1e-8cm 실제위치 검사가 실패했고 차이는 약0.00005548cm였다.

## 원인과 해결

설치된UE5.8.3의 위치 갱신 경로가 기본 벡터 허용오차 이내 이동을 생략할 수 있었다. 선택한 공개API에 비해 기존 검사가 지나치게 정확한 네이티브 갱신을 가정했다. 엔진을 고치거나 오프셋으로 강제 이동하지 않았다.

정책값은 별도로 기록해 독립 기대값과1e-7cm로 검사하고, 이1축 장면의 실제위치는1e-4cm로 검사한다. 시간·커서의 정확도를 네이티브 위치 허용오차로 낮추지 않는다. 부모스케일·여러 이동축·충돌·다른 버전에 같은 수치를 일반화하지 않는다.

## 재검사와 예방

원래 실패를 보존했고 보완된 예비 실행과 최종96방법·상황이 통과했다. 정책 끝점을1e-5cm 바꾸면 실제위치 허용오차 안이더라도 거부하는 검사와 실제좌표 변형 검사를 포함해 최종30개 검사가 통과했다. 전역 강제가 아니라 이 조건의 예방 검사다.
