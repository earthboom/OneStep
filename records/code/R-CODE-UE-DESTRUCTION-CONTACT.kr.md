# 잔해의 접촉 경계 침투

CCD와반복 수만으로96조각의3cm경계가 지켜지지 않았다.30입력에서-4.672/-4.273cm,1/120초v1반복 실행에서-3.879cm를 관측했다. 실제 물리 몸체와 화면 기하 경계가 일치해 표시만의 문제는 아니었다.

같은 진단 바이너리에서 서브스텝 끔/켬 비교는 시간 단계 민감성을 확인했다. 그러나1/120초도 모든 반복에서 충분하지 않았다. 실패v1을 모두 보존하고1/240초·최대16서브스텝의 새 버전으로 세 방식 전부 다시 측정했다. 원래 경계 검사는 유지했다.

최종27정책·18실행·각3회비용·기능8개·전체770개가 통과했다. 기존v1실패는 같은 경계 검사에서 거부된다. 단일 벽·12/96상자·20초 범위이며 일반 Chaos결함·모든 하드웨어·무한 적재·비트 단위 결정론을 주장하지 않는다. 과거 Unreal 실험 결과.
