# 안개 거리 표식이 가까운 상자에 가려짐

기존x=±(180+120i),y=-300+500i 배치는 원근 투영에서 겹쳐 먼 표식 중심이 가까운 상자에 가려졌다. 선/AABB 첫 교차 검사를 먼저 실패시킨 뒤x±400으로 분리했다. 실제 네이티브 위치/크기와끔 영상의 투영 위치·흰/검정 픽셀을 매 프레임 확인한다. 가리거나 화면 밖인 표식은 명시적으로 제외한다.

초기 소광1의 반응도 약해 최종10을 사용했다. 배치와소광을 함께 보완했으므로 변화가 소광만의 통제 실험 결과라고 주장하지 않는다. 초기 숨김 스텁의 플래그 통과는 실제 픽셀 검사에서 거부됐다. 실패 자료/소스는 보존하고최종 비용에서 제외했다. 엔진·렌더러 결함이나공통 도구 개선은 아니다. 과거 Unreal 실험 결과.

로컬 시험의 원시 측정과 매체는 해당 실험 기록에 보관돼 있다.
