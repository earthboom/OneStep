# 중복 중단이 페이드를 연장한 문제

샘플 2000에서 480샘플 페이드를 시작하면 종료는 2480이어야 한다. 2100의 중복 중단이 종료를 2580으로 옮겨 2500의 재시작을 늦췄다. 네이티브 정책 검사 314개 중 2개 실패로 재현했다. 초기 50요청 파일의 실제 오디오에서 이 중복을 관측했다는 뜻은 아니다.

이미 정지 상태일 때 Apply(stop)을 다시 호출해 게인의 시작 시각을 덮어쓴 것이 원인이다. 실제 재생→정지에서만 페이드를 시작하고 중복은 원래 종료를 보존하도록 수정했다. 예약 재시작 취소는 계속 허용한다.

수정 후 정책 314개가 통과했다. 최종 51요청에는 중단 249600·중복 249624·재시작 249648을 포함했고 실제 적용은 250080이다. 11개 실행의 20초 실제 믹스가 독립 파형과 일치했다. 범위는 고정 검사음의 작은 플레이어이며 일반 오디오 동시성·음악 품질 보장은 아니다. 과거 Unreal 실험 결과.

로컬 시험의 원시 측정과 매체는 해당 실험 기록에 보관돼 있다.
