# 역방향에서 개체를 앞지른 카메라

고정 +X 시야인데 속도의 반대 방향 오프셋과 지연이 결합해 10.918초에 카메라 X=-191.57이 개체 X=-204.37보다 앞섰다. 네이티브 정책 274개 중 2개 실패로 재현했다. 실제 충돌 물리 문제는 아니다.

속도 크기는 실제 충돌 후 값으로 계산하되 오프셋 방향은 고정 리그의 뒤쪽으로 유지했다. 수정 후 정책 274개, 최종 일반 플레이어 20개의 모든 실제 시야가 통과했다. 각 실행 대상의 이동·충돌·판정 1,200단계와 진입 순서가 정확히 같았다. 일반 3D 카메라 충돌·카메라 상대 조준 보장은 아니다. 과거 Unreal 실험 결과.

로컬 시험의 원시 측정과 매체는 해당 실험 기록에 보관돼 있다.
