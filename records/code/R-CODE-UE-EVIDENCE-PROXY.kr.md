# 잘못된 네이티브 결과가 자체 일관성 검사를 통과한 문제

## 기대와 관찰

UE5.8.3 이징 검사는 상태가 맞으면 실제 전환 시간도 맞는 것으로 취급했다. 독립 검토에서 벽시계 구간을 절반으로 줄이기, 전체 시간을0으로 만들기, 이벤트 전후 값을 모두999999로 바꾸기가 기존 검사를 통과했다.

## 원인과 해결

보고된 age와 상태만 비교했고 실제 벽시계 연결이 없었다. 이벤트도 서로 같은지만 검사했다. 네이티브 이징 정책 결함은 발견되지 않았다. 보완 후에는 상황 시간에서 독립적으로 기대 이벤트 값을 계산하고 실제 시간과 age를 연결한다. 로그 시점5ms 불확실성과 마지막 클램프1기록프레임은 명시한다. 고정30시뮬레이션 캡처는 별도 시계를 검사한다.

## 재검사와 예방

세 결과 변형 검사는 보완 전 실패를 재현했고 이후 통과했다. 최종 이징30개 검사가 통과했다. 시간 스텝의 첫 비행 정점/방법 데이터 누락, 빌보드의 잘못된 중첩·반투명·그림자 허용도 유사한 예방 사례다. 특정 검사가 모든 기술을 검증한다는 뜻은 아니다.

자료 일치와 요청FPS 도달은 구분한다. 이징은 요청30/60/144에서 실제23.21/45.66/110.32프레임진행FPS였고 해당 렌더FPS는 미검증이다. 전체 자료 위조 방지나 전역CI 강제는 주장하지 않는다.
