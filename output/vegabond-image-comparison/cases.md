# 이미지 생성 비교 사례와 판정 기준

실행 조건은 Codex의 같은 내장 이미지 도구, 같은 요청과 참조, 각 경로 두 번이다. 각 작업은 요청한 산출물 수만큼 최초 호출을 하고, 각 결과에 조건 누락이 있을 경우 최대 한 번의 수정 호출을 허용한다. 참조 이미지, 첫 결과, 수정 결과를 각각 기록한다. 출력 노출 순서는 경로를 가리고 섞는다. 모든 필수 항목을 충족해야 해당 작업이 합격한다. 생성 도구가 결과를 반환하지 않으면 해당 시도를 평가 불가로 기록한다.
