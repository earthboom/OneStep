# 지식

재사용 가능한 참고 자료, 관례, 검증 방법과 확인된 교훈을 담는다. 이 색인은 분야로 안내한다. 항목의 조회·유지는 [지식 스킬](../skills/vegabond-knowledge/SKILL.kr.md)을 따른다. 각 작업 프로젝트가 자신의 저장소를 관리한다.

| 분야 | 범위 |
| --- | --- |
| [코드](code/index.kr.md) | 소프트웨어 구현, 시스템, 런타임 동작과 검증 |
| [소설](fiction/index.kr.md) | 서사 기법, 작품 맥락, 목소리, 연속성과 원고 검토 |
| [게임](game/index.kr.md) | 장르에 맞는 게임 설계와 플레이 경험, 시스템 상호작용, 프로토타입과 플레이테스트 |
| [이미지](image/index.kr.md) | 래스터 이미지 생성·편집, 캐릭터 식별 특징과 실물 제품 검수 |
| [발표](presentation/index.kr.md) | 슬라이드 논지, 자료 제작, 내용 검토와 화면 점검 |
| [기획](planning/index.kr.md) | 기획안의 내용, 실현 가능성, 의존 관계와 성공 기준 |
| [공통](shared/index.kr.md) | 여러 분야에 적용할 근거가 있는 자료 |

실제 내용이 생길 때 새 분야와 세부 항목을 만든다. 예시용 사실이나 사고를 미리 등록하지 않는다.
