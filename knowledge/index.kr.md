# 지식

참고자료, 관례, 검증 방법, 근거가 확인된 재사용 교훈입니다.

이 색인은 분야로만 연결합니다. 항목 조회와 관리는 [vegabond-knowledge](../skills/vegabond-knowledge/SKILL.md)를 사용합니다. 이 저장소는 현재 작업 프로젝트에 속하며 전역 목록이 아닙니다.

| 분야 | 범위 |
| --- | --- |
| [코딩](code/index.md) | 소프트웨어 구현, 시스템, 실행 동작, 검증. |
| [소설](fiction/index.md) | 서사 창작, 작품 맥락, 문체, 연속성, 원고 검토. |
| [발표자료](presentation/index.md) | 슬라이드 논지, 덱 제작, 내용 검증, 시각 검수. |
| [기획서](planning/index.md) | 기획·제안서 내용, 실행 가능성, 의존 관계, 성공 지표. |
| [공통](shared/index.md) | 여러 분야에 적용됨이 확인된 자료. |

실제 내용이 필요할 때 새 분야를 추가합니다. 상세 항목은 실제 자료가 있을 때만 만들고, 예시 사실이나 사건을 미리 채우지 않습니다.
