# 지식

참고 자료, 관례, 검증 방법, 확인한 재사용 지식을 모은다.

이 색인은 도메인으로 연결한다. 지식을 찾거나 유지할 때는 [vegabond-knowledge](../skills/vegabond-knowledge/SKILL.kr.md)를 사용한다. 이 저장소는 현재 작업 프로젝트에 속한다.

| 도메인 | 범위 |
| --- | --- |
| [코드](code/index.kr.md) | 소프트웨어 구현, 시스템, 실행 시 동작, 검증 |
| [소설](fiction/index.kr.md) | 서사 기법, 이야기 맥락, 문체, 연속성, 원고 검토 |
| [게임](game/index.kr.md) | 장르별 게임 설계, 플레이어 경험, 시스템 상호작용, 프로토타입, 플레이테스트 |
| [이미지](image/index.kr.md) | 래스터 이미지 생성·편집, 캐릭터 정체성, 실물 상품 검수 |
| [프레젠테이션](presentation/index.kr.md) | 발표 논리, 슬라이드 제작, 내용 확인, 시각 검수 |
| [계획](planning/index.kr.md) | 계획과 제안서, 실현 가능성, 의존성, 성공 판단 기준 |
| [공통](shared/index.kr.md) | 여러 도메인에서 적용할 수 있음이 확인된 자료 |

실제 내용에 필요한 도메인을 추가한다. 상세 항목에는 실제 자료를 기록한다.
