# Historical Novel_0 research-use configuration

## Guidance

Historical workflow only: the former setup below is retained as evidence of prior use, not as current instructions to locate, configure or connect an external project. Use the active skills and the working project's own instructions for new work.

1. Scout identifies the target work, chapter/scene, intended change, preservation conditions, operation, scale, and checks. For a new draft use create; for an authorized edit use revise, with fiction methods inside that operation.
2. Knowledge queries the current project's routing index and this explicitly configured shared OneStep fiction catalog. Search relevant English concepts and Korean aliases, selecting up to three matching details initially. Do not load the entire research library for every scene.
3. Return source locations, usable guidance, applicability/exception conditions, canon and voice constraints, useful checks, and missing evidence. Retrieve the current work's original canon, scene state, character information, planned disclosure, and author-selected voice references separately.
4. Before drafting, turn that brief into concrete choices: which route or posture must be established, what the focal character can know, which detail carries the emotion, and what cost or aftermath persists. Resolve actual dependencies before using them to determine a result.
5. Draft or revise in Korean, then read the complete affected scene for causality, plausibility, continuity, reader comprehension, voice, and form. A citation or a clean catalog is not sufficient verification of prose.
6. Record material corrections and reusable findings through knowledge in the authorized project scope; retain author preferences and story facts in their owners. Refresh affected summaries when sources change.

For a gate-defense scene, start with blocking, body motion, and scene staging; read other entries only if equipment, history, or ability design creates a concrete dependency. For a breakthrough, use attainment language, breakthrough cases, and the owning martial canon. Apply principles rather than copying example wording.
