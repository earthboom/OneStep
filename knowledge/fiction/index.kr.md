# 소설 지식

사람 전용 번역. 영문 상세의 메타데이터와 영문 색인을 바탕으로 작성했다. AI는 이 파일을 읽거나 검색하지 않는다. 서사·작품 맥락·문체·연속성·원고 검토를 다룬다.

[분야 안내](../index.md) | [저장과 수명 관리](../../skills/vegabond-knowledge/references/storage.md)
