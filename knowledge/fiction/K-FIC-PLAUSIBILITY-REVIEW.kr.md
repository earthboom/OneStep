# 범위가 있는 진술과 확인 가능한 본문으로 핍진성 판단하기

- ID: `K-FIC-PLAUSIBILITY-REVIEW`
- 유형·상태·확인일: 방법, 활성, 2026-11-17
- 범위: 제공된 원고·설정·작가 의도에 따른 소설 설계·검토. 검증된 AI 탐지기나 객관적 문학 점수가 아닌 편집적 종합입니다.
- 검색어: plausibility-review, verisimilitude, logic, rationality, consistency, epistemic, 핍진성검토, 개연성평가, 논리검토, 인물합리성, 모순판정, 정보접근, 판단보류
- 근거: [연구 장부](K-FIC-RESEARCH-PLAUSIBILITY.md)와 기존 원고 평가. 실제 적용·구성 예제는 연결한 기록에 둡니다.

## 지침

기존 원고·설계 검토 안에서 사용합니다. TRIP·IPOCL·ConStory-Checker를 구현한 기능이 아니라 연구를 참고해 정제한 절차입니다.

### 무엇을 판단할 수 있는지 정하기

제공된 범위와 중요한 맥락을 읽고 판본·이야기 시점·장르와 전제·서술자·초점 인물·작가의 보존 조건·없는 장을 확인합니다. 환상적인 행동 자체가 전제를 제시할 수 있습니다. 지금 판단에 필요한 단서만 요구하며 세계관 백과사전을 요구하지 않습니다. 발췌문으로 장편 전체의 일관성을 보장하지 않습니다.

논점의 대상·상태·시간·세계 또는 분기·출처·지식 상태를 보존합니다. 사실로 제시한 사건과 대사·거짓말·믿음·기억·추측·비유·가정을 나눕니다. 서로 다를 때는 독자와 각 인물이 접근한 정보를 별도 칸에 둡니다.

### 중요한 상태 변화 확인

필요한 만큼만 다음을 적습니다.

`이전 상태·조건 → 행위자의 정보·믿음·목표 → 행동·비용 → 이후 상태·결과`

소유·위치·시간·능력·규칙·선행 조건을 제시한 본문을 찾습니다. 뒤의 사건이 필요로 하는 조건을 본문이 명시적으로 부정하는지, 그 사이 무엇이 바뀌었는지 확인합니다. 단순한 순서와 인과를 나눕니다. 인물의 선택은 그 믿음과 압박 속에서 무엇을 지키거나 얻으려는지 봅니다. 실패한 계획·손해 보는 친절·공황·오판을 자동으로 논리 오류라고 하지 않습니다. 면책을 위해 과거 상처·비밀 능력·없는 메시지를 만들지 않습니다.

### 판정을 검토 가능하게 만들기

| 항목 | 남길 내용 |
| --- | --- |
| 대상과 위치 | 실제 행동·진술과 본문 위치 |
| 적용 조건 | 규칙·이전 상태·기대의 다른 본문 위치. 명시 사실과 잠정 추론을 구분 |
| 충돌 방식 | 무엇이 함께 참일 수 없는지, 어느 선행 조건이 어긋나는지, 어느 필수 연결의 근거가 없는지 짧게 설명 |
| 가장 강한 대안 | 본문이 지지하는 시간·세계·상태 변화·정보 접근·기만·불신뢰 서술·생략을 확인. 설명에 새로 필요한 가정도 표시 |
| 결론과 불확실성 | 입증된 오류 / 미해결·근거 부족 / 입증된 오류 없음. 강점과 선택적 명료성 제안을 구분하며 근거 없는 확률을 붙이지 않음 |
| 다음 행동 | 필요한 최소 수정 또는 질문, 기대 이득·보존할 점·손실과 의존 관계 재확인. 오류가 없으면 수정이 필요하지 않음 |

입증된 모순에는 같은 관련 조건에서 양립하지 않는 진술이나 상태가 필요합니다. 서술되지 않았다는 것만으로는 부족합니다. 독자 이해에 꼭 필요한 설명이 없다면 연결의 부족과 불확실성을 보고할 수 있지만, 불가능한 동작이라고 단정하거나 원인을 대신 만들지 않습니다. 생략 가능성과 의도한 생략의 확인도 다릅니다.

### AI 판정 보정

외부 사실이나 수량의 판단에 필요하면 적절한 원자료나 계산을 사용합니다. 역사·기술·문화 근거를 모델의 익숙함으로 대신하지 않고 미확인 상태를 표시합니다. 기계 검사는 명시된 가정 아래 날짜·수량·위치를 확인할 수 있지만 자연어 추출과 가정은 따로 검토합니다.

장편은 최근 요약이나 상위 검색 결과뿐 아니라 연결된 앞뒤 구절과 미해결 판정을 확인합니다. 맥락이 바뀌면 다시 판단합니다. 중요한 판본 비교에서는 원본을 보존하고 필요할 때 표지·순서 영향을 줄입니다. AI끼리의 일치는 추가 분석이지 독자 연구나 독립된 진실이 아닙니다. 새 근거 없이 더 많은 결함을 요구하는 반복은 검증의 개선과 다릅니다.

## 적용 조건과 예외

물리적 현실성·내부 정합성·동기·도덕성·발생 확률·예술적 성취를 섞지 않습니다. 우연은 장면별로 평가하고 근거 없는 수치나 보편적인 우연 허용 횟수를 만들지 않습니다. 목적 있는 선택도 비효율적이거나 실패하거나 현명하지 않거나 잔인할 수 있습니다. 사회적 금지는 물리적 불가능성과 다르며 집행과 결과는 맥락에 달립니다.

본문이 지지하는 미스터리·꿈의 논리·불신뢰 서술·관계 변화·불확실성을 보존합니다. 반대로 장르명만으로 명시된 예외 없는 규칙의 충돌을 고칠 수 없습니다. 비난하거나 면책하기 전에 본문이 지지하는 가장 강한 대안을 확인합니다.

## 확인

- 다른 검토자가 결정적 인용과 위치를 같은 판본에서 확인할 수 있는가?
- 충돌의 양쪽은 같은 시간·세계·진술 층위인가?
- 모름·근거 없음·명시적 거짓을 나눴는가?
- 검토자의 이상적 선택이 아니라 인물의 목표와 믿음에서 판단했는가?
- 없는 설정을 만들지 않고 대안을 확인했는가?
- 분류가 수정의 크기를 정당화하며 목소리·유효한 모호성을 보존하는가?
- 수정 뒤 상태·정보·후속 결과를 다시 확인했는가?

## 근거

V01~V10의 전이 한계와 기존 구절 중심 평가를 함께 사용합니다. 이는 사람의 독립 주석을 받은 벤치마크나 일반 모델 정확도 추정이 아닙니다. 결론이 맞아도 본문 근거가 틀리면 이번 확인은 충분하지 않습니다.
