# 확정된 명중 결과와 다음 행동을 중심으로 타격 연출을 설계한다

## 지침

입력·버퍼 → 준비 동작 → 권한 있는 판정 → 접촉 피드백 → 회복을 따라간다. 준비 동작과 공격 범위로 위협을 읽게 한다. 확정된 위치·방향·반응으로 빗나감, 방어, 명중과 기타 결과를 구분한다. 확정된 결과마다 적절한 키로 피드백 이벤트를 한 번 발생시킨다. 회복 중에도 다음 위협, 조준과 이동할 공간이 보여야 한다.

히트스톱의 적용 범위와 중첩 상한 또는 합치기 규칙을 정한다. 버퍼 입력, 물리, 콤보 시간, 재사용 대기시간과 시청각 재생 시간이 어떻게 진행되는지 명시한다. 히트스턴은 행동을 제한하는 별도의 규칙으로 정한다. 실제 전투 구도에서 카메라의 방향과 감쇠를 조정한다. 같은 음량에서 접촉음의 첫 소리, 재질과 몸통 소리, 잔향을 비교한다. 출력 지연과 반복 공격에서 가려지는 신호를 확인한다.

## 적용 범위와 예외

플레이어가 연출용 흔들림, 움직임과 진동을 줄여도 판정과 필수 신호를 유지한다. 기기에 진동이 없거나 설정에서 효과를 껐을 때 시각과 소리로 필요한 정보를 받을 수 있다. 실제 조준에 영향을 주는 반동에는 게임 규칙을 적용한다. 리듬을 맞추는 동작에는 오디오와 입력 기준 시각을 명시한다.

## 확인

같은 공격을 빗나감, 방어, 몸에 명중하는 경우로 실행한 뒤 다단 공격과 재시작을 시험한다. 판정, 이벤트 방향과 횟수, 입력 회복을 검사한다. 대표 화면·입력·오디오 기기에서 효과를 줄이고 플레이한다. 결과와 다음 행동을 알아볼 수 있는지 관찰하면서 연출 요소를 한 번에 하나씩 바꿔 비교한다.
