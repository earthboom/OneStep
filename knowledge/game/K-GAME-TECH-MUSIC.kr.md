## 원리와 구현 요점

수직 레이어링은 동기화된 스템, 수평 재배열은 호환 음악 구간을 사용한다. 게임 상태를 음악 강도로 바꾸고 박·마디·제작된 큐에 맞춰 전환한다. 템포·박자·진입·종료점·전환 구간·크로스페이드 정책을 관리한다.

구현 선택과 점검은 출처를 바탕으로 한 실무적 종합이며 특정 게임의 정확한 구현을 보증하지 않는다.

## 적용 조건과 한계

클립을 무작위로 이어도 음악적 연속성이 보장되지 않는다. 용어 차이가 있어 실제 재생 동작을 명시한다. 짧은 전투 상태 변화마다 음악이 재시작되지 않게 한다.

## 적용 전 점검

적용 전 점검: 여러 박 위치에서 모든 전환·급반전·로딩 멈춤을 유발하고 위상·절단음을 청취한다.
