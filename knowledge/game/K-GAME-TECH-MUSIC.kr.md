## 원리와 구현 요점

수직 레이어링은 동기화된 스템, 수평 재배열은 호환 음악 구간을 사용한다. 게임 상태를 음악 강도로 바꾸고 박·마디·제작된 큐에 맞춰 전환한다. 템포·박자·진입·종료점·전환 구간·크로스페이드 정책을 관리한다.

구현 선택과 점검은 출처를 바탕으로 한 실무적 종합이며 특정 게임의 정확한 구현을 보증하지 않는다.

## 적용 조건과 한계

클립을 무작위로 이어도 음악적 연속성이 보장되지 않는다. 용어 차이가 있어 실제 재생 동작을 명시한다. 짧은 전투 상태 변화마다 음악이 재시작되지 않게 한다.

### vertical layering

**수직 레이어링(vertical layering)**은 같은 음악 시간축에 맞춘 스템을 더하거나 빼서 믹스를 바꾼다. **수평 재배열(horizontal resequencing)**은 음악적 경계에서 호환되는 다른 구간으로 이동한다. 템포 맵은 템포가 변해도 박이나 마디 위치를 재생 시각에 대응시킨다. 템포 변경 전후에 전환을 요청하고 못갖춘마디나 잔향까지 실제 연결을 들어 확인한다. ### 구현한 동작

하나의 네이티브 USoundWaveProcedural 소스에서 고정 검사음 A 440Hz, B 660Hz, 추가 레이어 990Hz를 혼합한다. 새 곡의 작곡·생성 음악은 하지 않았다. 각각 고정 1초 PCM 표이며 48kHz·120BPM·4/4를 공유한다. 박은 24,000샘플(0.5초), 마디는 96,000샘플(2초)이다. 오디오 샘플 카운터가 위상과 전환을 소유한다.

이번 구현은 Quartz 검증이 아니다. Quartz 재생 예약에 레이어 제거·정지·반전을 원자적으로 결합하는 엔진 확장을 추가하는 대신, 작은 플레이어 내부에서 샘플 경계를 처리했다. 새 애셋·외부 플러그인·의존성·렌더러·공통 검증 도구 변경은 없다.

예약 방식은 요청 샘플 f, 위상 원점 O, 경계 간격 Q에 대해 O+ceil((f-O+4800)/Q)×Q를 선택한다. **최소 100ms 준비 시간을 포함하는 첫 경계**이며 정확한 한계는 허용하고 한 샘플만 늦어도 다음 경계로 넘긴다. 즉시 방식은 요청 샘플에서 적용한다.

구간과 레이어는 별도 대기 슬롯을 사용한다. 같은 대기 요청은 원래 경계를 유지하고, 현재 값으로 되돌리는 요청은 대기 반전을 취소한다. 구간은 A/B를 교차 페이드하고 레이어는 자기 게인만 변경한다. 전환 중 위상을 재시작하지 않으며 페이드는 480샘플(10ms)이다.

중단은 예약을 취소하고 무음으로 페이드한다. **중복 중단은 페이드를 연장하지 않는다.** 재시작은 정지 후 시작을 뜻하며, 아직 중단 페이드 중이면 무음까지 기다린 뒤 A·레이어 없음·새 위상으로 시작한다. 재생 중의 재시작 요청은 중복으로 처리한다. 강제 처음부터 재생 기능은 아니다.

### 실제 출력 검증과 수정한 문제

정책 검사 314개와 실제 PIE·패키지 × 즉시·예약의 4개 월드가 통과했다. 실행마다 같은 51개 요청을 샘플 시각으로 미리 제출했다. 박·마디 경계 전후 한 샘플, 빠른 반전, 중복, 독립 예약, 준비 시간 부족, 예약 중 중단, 중복 중단, 페이드 중 재시작과 정상 재시작을 포함한다. 임의의 실시간 게임 스레드·네트워크 입력 지연을 검증한 것은 아니다.

예약은 27개, 즉시는 45개 실제 변경을 적용한다. 같은 51개 제공 요청을 정책에 따라 병합한 결과이며 누락으로 숨기지 않는다. 네이티브 정책을 호출하지 않는 독립 Python 계산으로 입력 결과·적용 샘플·전체 파형을 만든 뒤, **최종 11개 실행마다 실제 믹스 96만 샘플**을 대조했다. 실행당 하나의 전체 출력 게인만 맞추고 구간마다 따로 맞추지 않았다. 상대 레이어 크기·위상·시각·무음이 검사 대상이며 절대 음량·물리 장치 지연 보장은 아니다.

11개 실행의 최대 원시 출력 상대 RMS 오차는 2.96708640568e-07이다. 잘못된 경계·상태·스테레오, 음소거·누락, 레이어 전환 1프레임 지연, 과도한 미보고 시작 지연을 수정된 오류 검출 검사에서 거부했다.

초기 모델은 48개 중 42개 실패 후 통과했다. 추가 중복 중단 검사에서 **314개 중 2개 실패**를 재현했다. 중단 페이드가 다시 시작돼 재시작이 늦어지는 실제 정책 결함을 고쳤고 314개가 통과했다. 실제 오디오의 최종 요청에도 중복 중단을 넣어 확인했다.

숨겨진 PIE에서는 에디터가 백그라운드 음량을 0으로 덮어써 실제 검증이 실패했다. 기존 공간 음향 실험처럼 백그라운드 오디오를 일시 허용하고 원래 설정으로 복원했으며 설정 파일은 저장하지 않았다. 실패한 실행은 보존했다.

최종 읽기 전용 검토에서는 오류 검출 테스트가 보존된 실패 실행을 기준으로 읽어 거짓 통과하는 문제를 찾았다. 변경하지 않은 정상 기준이 먼저 통과해야 한다는 검사를 추가하니 기존 기준이 오류 1개·실행 검사 0개로 실패했다. 올바른 v2 기준으로 바꾼 뒤 8개 검사가 통과했고 전체 746개도 다시 실행했다. 수정 전 통과 로그는 최종 근거로 사용하지 않는다.

### 동일 조건에서 방식별 3회 비용

같은 3개 고정 표·51개 요청·20초 시나리오·소스 1개·1280×720·DX11·Development·FPS 제한 및 VSync 없음으로 실행했다. 순서는 즉시/예약, 예약/즉시, 즉시/예약이다. 소스 시간 2~18초에서 같은 512프레임 콜백과 **767,488개 스테레오 소스 프레임**을 측정했다. 모든 방식에서 실제 마스터 PCM 기록을 켰으므로 그 공통 실험 경로를 포함한 비용이다.

### 화면과 촬영 조건

네이티브 600프레임·20초·시뮬레이션/재생 각 30의 1배속 영상이다. 실제 마스터 PCM을 AAC로 인코딩하고 다시 전체 디코딩했다. 기준 대비 상관계수는 0.999987854850, 상대 RMS는 0.004993243다. 원본과 디코딩 각각 600개 serial과 1,800개 게인 막대를 확인했고 실제 스크린샷 6장을 직접 확인했다.

HUD는 가장 최근 생성된 소스 버퍼를 표시하므로 믹스 재생보다 앞설 수 있다. 측정한 최대 소스/재생 차이는 30.667ms, 세계 시간/재생 시계 차이는 0.001041ms다. 시작·끝 여백만 잘랐고 속도 변경·대체 오디오는 없다. 실제 30FPS 처리량·물리 장치 지연·주관적 음악 품질이나 수동 청취를 인증한 것은 아니다.

### 적용 조건

위상을 공유하는 레이어와 호환 가능한 구간을 바꿀 때 샘플 시계·독립 예약·명확한 늦은 요청 정책을 재사용한다. 설정·콜백·HUD만으로 실제 들리는 시각을 인정하지 말고 출력 믹스를 확인한다. 고정 템포·박자·3개 검사 표·소스 1개·순서 있는 요청 최대 256개·1시간 이내 요청 영역이며 이번 플레이어는 20.5초에 종료한다.

일반 스트리밍·압축 음원·템포 맵·무한 시계·실시간 입력 지터 계약·음악 품질·다중 음원 규모의 성능은 미검증이다. 장치 없음·교체·강제 종료·녹음 조기 중단의 복구도 검사하지 않았다. 작곡·생성 음악·리듬 게임·외부 플러그인·렌더러·공통 검증 도구 확장은 제외했다. 이전 실제 FPS 누락도 유지한다.
