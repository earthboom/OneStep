# How can a character read consistently in a portrait, sprite and imported animation?

## Guidance

Give the portrait an acting beat and test it in the real dialogue slot. In the game camera, preserve identifying contour, value or color blocks and prop location; simplify small costume detail. Use separate identity, camera and pose references if a portrait keeps imposing its own framing. Evaluate expression, facing and action at their respective display sizes. [Supergiant developer interview](https://www.gamedeveloper.com/design/how-supergiant-added-new-goddess-demeter-to-i-hades-i-pantheon) · [Ye et al., IP-Adapter](https://arxiv.org/abs/2308.06721) · [Valve character art guide](https://help.steampowered.com/en/faqs/view/0688-7692-4D5A-1935) · [Medeiros’s pixel art lessons](https://saint11.art/pixel_articles/)

Choose hand-drawn cels when each silhouette must change freely. Use parts, slots and bones when skins reuse movement; inspect crossings, rotated pixels and draw order. For many views and equipment sets, compare the revision cost of a shared 3D rig baked into sprites against the textures and cleanup it generates. A hybrid can reserve bespoke keys for strong silhouettes. Keep the editable artwork, rig, palette and export settings identifiable. Test on two representative variants before estimating the rest of the cast. [Aseprite sprite sheets](https://aseprite.org/docs/sprite-sheet/) · [Cuphead production talk](https://www.gdcvault.com/play/1024315/Animation-Bootcamp-Cuphead-Process-and) · [Spine keys and timelines](https://us.esotericsoftware.com/spine-keys) · [Unity PSD Importer](https://docs.unity3d.com/Packages/com.unity.2d.psdimporter%4010.0/manual/index.html) · [Thomas Vasseur on making Dead Cells](https://www.gamedeveloper.com/production/art-design-deep-dive-using-a-3d-pipeline-for-2d-animation-in-i-dead-cells-i-) · [Skullgirls animation talk](https://gdcvault.com/play/1020575/) · [Lasseter paper](https://www.cs.utexas.edu/~fussell/courses/cs384g-fall2011/projects/animator/lasseter.pdf) · [Unity 2D Animation](https://docs.unity3d.com/Packages/com.unity.2d.animation%4010.0/manual/index.html) · [Spine runtimes](https://en.esotericsoftware.com/spine-using-runtimes/)

Give clips semantic keys such as idle or talk, with direction, skin, loop and transition policy. Distinguish drawing index, exposure and game tick. Draw contact and passing poses before filling transitions. Fix camera and scale; choose where displacement comes from. A stationary pivot should preserve both ground contact and the character's intentional rise, fall or squash. ## Applicability and exceptions

Hand-drawn production may involve large binary masters. Choose file locking or large-file storage around the team's actual edit workflow; Git LFS tracks configured path patterns and Perforce can support exclusive checkout. Keep the export recipe with the editable source. An Aseprite CLI export can regenerate a sheet and its data; inspect the resulting asset in the project's selected Paper 2D or other runtime. [Cuphead GDC](https://gdcvault.com/play/1024315/Animation-Bootcamp-Cuphead-Process-and) · [Aseprite CLI](https://aseprite.org/docs/cli/) · [Git LFS](https://docs.github.com/en/repositories/working-with-files/managing-large-files/configuring-git-large-file-storage) · [Unreal Perforce](https://dev.epicgames.com/documentation/en-us/unreal-engine/using-perforce-as-source-control-for-unreal-engine) · [Unreal Paper 2D](https://dev.epicgames.com/documentation/en-us/unreal-engine/2d-in-unreal-engine)

A still commission only needs its own acceptance check. A stable similarity score can hide an almost motionless cycle. Video synthesis can supply candidates; it does not demonstrate transparent cels or game contact. If a pose detector fails on a stylized body, use an authored sketch. One human-portrait study favored motion before pixelation on four metrics; compare this route with a hand-cleaned low-resolution key for the project's characters. [Hu et al., paper](https://openaccess.thecvf.com/content/CVPR2024/papers/Hu_Animate_Anyone_Consistent_and_Controllable_Image-to-Video_Synthesis_for_Character_Animation_CVPR_2024_paper.pdf) · [Hsieh et al., experiments and Table 1](https://arxiv.org/abs/2412.03685) · [Wong et al., comparison and data description](https://marcovolino.github.io/docs/papers/2025-wong-cvmp.pdf) · [Fischer’s production video](https://www.youtube.com/watch?v=Ffl8b_GfJ-M)

## Checks

- Overlay the original poses at their intended pivot. If the prop already jumps, adjust the drawing. If jitter starts only after slicing, reconstruct using atlas rectangle, source canvas (`sourceSize`), trim offset/extent (`spriteSourceSize`) and duration. Fixed cells can share one canvas and origin. Inspect the exported loop with shipping movement speed and compare a planted foot against the world. Mirror only after checking asymmetry, grip, letters and light. [Aseprite author’s JSON example](https://community.aseprite.org/t/how-to-process-the-generated-json-sprite-sheet/34) · [Godot 2D animation documentation](https://docs.godotengine.org/en/stable/tutorials/2d/2d_sprite_animation.html)
- In Unity verify that Aseprite tags or layered PSD/PSB sources yield the intended clips after reimport. In Unreal Paper 2D, verify region, units and pivot, then play the Flipbook with its FPS and key holds. Map semantic keys to regions on import so repacking cannot change character or expression. [Unity PSD Importer](https://docs.unity3d.com/Packages/com.unity.2d.psdimporter%4010.0/manual/index.html) · [Unity Aseprite Importer features](https://docs.unity3d.com/Packages/com.unity.2d.aseprite%403.0/manual/ImporterFeatures.html) · [Unreal Flipbooks](https://dev.epicgames.com/documentation/en-us/unreal-engine/paper-2d-flipbooks-in-unreal-engine) · [Paper 2D Sprite Editor](https://dev.epicgames.com/documentation/unreal-engine/paper-2d-sprite-editor-in-unreal-engine) · [TexturePacker metadata export](https://www.codeandweb.com/texturepacker/documentation/custom-exporter) · [Import Sprites](https://dev.epicgames.com/documentation/unreal-engine/import-sprites-in-unreal-engine)
- At shipping scale, test bleeding, extrusion, rotated packing, alpha, compression and filters. Group atlases by actual simultaneous use, compatible material/draw order and load lifetime. Compare package size, resident texture memory, load and release across two regions. Rectangle occupancy and PNG bytes alone cannot predict those costs. ## Evidence

In a static portrait and 64×64 gameplay sprite trial, the broad forelock and orange scarf remained visible at 1×. The key could read as generic gold trim. The portrait was inspected with an overlay and the sprite on two mock backgrounds. Engine import and locomotion were outside this trial.
