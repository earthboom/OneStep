# 사전 파쇄·런타임 파괴 선택

기준 항목: K-GAME-TECH-DESTRUCTION · 확인일: 2026-11-07 · 상태: 참고 지식. 실제 엔진 구현·성능·플레이테스트는 수행하지 않았다.

## 원리와 구현 요점

장식적 피해는 모델 교체와 파편 연출로 충분할 수 있다. 게임플레이 파괴는 Geometry Collection·클러스터·충돌·파괴 임계값을 설계한다. 미리 나눈 조각의 물리 시뮬레이션과 런타임 절단은 구분하고 표면 자국은 데칼로 처리한다.

구현 선택과 점검은 출처를 바탕으로 한 실무적 종합이며 특정 게임의 정확한 구현을 보증하지 않는다.

## 적용 조건과 한계

사전 파쇄가 미리 정해진 애니메이션을 뜻하지 않는다. 물리·내비게이션·네트워크 상태·영구 손상은 시각적 파괴와 일치해야 한다.

## 적용 전 점검

적용 전 점검: 반복 충격·끼인 파편·저장 복원·멀티플레이 권한을 확인하고 지속 파편 수를 제한한다.

### 구현과 검증

480×24×240cm 벽을 미리 구성한12조각(4×3)/96조각(12×8)으로 교체해 Chaos 강체로 움직인다. 조각 사이 틈은0.4cm다. Geometry Collection 클러스터 파괴나 런타임 절단을 구현한 것은 아니다. 조각은 시나리오 전에 만들고,물리 활성화·충돌 설정·충격 적용은 파괴 CPU 시간에 포함한다. 제거 후에는 표시·물리·충돌을 해제하고 재사용 풀로 돌리므로 구성요소 메모리는 유지한다.

활성 조각의 총질량12kg,공간 좌표 기반 초기 속도(550+.1x,-120+.05z,110+.05z)cm/s를 공유한다. CCD와 개별 해석 반복32/8/4,최대 물리 단계1/240초·프레임당 최대16서브스텝을 사용한다. 고정240Hz 실행이나 실제 렌더링 FPS 인증은 아니다. 이전 런타임 물리 설정의 bool/float/int를 정확히 복원하고 실제 PIE 종료 뒤에도 확인했다. 물리 설정은 프로세스 공통이므로 단일 시험/소유자 조건이며 서로 다른 설정의 여러 월드를 동시에 운영하는 경우는 검증하지 않았다. 설정 파일·기존62애셋·의존성·렌더러·공통 도구는 바꾸지 않았다.

임계값100포함,요청ID 중복 방지,세대별 리셋을 적용했다. 같은18입력으로99→중복99→+1,파괴 후 반복,새 세대101초과,50+49+1,잘못된ID/음수,ID 재사용과정확100을 검사했다. 실행마다논리 파괴5회·수명 만료4회·활성 도중 리셋1회다. 수명3초 후 충돌 질의0,시뮬레이션·표시 해제,속도·각속도·원래 위치/회전 복원을 확인했다. 끔은 같은 논리 요청을 받는 정상 벽 기준이며 물리적 통행 가능성을 다른 방식과 같다고 주장하지 않는다.

정책27개,실제 PIE/패키지6월드와비용9개·영상3개 실행에서 실제 접촉·위치·회전·속도·질량·제거·리셋을 독립 확인했다. 바닥·벽·조각 사이 양의 충격량 콜백을 기록했다. 콜백 수는 서브스텝·지속 접촉의 반복을 포함하며 고유 충돌 횟수가 아니다. 상세 접촉 기록은4096개까지,전체 콜백 카운터는 계속 유지한다. 실시간 자세 상세 감사는20Hz,영상은 매 프레임이며 경계·상태 검사는 매 프레임이다.

경계는 바닥 최저점≥-3cm,벽 안쪽 면380cm에 대해최고X≤383cm다. 최종18실행의 관측 최저 바닥은 **-1.670564cm**,최고X는 **380.319561cm**였다. 미세 침투0을 보장하는 조건은 아니다.

### 실패와 보완

초기 정책24개 중16개 실패,충격 정규화27개 중3개 실패를 보존했고 최종27개가 통과했다. 초기30시뮬레이션 시험은 바닥-4.672cm로 실패했다. 반복 수와 질량·충격 보완 뒤에도-4.273cm였다. 같은 진단 바이너리에서 서브스텝 끔/켬만 비교하자 끔은실패,최대1/120초는통과했으나 이후v1반복 측정에서 한 프레임-3.879cm가 다시 발견됐다.

v1소스·버전·부분 측정·실패를 Results/Destruction/v1에 모두 보존하고 최종 비용에서 제외했다. 최대1/240초로 바꾼 새 버전에서 동작과9회 비용·영상을 전부 새로 실행했다. 통과한 실행만 골라 사용하지 않았다. CCD·반복 수 설정만으로 안전성을 인정하지 않고 실제 물리/화면 경계를 확인한다.

### 화면과 촬영 조건

### 적용 조건

미리 정한 토폴로지의 작은 재사용 파괴 물체에 적용한다. 피해/중복·세대·몸체 활성화·수명·리셋·화면 반응을 분리하고 실제 접촉과 제거 질의를 검사한다. 사전 생성·풀 메모리를 별도로 예산에 넣는다. 단일 벽·알려진 면·12/96조각·20초·한 장비의 한정된 검증이며,실제 궤적이 실행/프레임 스케줄마다 비트 단위로 같다는 보장은 없다.

아트 품질의 균열·Geometry Collection 클러스터·하중 구조물·붕괴·내비게이션·스키닝·파괴 에너지 보존·무한 실행/장기 히치/장치 변경은 검증하지 않았다. 런타임 절단·건물 붕괴·네트워크·저장·렌더러·공통 도구 개선으로 확장하지 않았다.

기능8개·전체Python770개와 기존그림자46·핵심PIE/패키지각73개가 통과했다. 기존manifest소스아카이브34개+이전폴더1개/7764파일·애셋62개를 보존했다. 최신29개 부분 구현·14개 전용 구현 없음이며 V54비밀번호는 미구현이다. 커밋·푸시하지 않았다.
