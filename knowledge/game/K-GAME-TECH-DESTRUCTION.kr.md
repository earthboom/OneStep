# 사전 파쇄·런타임 파괴 선택

기준 항목: K-GAME-TECH-DESTRUCTION · 확인일: 2026-11-07 · 상태: 참고 지식. 실제 엔진 구현·성능·플레이테스트는 수행하지 않았다.

## 원리와 구현 요점

장식적 피해는 모델 교체와 파편 연출로 충분할 수 있다. 게임플레이 파괴는 Geometry Collection·클러스터·충돌·파괴 임계값을 설계한다. 미리 나눈 조각의 물리 시뮬레이션과 런타임 절단은 구분하고 표면 자국은 데칼로 처리한다.

구현 선택과 점검은 출처를 바탕으로 한 실무적 종합이며 특정 게임의 정확한 구현을 보증하지 않는다.

## 적용 조건과 한계

사전 파쇄가 미리 정해진 애니메이션을 뜻하지 않는다. 물리·내비게이션·네트워크 상태·영구 손상은 시각적 파괴와 일치해야 한다.

## 적용 전 점검

적용 전 점검: 반복 충격·끼인 파편·저장 복원·멀티플레이 권한을 확인하고 지속 파편 수를 제한한다.
