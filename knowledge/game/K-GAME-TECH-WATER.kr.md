# 사인파·거스너파 수면

기준 항목: K-GAME-TECH-WATER · 확인일: 2026-11-07 · 상태: 참고 지식. 실제 엔진 구현·성능·플레이테스트는 수행하지 않았다.

## 원리와 구현 요점

진폭·파장·방향·위상을 가진 파동들을 합해 수면을 만든다. 거스너파는 표면점을 수평으로도 움직여 더 뾰족한 마루를 표현한다. 같은 변위장에서 노멀을 계산하고 부력 판정에도 호환되는 수면 질의를 제공한다.

구현 선택과 점검은 출처를 바탕으로 한 실무적 종합이며 특정 게임의 정확한 구현을 보증하지 않는다.

## 적용 조건과 한계

접힘을 피하도록 가파름을 제한한다. 파동 합은 완전한 유체 시뮬레이션이 아니며 쇄파·해안·장애물 유동을 자동 처리하지 않는다.

## 적용 전 점검

적용 전 점검: 상공 반복 무늬·얕은 해안·부유 물체·시뮬레이션 주기별 차이를 확인한다.

## Gerstner waves의 적용과 확인

게르스트너파는 수평 변위를 포함하므로 정점의 원래 수평 좌표와 렌더 위치가 다를 수 있다. 부력 검사에서는 같은 월드 좌표와 같은 시각에서 게임이 조회한 높이와 렌더된 수면을 비교한다. 경사가 큰 마루에서 차이를 확인하기 쉽다.

검색어 · Gerstner waves, horizontal displacement, buoyancy

[Mark Finch, Effective Water Simulation from Physical Models](https://developer.nvidia.com/gpugems/gpugems/part-i-natural-effects/chapter-1-effective-water-simulation-physical-models)은 용어와 적용 조건의 근거다. 제안한 검사는 대상 환경에서 수행한다.

## 사인파·Gerstner 수면 — 언리얼 실제 검증

사인파 합성과 Gerstner 파동을 비교하고 가파름 예산으로 접힘을 막는다. 측정 범위는 CPU 절차적 기하다.

UE5.8.3 Win64 Development/DX11에서 검증했다. 기준일은 2026-11-14(한국시간)이며 실행 기록에는 UTC를 사용한다. **AI 검증 완료, vagabond 테스트·리뷰 대기** 상태다. 보관된 측정 기록와 보관된 측정 기록을 함께 보아야 한다.

### 구현과 적용 조건

같은 65×65 정점, 8,192개 삼각형, 25cm 간격, 파동 4개를 사용했다. CPU에서 계산한 위치·법선·접선을 내장 UProceduralMeshComponent에 반영한다. 평면 대조군도 같은 메시 갱신 경로를 거친다. 따라서 가만히 있는 정적 메시와의 비교가 아니다.

기준좌표 u=(x,y), theta=k(D·u-c*t)+phase, k=2π/L이다. 사인파는 높이 A·sin을 합한다. Gerstner는 여기에 수평 q·A·D·cos 변위를 더한다. **전체 위치를 기준 x/y로 미분한 접선의 외적**으로 법선을 구한다. 사인파용 높이 기울기만 사용하면 Gerstner 법선이 틀린다. 기준좌표는 변위 후의 세계 XY와 다르므로 세계 높이 조회·부력으로 확대하지 않는다. 매끈한 해석 법선과 유한 삼각형 면의 법선도 구분한다.

파동 방향은 (1,0), (.6,.8), (-.8,.6), (0,-1), 진폭은 24/12/8/4cm, 파장은 640/420/280/200cm, 속도는 90/65/45/30cm/s, 위상은 0/.7/1.4/2.1라디안이다. 방향은 준비 단계에서 정규화한다. 공통 q=.9일 때 가파름 합 S=Σ(q·k·A)는 약 .648290이다.

Gerstner는 **S≤.99**만 허용한다. 이론상 특이·접힘 경계 1보다 여유를 두었으며, 초과 입력은 자동 제한하지 않고 원자적으로 거부한다. 근접 사례는 S=.989999999이고, 단일파의 정확한 .99 경계에서도 최악 파봉의 Jacobian은 .01로 양수다. q=0이면 사인파와 같고, 진폭이 모두 0이면 수평 이동이 없는 평면과 위쪽 법선이 된다.

지원 입력은 유한한 좌표·시간의 절대값 1e6 이하, 파동 1~4개, 진폭 0~1000cm, 파장 1~1e6cm, 속도 절대값 10000cm/s 이하, 위상 절대값 1e6 이하, q는 0~10이다. 다른 입력 범위나 시간 재기준화에는 재검증이 필요하다.

재질은 불투명 파랑 확산 표면이며 specular=0, metallic=0, roughness=1이다. 재질의 WPO·법선 덮어쓰기, 충돌·그림자는 사용하지 않는다. 내장 컴포넌트 설정과 재질 한 개만 추가했다. 설치 API는 이 컴포넌트를 실험적으로 표시한다. **공개 CPU 섹션 관측은 GPU 정점 버퍼의 비트 검증이 아니고, 이 비용은 GPU WPO의 성능도 아니다.**

### 동작 검증과 발견한 문제

정책 검사 222개가 통과했다. 반복·음수 좌표/시간, 중앙차분 법선(h=.001cm, 오차 1e-6), 단위·직교성, 정확한 단일파 값, 배정도 파수, 진폭 0, q=0, 비정규 방향, 가파름 경계·초과와 최악 파봉, 잘못된 입력의 원자적 거부를 확인했다. 30·60·144Hz와 불규칙한 시간 분할이 같은 끝 시각에서 일치했다. 이는 시간 입력 검사이며 실제 렌더링 FPS 인증이 아니다.

실제 PIE와 패키지에서 각각 20개 사례를 실행했다. 평면, 사인파/Gerstner의 시각 0·1.25, 재생, 음수 시간, 진폭 0, q=0, 가파름 근접, 분할 시간 t=8, NaN·과도한 가파름·영방향·영파장의 거부 및 기존 메시 보존, 시간 ±1e6을 포함한다. 모든 사례에서 같은 컴포넌트의 정점·법선·접선·인덱스·섹션 경계·재질·충돌을 관측했다.

총 **169,000개 정점 관측**을 독립 수식과 대조했다. 허용 기준은 위치 1e-4cm, 법선·접선 1e-6이다. 최대 독립 위치 오차는 7.10383289844e-12cm, 법선 오차는 9.29859380646e-14다. 같은 실행 대상에서 같은 입력을 재생하면 값·체크섬이 정확히 같다. 에디터와 패키지 사이에는 위치 최대 약 8.18e-12cm, 법선 약 1.08e-13의 차이가 있다. 원래 오차 기준을 충족하지만 **실행 대상 간 비트 동일성은 주장하지 않는다.** 하위 비트 차이를 만든 정확한 연산은 추적하지 않았다.

빈 구현에서 21개 검사 중 10개 실패를 확인했다. 첫 구현의 217개 검사 중 61개 실패 가운데 60개는 관측 오류였다. 작은 원시 차분 벡터의 외적이 GetSafeNormal의 기본 제곱 길이 한계에 걸렸다. 차분을 2h로 나눠 미분 벡터 스케일을 복원했고, 허용 오차는 완화하지 않았다. 별도로 float PI가 배정도 계산에 섞인 실제 구현 결함도 발견했다. 독립 배정도 파수·단일파·가파름 검사가 220개 중 7개 실패를 재현했고, UE_DOUBLE_PI 수정 후 통과했다. 최악 파봉·방향 정규화 검사를 추가한 최종 결과가 222개 통과다. 실패 근거는 보존했다.

### 화면과 촬영 조건

600개 네이티브 프레임, 20.000초, 30시뮬레이션/30재생의 1배속 영상이다. 평면·사인파·Gerstner·안전 한계 근접을 각각 5초 보여준다. 전체 격자가 보이는 고정 카메라를 사용했다. 청록 화살표는 실제 컴포넌트 법선이며 격자·화살표는 영상에만 포함된다.

모든 원본·디코딩 프레임의 실제 serial/phase 표식을 대조했고, 최대 시각 오차는 0.001041ms다. 시작·끝 여백만 잘랐으며 재타이밍·대체 이미지는 없다. 표면 가시성·장면 차이를 검사하고 대표 4장을 직접 확인했다. 모든 프레임을 수동 시청한 것은 아니며, 실제 30FPS 처리량 인증도 아니다.

### 사용 판단과 한계

완만한 기하 파도에는 사인파를, 수평 집중과 날카로운 파봉이 필요하면 가파름 예산을 지키는 Gerstner를 선택한다. 재현하려면 절대 배정도 시간·위상 규약·기준좌표·파동 입력을 유지해야 한다. 가장 짧은 파장에 맞는 메시 해상도가 필요하며 이번 설정은 파장당 8셀이다. 매끈한 법선이 메시보다 작은 기하를 복원하지는 않는다.

기존 RandomDesign 122개, 핵심 PIE·패키지 각각 73개 회귀 검사와 전체 실험실 테스트를 확인했다. 이전 소스 아카이브 29개와 애셋 61개를 보존하고 재질 한 개만 추가했다. 최신 목록은 24개 기술 부분 구현, 19개 전용 구현 없음이다.

부력·유체·해안·거품·반사·굴절·스트리밍·렌더러·검증 프레임워크 개선은 포함하지 않는다. 기존 실제 FPS 누락은 미검증으로 유지하며, 커밋·푸시하지 않았다.

### 검색 적용 확인

단독 키워드의 동음이의어 때문에 수면 시간을 기록하는 메뉴의 문자열 수정 요청이 물 표면 기술로 잘못 연결됐다. 기존 부정 검사에서 194개 중 193개만 통과한 것을 확인하고, 검색 엔진이나 검사 조건을 바꾸지 않은 채 키워드를 구체적인 ‘물 표면’으로 바꿨다. 이후 194개가 모두 통과했다. 파도 기하·법선·시간 결정에는 이 지식을 사용하고, 메뉴 문구 수정만으로 수면 구현을 도입하지 않는다.
