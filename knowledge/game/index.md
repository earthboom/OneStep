# Game design knowledge

Genre-aware design references for concepts, mechanics, interacting systems, production questions and player experience. Start with [the retrieval convention](K-GAME-RESEARCH-USE.md), then select applicable catalog entries by the actual design question. This store supports the [planning method](../../skills/vegabond-planning/SKILL.md) and its large-plan coordination.

[Domain routing](../index.md) | [Storage and lifecycle](../../skills/vegabond-knowledge/references/storage.md)

Use common methods with compatible genre references. A hybrid may need several methods; it does not inherit every convention of every genre. Source-case observations and proposed transferable checks are distinguished in each detail. Publication/patch context matters: historical developer cases are not current balance specifications.

The collection is a broad starting survey, not an exhaustive genre encyclopedia. Verify source locators before relying on consequential details. Full-text, slide-text, abstract-only and unavailable-video boundaries are explicit; no entry claims a local gameplay trial. Missing genre variants require focused follow-up research.
