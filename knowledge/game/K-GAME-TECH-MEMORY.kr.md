# 메모리 오류·임의 코드 실행

기준 항목: K-GAME-TECH-MEMORY · 확인일: 2026-11-07 · 참고 지식. 엔진 실행·성능·실제 플레이 검증은 별도다.

## 원리와 구현 요점

코드와 데이터는 실행 환경이 해석하는 비트열이다. 메모리·제어 흐름 손상은 의도하지 않은 실행으로 이어질 수 있지만 범위 밖 쓰기만으로 모든 취약점을 설명할 수는 없다. 개발에서는 수명·경계·타입 인터페이스와 저장·외부 데이터 검증을 우선한다.

### 추가 조사로 보완한 구현

TAStm32 하드웨어 프로젝트의 테스트 문서는 Masterjun의 SMW Total Control 재생 자료와 가상 컨트롤러 8채널을 명시한다. 구체적인 입력 재생 자료는 확인했지만 취약점 발생 조건 자체를 검증한 것은 아니다. 재사용 지식에서는 실행 흐름을 바꾸는 버그와 데이터를 전달하는 입력 스트림을 구분하며 모든 게임의 일반 입력이 실행 가능하다고 일반화하지 않는다. 재현할 때는 ROM 버전·초기 상태·컨트롤러 프로토콜을 고정해야 한다.

## 적용 조건과 한계

컨트롤러를 이용한 특정 고전 게임 취약점은 게임·버전별 근거가 필요하며 재현하지 않았다. 현대 실행 권한·메모리 보호는 고전 콘솔과 다르다.

## 적용 전 점검

적용 전 점검: 지원 환경의 메모리 검사기·파서 퍼징과 장면 전환·저장 로드의 경계·수명을 확인한다.
