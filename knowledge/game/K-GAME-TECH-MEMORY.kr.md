# 게임 데이터 처리에서 버퍼 경계와 객체 수명 검사하기

**K-GAME-TECH-MEMORY** · 데이터 복사·디코딩 전에 대상 버퍼 경계와 객체 수명을 검사하고 계측 빌드로 실제 실행 중의 잘못된 접근을 진단한다.

## 지침

MITRE의 `CWE-787`(Out-of-bounds Write)은 할당된 버퍼의 앞이나 뒤에 쓰는 오류다. 인접 데이터가 손상되거나 프로그램이 종료될 수 있다. C++로 저장 파일·에셋·네트워크 메시지를 읽을 때는 포인터 생성이나 쓰기 전에 길이와 오프셋을 검사한다. 오프셋이 용량 이하임을 먼저 확인하고 남은 용량과 개수를 비교한다. 원소 크기와 부호 변환도 반영한다.

## 적용 조건과 예외

지원되는 네이티브 C++ 빌드에서 Clang AddressSanitizer(ASan)는 실행된 범위 밖 접근이나 해제 후 사용 오류를 다수 탐지한다. 댕글링 포인터는 수명이 끝난 객체를 가리킨다. 소유자가 저장소를 해제하거나 재할당했다면 인덱스가 범위 안이어도 안전하지 않다. 오류 없는 실행은 지나간 경로에 한정된다. 임의 코드 실행(ACE)은 일부 결함의 가능한 결과이며 원인 분류 자체는 아니다.

## 확인 방법

계측 빌드에서 빈 레코드·잘린 레코드·정확히 맞는 길이·과대 길이를 검사한다. 거부 후에도 대상 상태가 유효한지 본다. 장면 해제와 버퍼 재할당 시 콜백 및 뷰 수명을 확인한다. 진단은 최초 잘못된 접근과 그 저장소의 할당 수명에 연결한다.

## 근거

MITRE는 약점의 정의를, Clang은 ASan의 검사 범위와 계측 방법을 설명한다. 공개된 과거 게임 재생 사례는 관찰 결과를 보여주지만 특정 버퍼 오류를 확정하지 않는다. 이번 검토에서 새로 계측 빌드를 실행하거나 개별 게임의 결함을 확인하지 않았다.
