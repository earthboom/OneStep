# 이징·스무드스텝·베지에 곡선

기준 항목: K-GAME-TECH-EASING · 확인일: 2026-11-07 · 참고 지식. 실제 엔진 구현·성능·플레이테스트는 수행하지 않았다.

## 원리와 구현 요점

정규화 시간을 진행률로 바꾼 뒤 값을 보간한다. 3t²-2t³은 양끝 기울기 0, 6t⁵-15t⁴+10t³은 양끝 이차 미분도 0이다. 3차 베지에는 매개 곡선이며 CSS식 시간 곡선은 x에 맞는 매개값을 구한 뒤 y를 읽는다. 임의의 바운스를 단일 3차 곡선으로 정확히 재현할 수 있는 것은 아니다.

구현 선택과 점검은 출처를 바탕으로 한 실무적 종합이며 특정 게임의 정확한 구현을 보증하지 않는다.

## 적용 조건과 한계

이징은 보간 규칙이지 물리적으로 정확한 운동을 자동 보장하지 않는다. 목표를 매번 향하는 감쇠와 유한 시간 애니메이션은 다르다.

## 적용 전 점검

적용 전 점검: 양끝값·미분·오버슈트·중단 후 재개와 FPS별 동일 재생 시간을 확인한다.

- [Ken Perlin — Improving Noise](https://mrl.cs.nyu.edu/~perlin/paper445.pdf) — 출처의 확인 범위는 아래 원칙을 따른다.
- 공식 문서·논문·저자 글은 확인한 본문 범위에 한정한다. 초록·영상 설명만 확인한 경우와 미열람 자료는 영문 정본 Evidence에 명시했다. 예제 코드·영상·제품 성능은 실행 검증하지 않았다.
- 출발 영상: V47, V59. [전체 대응표](K-GAME-TECH-GUIDE.kr.md).


## 검색 연결 보완 — 2026-11-11

카메라의 정해진 보간 전환 시간이 어긋나면 EASING의 정규화 시간/끝점 조건과 CAMERA의 추종 감쇠를 함께 조회한다. TIMESTEP은 시뮬레이션 누적과 이전/현재 표시 보간을 다루며 전환 곡선의 지정 지속시간과 구분한다. 기존 카메라 검색 회귀의 누락을 보완한 것이며 새 이징 엔진 검증이나 원 출처 재확인을 의미하지 않는다.

## 실제 언리얼 이징 — 2026-11-12

[V47/V59 실제 결과](../../prototypes/UnrealTechniqueLab/EASING-RESULTS.kr.md)는4곡선·정책104개·실제PIE96방법·상황·방법별 비용3회·정상1배속 영상이다. 시간 입력30/60/144Hz와 실제 렌더FPS를 구분한다. 관측:cap30→23.21FPS, cap60→45.66FPS, cap144→110.32FPS. 미도달 요청FPS 대역의 동작은 미검증이다.

정해진 종료시간에는 누적시간/기간을 사용한다. 선형은 일정진행률,Smoothstep은 끝점기울기0,Smootherstep은 끝점2차미분까지0,Bézier는 직접 만든 시간곡선이다. 베지에는x를 풀어y를 읽고 출력초과를 허용한다. 이 구현은 입력0..1,y제어점[-4,4]범위이며 CSS구간밖 외삽 전체를 재현하지 않는다.

중단은 값/커서를 유지하고 재개한다. 재시작은 현재값에서 새 목표/기간으로 출발한다. 역방향은 원래 곡선을 되짚어 비대칭 곡선·완료후 복귀·중단중 역전환을 다룬다. 위치유지와 속도연속성은 다르며 역재생은 속도방향을 바꿀 수 있다.0초는1번 완료하고 잘못된 입력은 원자적으로 거부한다. 남은dt를 새 전환으로 자동 이월하지 않는다.

33초8상황에서 독립 시간식으로 커서·값·완료·이벤트·실제xyz를 검사했다. 실제 시간은 벽시계와 로그시점5ms불확실성을 포함해 연결하고 끝점클램프는1기록프레임을 허용한다. 캡처는 별도의30시뮬레이션/30재생이다.

정책400cm와 실제399.9999445cm 차이는 엔진이1e-4cm이내 이동을 생략하는 경로를 확인한 결과다. 정책값1e-7cm·실제1축위치1e-4cm를 구분하며 실패원본을 보존했다. 정책 정확도를 네이티브 허용오차로 낮추지 않는다.

비용은1280×720·512독립큐브·동일격자/카메라/재질/크기·선택곡선1개·2초 준비+10초 측정·각3회다. 부분비용은 곡선평가/위치반영/읽기이며 중단·재시작·역전환 명령 비용이 아니다. 화면면적 차이·전체wall/간격·GPU완료를 구분한다. 공유곡선/인스턴싱 최적화나 보편적 속도 향상은 주장하지 않는다.

독립 검토의 실제시간 연결/위조 이벤트값 누락은 실패3개를 재현한 뒤 보완했다. 결과변형30개,18이전보관본·36기존자산 보존을 확인했다. 충돌·물리·UI·전체 애니메이션블렌딩·속도연속 재목표화는 별도다. 렌더러·도구 최적화로 범위를 확대하지 않았다. 최신13부분구현/30직접구현없음이다.
