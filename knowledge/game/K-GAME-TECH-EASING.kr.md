# 이징·스무드스텝·베지에 곡선

기준 항목: K-GAME-TECH-EASING · 확인일: 2026-11-07 · 참고 지식. 실제 엔진 구현·성능·플레이테스트는 수행하지 않았다.

## 원리와 구현 요점

정규화 시간을 진행률로 바꾼 뒤 값을 보간한다. 3t²-2t³은 양끝 기울기 0, 6t⁵-15t⁴+10t³은 양끝 이차 미분도 0이다. 3차 베지에는 매개 곡선이며 CSS식 시간 곡선은 x에 맞는 매개값을 구한 뒤 y를 읽는다. 임의의 바운스를 단일 3차 곡선으로 정확히 재현할 수 있는 것은 아니다.

구현 선택과 점검은 출처를 바탕으로 한 실무적 종합이며 특정 게임의 정확한 구현을 보증하지 않는다.

## 적용 조건과 한계

이징은 보간 규칙이지 물리적으로 정확한 운동을 자동 보장하지 않는다. 목표를 매번 향하는 감쇠와 유한 시간 애니메이션은 다르다.

## 적용 전 점검

적용 전 점검: 양끝값·미분·오버슈트·중단 후 재개와 FPS별 동일 재생 시간을 확인한다.
