# 서버 되감기·지연 보상

기준 항목: K-GAME-TECH-LAGCOMP · 확인일: 2026-11-07 · 참고 지식. 실제 엔진 구현·성능·플레이테스트는 수행하지 않았다.

## 원리와 구현 요점

시각별 충돌 이력을 보관하고 허용된 사격을 제한된 과거 상태에서 질의한다. 시계 대응과 표시 보간 지연을 반영하고 현재 권한 세계와 임시 과거 질의를 구분한다.

구현 선택과 점검은 출처를 바탕으로 한 실무적 종합이며 특정 게임의 정확한 구현을 보증하지 않는다.

## 적용 조건과 한계

되감기는 사격자 시점을 돕지만 이미 엄폐한 사람에게 불리할 수 있다. 모두가 이를 선호한다는 보편 주장은 입증되지 않았다. 공정성 기준과 최대 되감기를 명시한다.

## 적용 전 점검

적용 전 점검: 엄폐 전환·고속 표적·비대칭 지연에서 양 클라이언트 시점과 서버 이력을 함께 기록한다.
