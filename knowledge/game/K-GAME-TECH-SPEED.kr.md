# 속도감·FOV·모션 블러

기준 항목: K-GAME-TECH-SPEED · 확인일: 2026-11-07 · 참고 지식. 실제 엔진 구현·성능·플레이테스트는 수행하지 않았다.

## 원리와 구현 요점

가속 이벤트에 FOV 변화·카메라 오프셋·지연·속도 기반 블러를 연결한다. 기본 구도와 연출을 분리해 강도 설정이 조준·이동 규칙을 바꾸지 않게 한다. 깊이 기반 카메라 블러는 시점 변환으로 픽셀 이동을 복원하지만 움직이는 물체는 추가 운동 정보가 필요하다.

구현 선택과 점검은 출처를 바탕으로 한 실무적 종합이며 특정 게임의 정확한 구현을 보증하지 않는다.

## 적용 조건과 한계

블러가 잃어버린 입력 반응이나 실제 프레임을 복구하지는 않는다. 큰 FOV 변화·강제 카메라 이동은 편안함과 표적 판독을 해칠 수 있다.

## 적용 전 점검

적용 전 점검: 실제 주행·이동 과제에서 효과 끔·약함·기본을 비교하고 접근성 설정을 제공한다.

### field of view

카메라의 **시야각(field of view, FOV)**은 카메라가 담는 각도다. 시야각을 바꾸면 속도감과 구도가 변한다. 카메라 모션 블러에서는 화면 깊이와 현재 뷰·투영 행렬의 역행렬로 월드 위치를 복원하고 이전 행렬로 투영해 화면 이동량을 구한다. 독립적으로 움직이는 객체에는 자체 모션 벡터나 속도 버퍼가 필요하다. 정적 장면에서 카메라만 이동한 경우와 카메라가 고정된 채 캐릭터만 이동한 경우를 비교한다. [Gilberto Rosado — Motion Blur as a Post-Processing Effect](https://developer.nvidia.com/gpugems/gpugems3/part-iv-image-effects/chapter-27-motion-blur-post-processing-effect)

## 속도 기반 FOV·카메라 오프셋/지연·모션 블러 — 언리얼 검증

UE5.8.3 Win64 Development/DX11,2026-11-14 한국시간 기준이며 실행 시각은 UTC다. **AI 검증 완료, vagabond 테스트·리뷰 대기** 상태이며 사용자 승인은 아직 없다. 보관된 측정 기록와 보관된 측정 기록을 참조한다.

### 구현과 보존

실제 충돌 이동 후 속도 크기를 2200cm/s로 정규화한다. 끔/약함/전체는 FOV 90+0/7.5/15도, 고정 전방 카메라의 뒤쪽 오프셋 0/55/130cm, 엔진 모션 블러 0/.2/.5다. 기본 오프셋은 (-360,0,140)cm이며 지수 감쇠를 사용한다. 중단은 기본 시야로 복귀하면서 엔진 이력을 초기화하고 재활성화는 그 상태에서 시작한다. 14·16초 카메라 컷도 소유 상태와 엔진 이력을 함께 초기화한다.

정책 274개가 통과했다. 정지·최대·가속·급정지·벽 충돌·역방향·중단·재활성화·컷을 포함한 20초에서 플레이어마다 고정 60Hz 이동 1,200단계를 실행했다. 최종 일반 플레이어 20개에서 이동·충돌·월드 전방 레이·영역 진입의 원래 값과 순서가 각 실행 대상 내에서 정확히 같았다. 독립 기하·이동·카메라 계산과 실제 FSceneView·최종 후처리·투영도 대조했다.

### 실제 문제와 수정

초기 스텁은 274개 중 270개 실패했다. 역방향에서 속도의 반대쪽으로 오프셋을 주자 지연과 결합해 10.918초에 카메라 X=-191.57이 개체 X=-204.37보다 앞섰다. 정책 2개 실패로 재현하고 고정 전방 리그의 뒤쪽에 오프셋을 유지하도록 수정했다. 중단 시 기본 위치로 즉시 이동할 때 엔진 컷이 빠진 문제도 실제 실행 검사로 검출해 수정했다.

벽의 기하학적 중심 한계 5950cm보다 1.0367cm 앞에서 멈추는 것은 엔진의 의도된 충돌 pullback이다. 공식으로 독립 계산한 이동 오차는 약 0.00000282cm였다. WorldToPixel 성공은 카메라 앞이라는 뜻이 아니므로 signed clipW와 앞/뒤를 구분했다.

실제 블러 검사에서 임의의 밝기 피크 10% 감소는 유효한 보장이 아니었다. 실패 결과를 보존하고 공간 분산 증가·일치하는 카메라·실제 컷·끔 픽셀 대입 거부를 판정 기준으로 사용했다. 최종 별도 카드 검사 114개 이동 프레임에서 추가 분산 중앙값 42.784653px², 최소 34.418426px²이며 컷 2개도 통과했다. 피크 비율 0.945378는 관측값이다. 녹색 화면 검사의 채널 분류와 정지 프레임을 잘못 고른 오류 대입 검사도 원인을 확인해 보완했다. 렌더러는 수정하지 않았다.
