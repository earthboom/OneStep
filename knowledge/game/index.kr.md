# 게임 개발 지식

구현 질문은 [기술 안내서](K-GAME-TECH-GUIDE.kr.md)에서 시작한다. 최초 발견 단서인 쇼츠 59편과 원리 중심 기술 43개, 근거 한계와 채택 검사 제안을 연결한다.

[활용 규칙](K-GAME-RESEARCH-USE.kr.md)에 따라 실제 결정·증상으로 기획·설계·구현·디버깅·최적화 지식을 고르고 채택 여부와 측정 가능한 검사를 기존 작업 개요에 담는다. 장르별 기획 지식과 기술 구현 지식은 서로 다른 조건을 다룬다.

[분야 목록](../index.kr.md) · [저장·수명주기](../../skills/vegabond-knowledge/references/storage.kr.md)

혼합 장르는 호환되는 공통 방법과 여러 장르 지식이 필요할 수 있지만 모든 관습을 자동 상속하지는 않는다. 출처 사례와 전용 가능 검사 제안을 구분하며 과거 개발 사례를 현재 밸런스 규격으로 취급하지 않는다.

이 목록은 출발점이지 모든 장르를 망라한 백과사전이 아니다. 중요한 세부 내용은 출처 위치를 확인한다. 원문·슬라이드·초록만 확인한 경우와 접근 불가 영상의 경계를 각 항목에 남겼다. 없는 변형은 집중 추가 조사가 필요하다.

제한된 엔진 실험: [DynamicLab](../../prototypes/TechniqueLab/DYNAMIC-RESULTS.kr.md)은 지연 장애물 변경·동일 반경 공유 목표 예약, [TrafficLab](../../prototypes/TechniqueLab/TRAFFIC-RESULTS.kr.md)은 정해진 교행 차선·고정된 서로 다른 반경·방향 일정을 다룬다. 측정한 전체 프레임 결과와 채택 조건을 읽는다. 기술 4개에 제한된 엔진 증거가 있고 39개는 로컬 엔진 검증이 없다.

영문 기준 문서에서 사람용으로 재생성한 요약이다. AI는 영문 목록과 상세 항목을 사용한다. 정확한 메타데이터·범위·확인일은 영문 기준 목록에 있으며, 롤백 지식의 확정·외부 지급 조건은 2026-11-08 보완했다.
