# 장르에 맞게 배울 수 있고 접근 가능한 상호작용 설계

사람 전용 번역. AI는 영문 K-GAME-ACCESSIBILITY-ONBOARDING.md를 사용한다.

ID: K-GAME-ACCESSIBILITY-ONBOARDING. 유형: 참고 자료. 상태: 사용 가능. 근거 확인일: 2026-11-07.

요약: 의도한 도전과 정보 인지·목표 이해·조작의 장벽을 구분한다. 중복 감각 단서·조정 가능한 입력·다시 볼 수 있는 학습을 계획하고 관련 이용자·기기로 전체 흐름을 확인한다.

적용 범위: 장르별 온보딩·접근성·조작·난이도 기획. Xbox 지침은 설계 참고이며 준수 인증의 증거가 아니다.

검색어: accessibility, onboarding, tutorial, input, objective-clarity, difficulty, readability, 접근성, 튜토리얼, 온보딩, 조작, 학습, 난이도, 가독성

## 활용 지침

출처 관찰: XAG 103은 중요한 정보를 다른 감각 채널로도 전달하도록 한다 [S1]. XAG 107은 입력 재지정과 힘든 입력 패턴의 대안을 다룬다 [S2]. XAG 109는 다시 확인할 목표와 정적 조작표를 넘어선 안내를 다룬다 [S3]. XAG 108은 체감 난이도를 이용자 능력과 게임 장벽의 관계로 설명한다 [S4].

응용 방법: 최초 실행·설정·첫 행동·실패·오랜만의 복귀·후반 요구를 연결한다. 필수 행동마다 알아차리고·이해하고·기억하고·수행할 것을 적는다. 의도한 도전을 유지하면서 피할 수 있는 감각·인지·운동 장벽을 찾는다. 키 변경·자막·단서 채널·보조 기능이 학습과 다른 UI에 미치는 영향도 정한다.

이용자가 현재 목표를 인식하고 독립적으로 행동하는지 드러내는 과제를 사용한다. 발견 중심 게임은 단계별·선택형 도움을 사용해 핵심 조작 접근이 퍼즐 답 공개로 이어지지 않게 한다.

## 적용 조건과 예외

실제 메커니즘·대상에 맞는 지침 구획을 적용하며 난이도 수를 일괄 고정하거나 의도한 도전을 없애지 않는다. 경쟁에서 보조 기능을 쓰면 공정성 검토가 필요할 수 있다. 고대비 화면·자동 검사·감각 채널 하나를 끈 시험만으로 모든 이용자의 접근성을 입증하지 않는다. 출처 영상·예시 게임을 직접 플레이하지는 않았다.

## 확인 항목

제안 점검: 장벽을 통과해야만 설정에 갈 수 있는가? 안내가 변경 키를 따르는가? 색만·소리만 없이 중요한 단서를 이해할 수 있는가? 복귀자가 전부 재실행하지 않고 목표를 회복할 수 있는가? 전체 흐름을 시험하고 이용자·기기·설정 범위를 밝히며 선택형 힌트와 강제 스포일러를 구별한다.
