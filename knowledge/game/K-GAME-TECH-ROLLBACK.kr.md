# 롤백·입력 지연 넷코드

기준 항목: K-GAME-TECH-ROLLBACK · 확인일: 2026-11-07 · 참고 지식. 실제 엔진 구현·성능·플레이테스트는 수행하지 않았다.

## 원리와 구현 요점

원격 입력을 예측하고 상태 스냅샷을 저장한 뒤 실제 입력과 비교한다. 다르면 과거 상태를 복원해 중간 프레임을 모두 그리지 않고 현재까지 다시 계산한다. 재실행되는 소리·파티클·업적을 중복 처리하지 않는다. 입력 지연과 결합해 보정 범위를 조절할 수 있다.

구현 선택과 점검은 출처를 바탕으로 한 실무적 종합이며 특정 게임의 정확한 구현을 보증하지 않는다.

## 적용 조건과 한계

롤백은 애니메이션 앞부분을 생략하는 기법이 아니다. 복원 가능한 결정론적 상태·재계산 CPU 예산·최대 롤백 정책이 필요하다.

## 적용 전 점검

적용 전 점검: 틀린 예측·뒤바뀐 입력·긴 공백을 만들고 최종 상태 해시와 부수 효과의 단일 실행을 확인한다.
