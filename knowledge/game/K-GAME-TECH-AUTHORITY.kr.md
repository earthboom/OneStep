## 원리와 구현 요점

결과 주장을 신뢰하는 대신 입력 의도를 권한 있는 시뮬레이션에 보내 검증한다. 로컬의 지연 민감 동작을 예측하고 서버 확인 상태로 보정한 뒤 지원되는 이동 모델에서는 미확인 입력을 다시 적용한다. 외형 보간과 권한 충돌은 분리한다.

구현 선택과 점검은 출처를 바탕으로 한 실무적 종합이며 특정 게임의 정확한 구현을 보증하지 않는다.

## 적용 조건과 한계

서버 권한이 모든 치트를 막는 것은 아니다. 예측 애니메이션이 재생됐다는 이유로 보상을 확정하지 않는다. 특정 서비스의 틱 수치를 보편 요구로 삼지 않는다.

## 적용 전 점검

적용 전 점검: 손실·지터·잘못된 입력을 주고 입력 번호·확인 번호·보정 크기·서버 보상을 기록한다.
