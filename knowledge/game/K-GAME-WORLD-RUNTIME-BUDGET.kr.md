# 화면 밖 처리와 스트리밍 비용을 줄일 때 월드 결과를 유지한다

## 지침

지원 기기·빌드에서 해상도와 품질을 고정하고 긴 프레임을 재현한다. 최초 진입, 워밍업, 재진입을 구분한다. CPU와 GPU 타임라인에서 주요 비용을 찾는다. 해상도로 픽셀 비용을, 드로 호출과 상태 변경으로 CPU 제출 비용을, I/O·압축 해제·업로드·파이프라인 워밍업으로 최초 진입 지연을 구분한다. 중앙값과 상위 백분위 프레임 시간, 긴 프레임과 메모리를 프로젝트 예산에 대조한다.

객체의 렌더링 여부, 에셋의 메모리 상주 여부, 논리 상태 유지, 시뮬레이션 진행을 각각 결정한다. 화면 밖 퀘스트나 전투 결과에도 소유자를 둔다. 관찰해야 하는 결과에 맞춰 전체 진행, 느린 갱신, 예약된 상태 갱신, 진입 시 복원 중 선택한다. 생성 수와 비동기 활성화에 한도를 둔다. 반복 생성 비용이 큰 객체는 풀을 고려하고 상태·타이머·구독·실행 중 작업을 정리한 뒤 재사용한다.

## 적용 범위와 예외

컬링, 배칭, 거리별 상세도와 풀은 CPU·GPU·메모리·시각 품질에 각각 비용이 있다. AI가 이미 충분히 싸면 그대로 갱신할 수 있다. 상점이나 퀘스트 대상은 화면에 보이는 표현을 언로드해도 상태를 진행해야 할 수 있다. 목표 기기와 실제에 가까운 객체 밀도에서 측정한다.

## 확인

진입 → 조우 → 이탈 → 재진입을 반복하고 같은 NPC ID의 생존·퀘스트 상태를 확인한다. 대표 경로와 부하가 큰 경로에서 최초 로딩과 재진입, 긴 프레임, 복귀 뒤 상주 메모리, 필요한 시각 신호를 비교한다. 취소와 풀에서 꺼낸 객체의 두 번째 사용도 확인한다. [성능 측정](../code/K-CODE-PERFORMANCE-MEASUREMENT.kr.md) · [월드 수명 검증](../../skills/vegabond-code/references/world-lifecycle-verification.kr.md)
