## 원리와 구현 요점

구현 패턴 제안: 재료 속성과 원소 효과를 데이터로 표현하고 전이 조건·우선순위를 정한 뒤 결과 이벤트를 물리·음향·렌더링에 전달한다. 작은 상호작용 표부터 시험한다. 원본 개념 규칙은 추가 조사로 확인했으며 자료구조·이벤트 설계는 실무 종합안이다.

### 추가 조사로 보완한 구현

닌텐도/GDC 원본 슬라이드에서 이동 계산과 상태 변화를 구분했다. 40:23은 원소 효과와 재료 물체, 40:53은 원소→재료 상태 변화, 41:08은 원소→원소 상태 변화, 41:23은 재료 접촉만으로 다른 재료의 화학 상태를 바꾸지 않는 규칙을 보여준다. 이는 해당 게임의 모델이지 현실 화학 법칙이 아니다. 구현 종합안: 접촉·노출 수집→방향성 규칙 평가→동시 변화 우선순위 결정→상태 확정→물리·시각·음향 이벤트 전송. 불붙은 나무는 원소인 불 효과를 방출하도록 표현할 수 있다.

### chemistry engine

Nintendo 발표의 **화학 엔진(chemistry engine)**에서는 원소 효과가 재질 상태나 다른 원소 효과를 바꿀 수 있다. 해당 모델에서 재질끼리 접촉하는 것만으로 화학 변화는 일어나지 않는다. 이를 옮기는 한 방법인 **상호작용 행렬(interaction matrix)**에는 작용 효과·대상 상태·전제·결과를 방향별로 적는다. 동시에 노출되는 경우를 여러 처리 순서에서 확인한 뒤 우선순위를 정한다. [Nintendo/GDC — original technical presentation](https://www.youtube.com/watch?v=QyMsF31NdNc&t=2423s)

## 실제 원소·재질 규칙 검증 — 2026-11-12

작은 환경퍼즐/액션 상호작용에서 재질·효과 행렬과 우선순위가 필요할 때 적용한다.100ms양자화로최대한틱반응지연이있어빠른전투는별도주기와재검증/재측정이필요하다. 실제접촉수집→전체검증/정규화→다음상태→일괄확정→한번이벤트전달로구성하며상호재귀OnHit는피한다. 게임의 나무/금속 태그와언리얼표시/물리재질은별도다. 접촉만으로전이하지않는다.
