# 화학 엔진·시스템 상호작용

기준 항목: K-GAME-TECH-SYSTEMIC · 확인일: 2026-11-07 · 참고 지식. 엔진 실행·성능·실제 플레이 검증은 별도다.

## 원리와 구현 요점

구현 패턴 제안: 재료 속성과 원소 효과를 데이터로 표현하고 전이 조건·우선순위를 정한 뒤 결과 이벤트를 물리·음향·렌더링에 전달한다. 작은 상호작용 표부터 시험한다. 원본 개념 규칙은 추가 조사로 확인했으며 자료구조·이벤트 설계는 실무 종합안이다.

### 추가 조사로 보완한 구현

닌텐도/GDC 원본 슬라이드에서 이동 계산과 상태 변화를 구분했다. 40:23은 원소 효과와 재료 물체, 40:53은 원소→재료 상태 변화, 41:08은 원소→원소 상태 변화, 41:23은 재료 접촉만으로 다른 재료의 화학 상태를 바꾸지 않는 규칙을 보여준다. 이는 해당 게임의 모델이지 현실 화학 법칙이 아니다. 구현 종합안: 접촉·노출 수집→방향성 규칙 평가→동시 변화 우선순위 결정→상태 확정→물리·시각·음향 이벤트 전송. 불붙은 나무는 원소인 불 효과를 방출하도록 표현할 수 있다.
