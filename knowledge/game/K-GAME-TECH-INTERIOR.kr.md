# 인테리어 매핑으로 진입할 수 없는 방 표현

기준 항목: K-GAME-TECH-INTERIOR · 확인일: 2026-11-07 · 참고 지식이며 실제 엔진·성능 검증은 별도다.

## 원리와 구현

내부에 들어가지 않는 창문의 가상 방에 사용한다. 시선을 방의 로컬 좌표로 변환하고 암묵적인 상자와 교차시켜 해당 벽·바닥·천장 텍스처를 샘플링한다. 전체 실내 메시를 만들지 않고 방의 변주를 줄 수 있다. 구현 선택·검사는 공학 종합안이며 특정 게임의 정확한 구현을 보장하지 않는다.

## 적용 조건과 한계

방은 셰이딩에 의한 환상이다. 실제 충돌·길찾기·그림자·상호작용 가구를 자동으로 제공하지 않는다. 가까운 사선 시점에서 한계가 드러날 수 있다. 내부 진입이 필요하면 실제 기하를 검토한다. 검색 키워드는 일반적인 ‘실내’보다 인테리어매핑·장식창문·비진입창문으로 범위를 좁혔다.

## 적용 전 점검

창문 경계·모서리 시점·반복 방을 비교하고, 진입 공간은 실제 기하로 전환한다. 이 검사는 제안이며 실제 장면에서 실행하지 않았다.
