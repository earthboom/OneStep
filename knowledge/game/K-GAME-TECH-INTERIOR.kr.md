# 인테리어 매핑으로 진입할 수 없는 방 표현

기준 항목: K-GAME-TECH-INTERIOR · 확인일: 2026-11-07 · 참고 지식이며 실제 엔진·성능 검증은 별도다.

## 원리와 구현

내부에 들어가지 않는 창문의 가상 방에 사용한다. 시선을 방의 로컬 좌표로 변환하고 암묵적인 상자와 교차시켜 해당 벽·바닥·천장 텍스처를 샘플링한다. 전체 실내 메시를 만들지 않고 방의 변주를 줄 수 있다. 구현 선택·검사는 공학 종합안이며 특정 게임의 정확한 구현을 보장하지 않는다.

## 적용 조건과 한계

방은 셰이딩에 의한 환상이다. 실제 충돌·길찾기·그림자·상호작용 가구를 자동으로 제공하지 않는다. 가까운 사선 시점에서 한계가 드러날 수 있다. 내부 진입이 필요하면 실제 기하를 검토한다. 검색 키워드는 일반적인 ‘실내’보다 인테리어매핑·장식창문·비진입창문으로 범위를 좁혔다.

## 적용 전 점검

창문 경계·모서리 시점·반복 방을 비교하고, 진입 공간은 실제 기하로 전환한다. 이 검사는 제안이며 실제 장면에서 실행하지 않았다.

## interior mapping의 적용과 확인

인테리어 매핑에서는 방 로컬 좌표계의 시선과 상자의 교차점으로 외벽 뒤에 보일 면을 정한다. 시선이 창에 비스듬하거나 카메라가 가까울 때 시차 오차와 실제 형상 부재가 드러나는지 확인한다.

검색어 · interior mapping, ray-box intersection

[Joost van Dongen, Interior Mapping](https://www.proun-game.com/Oogst3D/CODING/InteriorMapping/InteriorMapping.pdf)은 용어와 적용 조건의 근거다. 제안한 검사는 대상 환경에서 수행한다.

## 실제 언리얼 검증

상태: 활성 참고 지식. 실제 확인일 2026-11-12. 엔진 공통 원리이며 API와 비용은 엔진 버전에 따라 다르다.

### 지침

입장할 수 없는 창문 뒤에 상자형 실내 깊이와 시차를 표현할 때 사용한다. 카메라와 시선 광선을 방 로컬 좌표로 변환하고 가상의 상자와 교차시켜 벽·바닥·천장 텍스처를 선택한다. 창문 UV 거울을 먼저 되돌려 실제 표면점을 복원하고 교차 후 텍스처 거울을 적용한다. 구현 순서와 검사는 자체 공학적 판단이며 원본 게임 구현을 보장하지 않는다.

### 적용 조건과 예외

실내는 셰이딩 착시다. 충돌·길찾기·그림자·상호작용 가구가 자동으로 생기지 않는다. 근접하거나 비스듬한 시점에서 한계가 드러날 수 있다. 시차가 불필요하면 평면 텍스처, 실제 입장·물리·가구·근접 상호작용이 필요하면 실제 공간을 구성한다. 양수 비균일 크기와 UV 거울은 음수 형상 크기와 구분한다.

### 검사

UE5.8.3 Win64 Development/DX11 부분 검증: 정책/아틀라스/시간/메시 메타데이터 48개, 증거 검사 50개, 실제 창문 관측 576개 / GPU 표본쌍 14,400개, 표현별 패키지 성능 3회다. **최종 실제 30·60·144FPS 목표 구간은 충족하지 못했으며 미확인이다. 전체 AI 검증은 미완료다.** 시간 입력 검사나 정상 속도 영상이 실제 FPS를 증명하지 않는다. 최신 범위는 18개 부분 구현 / 25개 직접 구현 없음이다.

입력 규약은 유한 UV [0,1], 거울 0/1, 크기 1..10000cm, 카메라 성분 절댓값 ≤1e7, 로컬 Z>1e-4다. 정규화 방향 Dz≥-1e-6은 거부하고 축 절댓값 ≤1e-6은 제외한다. 동률은 X/Y/Z 순서다. 무효 CPU 입력은 출력을 보존하고 GPU는 유한 검정색을 반환한다. 자체 경계이며 상용 게임 수치나 대규모 좌표 정밀도 보장이 아니다.

창문 4개는 180×140cm, 깊이 100/160/220/280cm다. 320×64 아틀라스의 실제 20,480텍셀을 독립 대조했다. 선형 BGRA8/최근접/클램프/LOD0/밉 없음/비압축, 단면 Opaque/Unlit이다. 창문은 2삼각형/1섹션, 실제 5면 방은 10삼각형/5섹션, 공유 외벽은 21사각형/42삼각형이다. 실제 방 기준도 충돌 없는 표현이므로 입장·물리·내비게이션 검증으로 보지 않는다.

정상 시점/변환/거울/깊이 12상황과 오류/무효/합성 임계값 6대조군을 이동 중·정지 후 확인했다. .01/.99 경계가 포함된 5×5 표본을 실제 픽셀 중심 광선으로 독립 계산한다. 반올림 후 외벽인 161표본쌍도 분류했으며 최대 RGB 오차 .006832682로 기존 .008 한계를 유지했다. 실제 정점·UV·앞면 순서·섹션·변환·재질·아틀라스·가시성·캡처 목록을 함께 확인한다. 수치 HDR 선형 읽기와 톤매핑 스크린샷은 구분한다. 합성 GPU 카메라는 임계값 입출력 검사이며 실제 시점이나 GPU 명령 계수 측정이 아니다.

재사용할 검사: 실제 기록 카메라 축과 정당화된 엔진 회전 허용오차를 사용한다. 점 텍셀 경계에서는 DX11 1/256픽셀 정점 스냅과 원근 UV 보간을 각 표현별로 확인한다. 픽셀과 종료코드가 정상이어도 런타임 ensure를 거부하고 소유 메시 UV 밀도 메타데이터를 초기화한다. 초기 검정/동일 캡처는 검산이 거부했고 캡처별 목록으로 수정했다. 독립 검토 1회에서 발견한 경계/임계값 누락도 실패 재현 후 보완했다. 최종 실행은 모두 수정된 v2이며 이전 높은 FPS를 옮기지 않는다.

1280×720/정적 창문 4개/준비2초/측정8초의 3회 전체 wall p95 범위는 평면 10.406–10.745ms, 매핑 10.517–10.890ms, 실제 방 10.493–10.562ms다. 측정 중 캡처·읽기·메시 생성·변환·재질 갱신과 최종 저장/종료를 제외하고 HUD/숫자 배열은 포함했다. 전체 wall/간격과 지연된 전체 GPU는 셰이더 단독 비용이 아니다. 범위가 겹치고 실제 방도 5섹션의 비최적화 기준이므로 보편적 향상이나 도시 예산을 주장하지 않는다. 이동 카메라 갱신 비용은 분리하지 않았다.

조명·유리·반사·가구·밉/필터·곡면벽·음수 형상 크기·임의 건물 모서리·스트리밍·큰 화면 점유율은 별도 검증한다. 실제 자산·시점·수명주기·프레임 꼬리 비용을 다시 확인한다. 렌더러/도구 개선이나 커밋/푸시는 수행하지 않았다.
