# 개별 보상 조정 전에 게임 자원 흐름 모델링

사람 전용 번역. AI는 영문 K-GAME-ECONOMY.md를 사용한다.

ID: K-GAME-ECONOMY. 유형: 참고 자료. 상태: 사용 가능. 근거 확인일: 2026-11-07.

요약: 자원 기반 게임은 정한 플레이 기간 동안 생성·보관·이전·전환·소멸을 추적한다. 플레이어 행동 전략·상한·되먹임을 비교한 뒤 스프레드시트나 단일 보상률을 균형의 근거로 해석한다.

적용 범위: 게임 안의 자원·RPG 성장·전략·경영·거래 시스템. 시나리오 모델이며 실제 금융 조언이나 수익화 의무가 아니다.

검색어: economy, sources, sinks, resource-flow, feedback-loop, simulation, currency, inflation, 게임경제, 보상, 재화, 수급, 소모처, 성장, 밸런스

## 활용 지침

출처 관찰: Dormans는 상호작용하는 자원 흐름·되먹임을 모델링하고 단순화한 전략 게임을 정해진 행동 전략으로 시험한다 [S1]. Schreiber는 자원의 생성·소멸·교환과 개방 경제의 다른 조건을 설명한다 [S2]. Unity는 F2P 중심 안내에서 성장에 관련된 자원을 획득·소비 활동에 연결한다 [S3].

응용 방법: 자원과 계산 경계를 정의한다. 생성·소모마다 양·속도·발생 조건·상한·수령자·전제 조건을 기록한다. 이전은 생성·소멸과 구별한다. 이용자 거래 자체로 전체 경제의 재화가 없어지는 것은 아니다. 기말 보유량 = 기초 보유량 + 생성 + 유입 이전 - 소모 - 유출 이전으로 시작한다.

필요한 초심자·효율적 이용자·복귀자·상한 도달자의 전략과 기간을 비교한다. 시간·보상 변경을 성장·구매 선택·희소 입력·콘텐츠 수요로 추적한다. 모델 전제를 표시하고 허용된 플레이테스트·운영 관측과 예측을 대조한 뒤 조정을 확정한다.

## 적용 조건과 예외

계산 경계는 이용자·진영·서버·한 회차일 수 있고 이에 따라 결론이 다르다. 모델에 넣지 않은 정보·조작 숙련·사회 행동은 반영되지 않는다. 싱글플레이와 지속적인 이용자 거래 경제는 목표가 다르다. 성장·고갈 단계에서 생성과 소멸의 일치가 항상 바람직한 것은 아니다. F2P 사례를 다른 게임의 유료 재화·에너지 제한·유료 가속 의무로 삼지 않는다.

## 확인 항목

제안 점검: 단위와 합계를 맞추고 다른 행동 전략에서 상한·순환을 시험한다. 무한 축적·자원 부족·지배적 전환을 찾는다. 민감도·누락 행동을 밝힌다. 시뮬레이션 결과는 해당 모델과 전략의 결과이며 모든 이용자나 안정된 시장의 증거가 아니다.
