# 볼류메트릭 연기·구름과 게임 판정 분리

기준 항목: K-GAME-TECH-VOLUME · 확인일: 2026-11-07 · 참고 지식. 엔진 실행·성능·실제 플레이 검증은 별도다.

## 원리와 구현 요점

밀도장과 산란·소광으로 연기·구름을 표현하고 노이즈로 형상을 만든다. 저해상도 계산과 시간축 복원은 품질·성능 절충이다. 경쟁 게임의 연막은 클라이언트 최종 이미지에 맡기지 말고 권한 있는 밀도·가시성 규칙을 공유한다.

### 추가 조사로 보완한 구현

밸브의 2023년 CS2 패치 노트는 벽 근처 연기 부피 확장, AMD에서의 스텝 함수 조정, 산탄총이 만드는 구멍을 명시한다. 공간 부피 연막 동작은 확인되지만 전체 솔버가 공개된 것은 아니다. 구현 종합안은 권한 있는 연막 점유·일시적 총탄/수류탄 변형과 시점별 조명을 분리하고 공유 상태를 플랫폼에 맞게 샘플링하는 방식이다. 지오메트리 교차·복원 품질이 게임 가시성을 바꾸지 않도록 확인한다.

## 적용 조건과 한계

밸브의 해당 패치에서 부피 연막 동작을 확인했지만 전체 밀도 솔버·동기화·레이마칭 코드는 공개되지 않았다. 부피 표현과 유체 시뮬레이션은 다르며 경쟁 가시성은 대상 게임에서 검증한다.

## 적용 전 점검

적용 전 점검: 움직이는 조명·카메라 컷·연기 내부·깊이 경계와 품질별 가시성 일치를 확인한다.

## Volumetric Fog의 적용과 확인

언리얼 Volumetric Fog는 시간 재투영으로 여러 프레임의 안개 샘플을 재사용한다. 빠르게 움직이거나 켜지는 광원은 잔상을 남길 수 있다. 정지·이동 광원을 비교하고 광원의 `Volumetric Scattering Intensity`를 바꿔 안개 기여도와 불투명 표면 조명을 구분한다.

검색어 · Volumetric Fog, temporal reprojection, Volumetric Scattering Intensity

[Epic, Volumetric Fog](https://dev.epicgames.com/documentation/en-us/unreal-engine/volumetric-fog-in-unreal-engine)은 용어와 적용 조건의 근거다. 제안한 검사는 대상 환경에서 수행한다.

### 구현과 동작

기본 Exponential Height Fog 하나·움직일 수 있는 스포트라이트 하나·미리 만든 불투명 Unlit 상자11개를 사용했다. 낮음은 격자 픽셀16/Z64,높음은8/Z128이다. 그림자 품질5·최대 해상도1024·기본 그림자·AA끔 등 나머지는 같다. 격자 설정이며 실제 GPU메모리 할당량을 측정한 것은 아니다. 끔은 같은 요청을 처리하면서 안개 전체 표시와 볼류메트릭 안개를 해제한다. 기존62애셋·프로젝트·설정 파일·의존성·렌더러·공통 도구는 바꾸지 않았다.

24초에2초씩12단계로 밀도0→.012→.05,광산란g=.7,볼류메트릭 그림자 끔/켬,카메라 횡이동·컷,광원 끔/켬,안개 중단·재활성화를 실행했다. 소광 배율10·높이 감쇠.2·높이200cm·평가 거리5000cm다. 광원 위치(0,1500,260),세기500000,내부/외부 각도20/35도다. 정책 범위 밀도[0,.05]·g[-.9,.9]·소광[0,10]의 잘못된 값/비유한 입력은 원자적으로 거부한다. 원시 엔진 setter가 이를 보장한다는 뜻은 아니다. 실제 렌더링 값은 밀도0/.012/.05,g0/.7,소광10이다.

실제 PIE/패키지6월드·비용9회·영상4회에서 같은 단계 요청을 확인했다. 상태 플래그 외에 실제 화면·뷰·몸체 위치와 거리 표식의 선/AABB 첫 교차를 독립 검사했다. 가림 비교에서는 차폐벽의 투영 사각형과4픽셀 여유를 제외하고,벽 안쪽만 달라지는 음성 변형을 거부했다. 표식은x±400,y-300/200/700/1200,z220에 둬 서로 가리지 않는다. 카메라 컷은 실제 FSceneView 플래그를 요구하고,끔 영상에서 투영 위치의 실제 흰/검정 픽셀을 확인했다. 종료 뒤 런타임 CVar9개 값 복원을 실제 PIE에서 검사했다. 우선순위 플래그와 서로 다른 여러 월드의 동시 사용은 인증하지 않았다.

### 광원 잔상·카메라 이동과 컷

### 초기 문제와 실제 영상

안개를 숨긴 초기 스텁은 네이티브 상태 검사에는 통과했으나 실제 화면 변화.1046/255로 거부됐다. 표시한 기본 소광1에서도 변화.6043/255로 약했고,기존 거리 표식은 가까운 상자가 먼 표식을 가리는 문제가 있었다. 선/AABB검사를 먼저 실패시킨 뒤x±400으로 분리하고 소광10을 적용했다. 두 장면 보완을 함께 했으므로 화면 차이를 소광만의 통제 실험 결과라고 주장하지 않는다. 초기 실행과 소스는 보존하고 최종 비용에서 제외했다. 엔진 결함·렌더러 최적화는 아니다.

끔/낮음/높음 각24초,총72초·2160프레임의 정상1배속이다. 추가 높음/히스토리끔24초는 별도다. 원본/디코딩 마커·화면 조건·이어 붙인 디코딩 프레임 해시를 확인했다. 속도 변경·합성 화면은 없다.

### 적용 조건

환경 안개와 빛의 표현에 적용한다. 벽은 빛의 기여를 가릴 뿐 전역 안개 밀도를 없애거나 게임플레이 시야를 보장하지 않는다. 빠르게 변하는 광원은 측정된 잔상을 감안해 시각 품질을 별도로 판단한다. 이번에는 기본 필터를 유지하고 최적화하지 않았다.

광원 하나·불투명 Unlit기하·한 장비·24초의 한정된 결과다. 투명 재질·대규모 야외·임의 광원 수·하드웨어 일반 예산·완벽한 경계 품질은 미검증이다. ViewDistance를 딱 잘리는 게임플레이 범위로 검증한 것도 아니다. 구름·유체·게임플레이 연막·네트워크·렌더러·공통 도구 개선으로 확대하지 않았다.

정책54개·기능8개·전체Python778개와 기존파괴27·핵심PIE/패키지각73개가 통과했다. 기존manifest소스35개+이전폴더1개/36폴더·8434파일·애셋62개를 보존했다. 최신30개 부분 구현·13개 전용 구현 없음이다. V27구름·V10게임플레이 연막·V54비밀번호는 여전히 미구현이다. 커밋·푸시하지 않았다.
