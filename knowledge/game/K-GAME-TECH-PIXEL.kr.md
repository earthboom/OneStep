# 픽셀 아트와 팔레트 저장

기준 항목: K-GAME-TECH-PIXEL · 확인일: 2026-11-07 · 상태: 참고 지식. 실제 엔진 구현·성능·플레이테스트는 수행하지 않았다.

## 원리와 구현 요점

실제 표시 배율에서 픽셀 덩어리·윤곽 리듬·팔레트·선택적 안티앨리어싱을 조정한다. 인덱스 색상은 팔레트 번호를 저장하며 이론상 n색에 ceil(log2(n)) 비트가 필요하지만 파일 규격 제약이 있다. 디더링은 공간 패턴으로 중간 명암을 표현한다.

구현 선택과 점검은 출처를 바탕으로 한 실무적 종합이며 특정 게임의 정확한 구현을 보증하지 않는다.

## 적용 조건과 한계

작화 관례는 스타일 선택이며 절대 금지 규칙이 아니다. 파일 크기·CPU 디코딩 메모리·GPU 텍스처 형식은 다르다. 특정 SNES 스프라이트 저장 구조를 입증하지 않는다.

## 적용 전 점검

적용 전 점검: 정수·비정수 배율·필터·팔레트 교체를 비교하고 PNG 크기 대신 런타임 텍스처 메모리를 측정한다.
