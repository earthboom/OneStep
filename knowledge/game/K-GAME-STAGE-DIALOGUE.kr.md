# 스테이지 대화 상태와 2D 연출을 재사용한다

## 지침

대사는 안정적인 ID와 화자, 원문, 번역 문맥, 초상·표정·음성 키를 갖는다. 짧은 단문은 표를, 선택과 분기는 그래프나 스크립트를, 재방문 대사는 조건과 우선순위를 활용한다. 스테이지는 대화 가능 여부, 반복 정책과 중단을 결정한다. 대화 실행기는 임시 상태를 관리하고 퀘스트·보상·진행 소유자가 합의된 시점에서 명령을 검증하고 확정한다.

플레이어가 계속 보고 조작해야 하는 범위에 따라 조작을 멈추는 대화, 월드 안 신호, 선택 상호작용을 고른다. 시작 조건, 낮은 우선순위 대화의 중단, 종료 조건, 사망·취소·퇴장·로드 뒤 재개 또는 재시작 여부를 정한다. 연출을 건너뛸 때도 합의된 결과 확정 정책을 따른다.

## 적용 범위와 예외

고유한 형태와 실루엣이 중요하면 프레임별 그림을, 동작과 외형을 반복해서 쓸 때는 리그를, 여러 방향의 일관성이 필요하면 3D 렌더링을 고려한다. 편집 원본, 내보내기 버전과 안정적인 클립 이름을 관리한다. 아틀라스 좌표는 파생 값이다. 다시 가져와도 포즈 지속 시간, 트리밍 오프셋, 발과 말풍선 앵커를 유지한다. 클립 이벤트가 규칙을 실행한다면 소유자, 타이밍, 취소와 반복 동작을 정한다.

## 확인

다시 가져온 뒤 루프 지속 시간, 비대칭 부분의 반전, 피벗, 텍스처 번짐과 실제 크기를 비교한다. 스테이지에서 첫 대사, 선택, 취소, 재시작과 재진입을 실행한다. 미리보기나 중단 후 재개에서 보상이 중복되지 않는지 확인한다. 실제 장면에서 긴 번역, 음성·글리프 누락, 자막 시간, 입력 초점과 신호 가독성을 확인한다. [스테이지 식별](K-GAME-STAGE-COMPATIBILITY.kr.md) · [회귀 검증 범위](K-GAME-REGRESSION-SCOPE.kr.md)
