# 코드 지식

제외된 로컬 산출물을 가리키는 등록 출처 링크는 과거 증거를 보존할 뿐이다. 저장소 파일, 현재 접근 가능 여부, 새 실행 확인을 보장하지 않는다.

소프트웨어 구현, 시스템, 런타임 동작, 검증.

Unreal Editor 플레이를 실제로 검증할 때는 [네이티브 PIE 자동화](K-CODE-UE-PIE-VERIFICATION.md)를 본다. 이 문서는 실제 플레이 월드와 standalone Game 실행을 구분하고, 렌더링과 완료 증거를 빌드된 모듈에 연결한다.

코딩 철학, 설계, 리팩터링 질문은 [원칙 검색](K-CODE-PRINCIPLE-REUSE.md)에서 시작한다. 실제 유지보수, 의존성, 설정, 수명, 성능 결정에 맞춰 고르고, 언어와 런타임 및 프로젝트 제약을 유지한다. 이 참고 자료는 범용 스타일 점수가 아니다.
