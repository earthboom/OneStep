# 코드 지식

> 영어 원문 [index.md](index.md)의 번역이다. 표는 영어 메타데이터에서 생성되며, 키워드는 검색어라 원문 그대로 둔다.

제외된 로컬 산출물을 가리키는 등록 출처 링크는 과거 근거만 보존한다. 저장소 파일, 현재 접근, 새 실행 점검을 약속하지 않는다.

소프트웨어 구현, 시스템, 런타임 동작, 검증.

실제 Unreal Editor 플레이 검증은 [네이티브 PIE 자동화](K-CODE-UE-PIE-VERIFICATION.md)가 실제 플레이 월드를 단독 Game 실행과 구분하고, 렌더링과 완료 근거를 빌드된 모듈에 묶는다.

코딩 철학, 설계, 리팩터링 질문은 [원칙 조회](K-CODE-PRINCIPLE-REUSE.md)부터 시작한다. 실제 유지보수, 의존성, 설정, 수명, 성능 결정에 맞춰 고르고, 언어와 런타임, 프로젝트 제약을 지킨다. 이 참고 자료들은 보편적인 스타일 점수가 아니다.
