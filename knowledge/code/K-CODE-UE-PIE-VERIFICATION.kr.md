## 사용 지침

설치된 UnrealEd의 AutomationEditorCommon 헤더와 구현을 확인한다. 이번 버전의 FEditorLoadMap·FStartPIECommand(false)·FEndPlayMapCommand는 맵 로드·실제 플레이 요청·종료를 수행한다. 요청이 큐에 들어간 것만으로 통과시키지 않고 실제 플레이 월드와 개체의 완료를 기다린다.

UnrealEd 의존성은 Editor 빌드에만 추가하고 테스트도 Editor/Automation 조건으로 보호한다. 렌더 검증에 NullRHI를 사용하지 않는다. 독립 실행 -game은 일반 Game 월드이며 PIE를 대신하지 못한다.

실제 WorldType=PIE, 요청한 모드, 런타임 검사, 크기가 있는 렌더 뷰포트와 상황 완료를 독립적으로 검사한다. Editor DLL·프로젝트·설정·소스 지문을 빌드와 비교한다. 종료0만 믿지 않고 실패·누락·오래된·미완료 결과를 거부한다. 캡처 세션을 재사용하지 않으며 고정 시간 영상 캡처와 성능 측정은 별도로 한다.

## 전체 입력 소유형 비동기 저장 — 2026-11-11

[실제 결과](../../prototypes/UnrealTechniqueLab/ASYNC-SAVE-RESULTS.kr.md)는 같은 소유형 입력·표준 직렬화기를 사용하는 동기/비동기3쌍을 비교한다. 작업자는 메타데이터·현재/과거 경로·원장·커버리지·형식화된 프레임까지 독립적으로 소유하며 Actor/월드/공유 JSON을 읽지 않는다. 이전 단계의 동기 저장 설명은 역사적 결과이고 새 경로만 별도 검증했다. 게임 스레드 제출·완료 처리, 작업자 변환/쓰기/해제, 전체 완료 시간, 추가 프레임·종료 대기, 대기열·OS메모리 최고치를 구분한다. 비용을 측정 창 밖으로 옮긴 것만으로 전체 개선이라 하지 않는다.
