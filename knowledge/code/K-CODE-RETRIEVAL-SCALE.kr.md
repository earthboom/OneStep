# Markdown 색인 확장 시 한국어 검색 품질과 호출자 응답 시간 검증하기

질문과 오답 후보를 고정해 결과 순서와 외부 수정 반영을 확인하고, 호출자가 응답을 해석할 때까지 시간을 잰다. 회차별 백분위와 개별 응답 제한은 판정이 달라질 수 있다.

ID `K-CODE-RETRIEVAL-SCALE` · 방법 · 활성 · 근거 확인 2026-11-23

적용 범위 — OneStep Markdown 검색, SQLite 색인 및 색인을 미리 만든 순차 클라이언트 세션

## 지침

말뭉치 해시, 질문 순서, 필수·금지 ID, 표시 한도와 빈 결과 조건을 고정한다. 동일 필터에서 표시된 ID와 순서를 함께 비교한다. 바꿔 말한 질문, 정확한 기술명, 사건 ID, 비슷한 증상이나 원인이 다른 질문을 포함한다. 한국어 질의를 확장할 때는 의미 있는 개념 조합을 요구하고, 쿼리가 실제 활성화한 용어와 규칙이 꺼져야 하는 인접 사례를 확인한다. ## 적용 범위와 예외

빈 색인 구축, 준비된 색인을 쓰는 새 프로세스, 외부 편집 후 검색, 유지 중인 세션을 따로 잰다. 파일 이름 열거 비용은 파일 수에 따라 늘어난다. 광범위한 질문은 말뭉치 대부분과 일치해도 준비된 색인으로 후보 선택 비용을 줄일 수 있다. 실제 바꿔 말하기 실패가 계속되면 같은 양성 사례와 음성 사례에서 한국어 분석기 또는 혼합 검색을 비교한다. 합성어 분해와 품사 필터에서 중요한 글자가 사라질 수 있다. ## 확인 방법

호출자의 단조 시계를 쓴다. 매 세션 첫 질문은 프로세스 실행 직전, 다음 질문부터는 인코딩 직전에 시작하고 응답 전체를 읽어 해석한 직후 멈춘다. 한 회차 50건의 최근접 순위 P95는 오름차순 48번째다. 개별 제한은 반올림하지 않은 각 시간에 경계값을 포함해 판정한다. 원문 재독 횟수와 결과 순서를 확인하고, 색인 구축과 출처 검증 시간은 따로 잰다. 질의 사이에 파일 한 건을 추가·수정·삭제해 바뀐 파일만 다시 읽고 삭제된 결과가 사라지는지 점검한다.

## 근거

2026-11-23 실험은 실제 172건에 12개 주제의 반복 자료 29,828건을 더했다. 한국어 변형 질문 9개에서 상위 셋 안에 든 정답이 3개에서 9개가 됐고 1위는 8개였다. 준비한 색인에 새 프로세스로 같은 질문 50개를 보냈을 때 같은 환경 JSON 대조군 P95는 3.213초, SQLite 두 회차는 0.527초와 0.448초였다. 표시 순서는 동일했다. 나중에 기계 조건이 달라진 새 프로세스 P95는 1.997초와 2.405초였다. 준비된 색인의 세션 다섯 회차 모두 P95 2초 이내였지만 개별 통과는 243/250이었다. 후보가 29,846개인 질문에서 본문 발췌 전에 순위를 계산하자 별도 추적의 순위 단계가 747ms에서 130ms가 됐다. 이후 다섯 회차는 같은 결과 순서에서 250/250 통과, 최대 1.282초였다. 반복 자료, OS 캐시, 직렬 요청이라는 조건 때문에 실제 사건의 다양성·동시 부하·다른 기계로 일반화하기 어렵다.
