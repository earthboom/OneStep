# 양방향·서로 다른 반경 실험 — 2026-11-08

기존/동적 실험을 보존하는 별도 TrafficLab을 구현한다. 목표는 밀집 교행의 충돌·진전·전체 프레임 근거를 PATH/CROWD에 연결하는 것이다. 상용 통합·보편적인 군중 솔버는 아니다.

128×40 정적 환경에 폭1의 좁은 통로와 y23/25/27/29의 넓은 차선4개를 둔다. 반경 .20/.35/.60, 여유 .04, 속도3, 고정1/60틱이다. 반경별 양쪽 출구의 거친 역방향 장이 호환 통로를 고르고 작성한 상하좌우 경유점이 실제 이동을 정한다. 거친 비용1/2는 선호도이며 기하 최단 거리가 아니다. 큰 원판은 좁은 통로를 거부한다. 반경은 생성 시 고정이다.

좁은 곳은 방향별 FIFO·방향 임대·기존 진입 완전 배출·반대 대기 시 단계별 신규4개 제한을 쓴다. 방향 간 전역 FIFO와는 다르다. 입구 대기 줄을 출구에서 분리하고 전신이 벗어나야 임대를 반환한다. 넓은 차선은 최대 체격에도 간격이 남는다. 반경 합으로 쓸린 이동과 팽창 벽을 검사한다. 공간 해시는 r≤.60·속도3·dt≤1/30이 전제다. ORCA·CBS·완전 MAPF 구현이 아니다.

폭/반경 경계·이동 중 겹침·도착 구간·좁은 교대·넓은 동시 교행·64/128/256혼합 완주·역순/지연 요청·진입 중단/재개를 검증한다. 진입 제어만 끈 비교군은 충돌 없는 교착, 충돌 방어도 끈 비교군은 겹침을 보여야 한다. 매 틱 독립 감사와 표시 프레임별 실제 반경 Unity 벽 검사를 한다. 개체 초기화/순간이동으로 통과시키지 않는다.

안전 상황은 쌍/벽 침투·순간이동·임대 오류·금지 통로·전역5초 정지가 없어야 한다. 쌍120초,64/128개180초,256개300초 내 양쪽 모두 도착해야 한다. 의도적 진입 중단은 외부 차단으로 표시하고 완주 제한은 유지한다. 동작 재생8틱/화면과 성능60Hz 실시간 누적기를 구분한다.

성능은64/128/256활성 개체·균일/혼합 반경·동일 장면·창·표현,1초 준비/6초 측정,순차 release3회다. 전체 벽시계 프레임·틱 포함 제어·현재 인원/표시·CPU/render/GPU·누락·실행 순서·해시를 남긴다. 목표는 전체 p95 16.67ms이며 초과를 버리지 않는다. GPU 누락을0비용으로 보지 않는다.

임의 형상·곡선·가속·밀기·새 이동 장애물·분산 권한·무한 유입은 범위 밖이다. 진입 중단은 물리 문 폐쇄가 아니며 이전 동적 실험이 별도로 존재한다. 원저 C-space·통로 대칭·고정 경로 협조는 설계 참고이고 자체 제어의 완전성 증명이 아니다.
