# 동적 경로·군중 실험 — 2026-11-08

사용자가 요청한 실험 확장이다. 원래 장면·빌드·과거 측정을 보존하고 별도 DynamicLab에서 이동 중 장애물과 국소 회피를 검사한다. PATH의 공유 목표·무효화와 CROWD의 경로/국소 충돌/렌더 분리를 적용했다. 문제 기록 조회의 소설 관련 결과는 부적합하여 기각했다.

## 설계와 통과 기준

상하좌우 단위 격자와 같은 반경0.20의 원판이 칸 중심 사이를 연속 이동한다. 월드 하나가 그래프·예약·장애물 처리를 소유한다. 현재 칸과 목적 칸을 예약하고 비어 있는 내리막 이웃으로 이동하거나 양보한다. 처리 순서를 순환한다. 오른쪽 출구 영역을 비용0으로 공통 싱크에 연결하되 실제 비인접 이동은 하지 않는다. 두 개의 한 칸 문이 합류 병목이다. 보수적인 협력 셀 예약 방식이며 ORCA·일반 연속 군중의 보장을 가져오지 않는다.

폐쇄 요청은 새 경로에서 즉시 칸을 제외하고 재계산한다. 기존 예약이 있으면 통과·이탈까지 실제 콜라이더 폐쇄를 미룬다. 재개방은 경로·표현을 함께 갱신한다. ID·위치는 보존한다. 즉시 압박 문·연속 장애물 속도·다른 반경·대각·교행·상용 물리 통합은 범위 밖이다.

검사는 실제 문 부피 안에서 요청, 초기화/순간이동 없는 이탈·우회, 전체 경로 차단 뒤 정지/재개, 상자 칸 변경, 64/256개 합류다. 겹침·벽·낡은 필드·잘못된 예약·제한시간 내 미도착을 검사한다. 제한은64개60초·256개120시뮬레이션 초다. 독립 기하 감사와 실제 네이티브 콜라이더 검사를 쓰고 회피를 끈 비교군은 겹침을 검출해야 한다. 가속 동작 재생과 실시간 성능을 나눈다.

성능은64/256/512개, 같은 렌더 설정에서 회피 있음/없음을 비교한다. 준비1초·측정6초를 독립 Windows release Mono3회로 반복한다. 60Hz 누산기와 제한된 따라잡기를 사용하고 남는 시간을 버리지 않는다. 모든 프레임 간격·가능한 엔진 CPU/GPU·제어/갱신·장애물 처리 비용을 기록한다. 목표는 p95 16.67ms 이하다. 미달은 버리지 않고 조건으로 보고한다. 경로를 충분히 길게 만들어 측정 중 활성 인원이 줄거나 재생성되지 않게 한다. 대기·OS부하·비동기GPU·계측 비용을 명시하고 CPU와GPU를 합하지 않는다.

실행 순서는 실패 검사 → 소유/예약/폐쇄 → 엔진 검사 → 별도 장면/빌드 → PlayMode·독립 실행·실제 UI → 원본 분석 → 기존 지식/목록/번역 갱신이다. 상용 통합·의존성 설치·커밋·푸시·무관 파일 정리는 하지 않는다.

## 발견과 수정

최소 구현에서8개 중5개 실패를 확인한 뒤8개를 통과했다. 독립 검토의 상자 반복 이동·일시정지 동기화·도착 구간 누락은 회귀4개 실패로 재현하고12개 통과로 수정했다. 초기 예약 통과 시험의 요청은 실제 몸체 진입보다 빨랐다. 추가 점유 검사가 이를 실패로 검출했고 최종 시점은 실제 문 안이다. 요청25틱(0.4167초) 뒤 안전하게 닫혔다. 초기38틱 기록은 과거 자료로 보존한다.

배치 에디터와 숨김 실행은 렌더/GPU가0이어서 전체 프레임 측정으로 기각했다. Visible 실행은 실제 렌더링을 확인했다. 그래도 일부 GPU값은 누락되므로0비용으로 처리하지 않는다. 분석의95%GPU가용 가정은 전체 프레임 측정과 GPU꼬리 완전성을 혼동해 철회했다. 원본 간격과16.67ms 목표는 유지하며 GPU꼬리 미검증을 표시한다.

## 최종 엔진 근거

[결과·재현](DYNAMIC-RESULTS.kr.md)에 PlayMode·같은 빌드 독립3회·실제UI를 보관한다. 각각 회귀12개·시나리오 기대6개를 통과했다. 안전 합류64/256개는31.27/101.47시뮬레이션 초에 끝났다. 전체 프레임149,913개를 보존했고 최종 여섯 비교 조합은 세 실행 모두16.67ms p95를 충족했다. 512개 예약 회피 p95는2.87–3.15ms였다.

이전에는 같은 경우24.61–31.24ms였고 Results/Dynamic/pre-body-capture에 보존했다. 성능 최적화나 격리 부하 비교로 그 원인을 입증하지 않았으므로 실제 장면·기기·부하의 조건부 채택이다. GPU는149,913개 중11,887개가 누락되어 꼬리 지연은 미검증이다. 원본은 무손실 압축·왕복 해시를 확인했고 압축 입력 분석이 이전 요약과 바이트 단위로 일치했다.

PATH·CROWD·GUIDE·활용 규약을 갱신했다. 누적 엔진 근거는 제한된 원리4개 항목이며39개는 미검증이다. 목록·검색·문서 검사는 엔진 검사와 구분한다. 사용자 승인이나 상용 통합을 주장하지 않는다.
