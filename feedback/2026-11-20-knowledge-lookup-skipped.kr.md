# 피드백 — 진입 지침에 구체적인 검색 명령이 없을 때 지식 조회가 누락된 사례

- 날짜: 2026-11-20
- 사용한 OneStep 버전: 0d0053a까지의 커밋(2026-11-20). 세션별 정확한 커밋은 알 수 없음
- 관련 지침: skills/vegabond-scout/SKILL.md의 요청 파악과 지식 요청, skills/vegabond-knowledge/SKILL.md의 조회·종합
- 유형: 문제
- 상태: verifying (검증 중)
- 작업 맥락: 한 게임 저장소의 체크아웃 네 곳에서 팀 지침과 OneStep 로컬 지침을 함께 사용한 설계·구현·병합·조사 작업

## 기대와 관찰

실질적인 작업에서는 필요한 지식을 구체적으로 요청하고, 예정된 동작을 기준으로 문제 기록을 검색하도록 했다. 로컬 지침에 Scout와 지식 스킬의 이름만 적힌 환경에서 감사한 세션 8개는 검색 도우미를 호출하거나 지식 경로에 접근한 흔적이 없었다. 세션별 도구 호출은 약 100회에서 2,000회 이상이었으며 대부분 Scout를 읽었다. 로컬 지침에 `--store records`까지 포함한 실제 도우미 명령이 있던 환경에서는 해당 절차를 따른 모든 세션이 명령을 실행하고 참고한 ID를 보고했다.

## 근거와 추정 원인

주 대화의 도구 입력에서 도우미나 저장소 경로를 언급한 횟수를 확인했다. 방법은 knowledge/code/K-CODE-AGENT-INSTRUCTION-AUDIT.md에 있다. Scout의 지식 요약 요청을 선택적인 맥락 수집으로 해석하거나, 작업 프로젝트 문서를 읽은 것만으로 정보 수집을 마쳤다고 여겼을 가능성이 있다. 동일 체크아웃에서 조건을 통제해 원인을 비교한 결과는 없다.

## 개선 제안

Scout의 정보 조회 단계나 연결 프로젝트의 진입 지침에, 예정된 동작으로 문제 기록을 검색하는 실제 명령을 제시한다. 보고에는 참고한 ID와 채택 판단을 담는다. 변경된 지침으로 실질적인 작업을 수행한 뒤 대화 기록의 검색 호출과 보고서의 ID를 대조한다.

## 검토와 검증

2026-11-23에 Scout에 실행 가능한 문제 기록 검색 명령을 추가했다. 기록의 적용 범위를 읽고 검사를 선택하는 예시와, 입력만으로 충분한 띄어쓰기 예시를 함께 넣었다.

수정된 Scout로 서로 독립된 새 실행 맥락 여섯 개에서 기존 [요청 적용 평가](../skills/vegabond-knowledge/tests/information-needs/evaluation.md)를 수행했다. 답변은 [기존 사례별 평가 기준](../skills/vegabond-knowledge/tests/information-needs/rubric.json)을 충족했다. 결제 제공자 교체 사례에서는 R-EVAL-BUSY와 사고 원문을 조회해 기존 제공자의 재시도 규칙 적용을 보류하고, 응답 유실 후 중복 청구 검사를 제안했다. 띄어쓰기 사례에서는 요청한 공백 하나를 고치고 주어진 문장과 대조했다고 보고했다. 나머지 사례는 대기열 콜백, 소설의 정보 공개 시점, 전투 속도, 유지율 주장을 다뤘다.

합성 과제에서 답변에 드러난 판단을 검토한 결과다. 원래 게임 체크아웃에서의 변경 전후 측정과 유지관리자의 수용 여부는 아직 확인되지 않았다.

별도의 일곱 번째 실행에서는 현재 체크아웃을 대상으로 고정 전방 카메라의 검사 계획을 작성했다. 예정된 후진 전환 동작으로 문제 기록을 검색해 R-CODE-UE-SPEED-REVERSE를 열고, 과거 결함에 따라 지연이 적용된 실제 카메라와 캡슐의 위치 관계를 매 프레임 확인하는 검사를 선택했다. 검사의 선택을 확인한 작업이며 언리얼 런타임은 실행하지 않았다.
