# 피드백: 도구 호출을 먼저 하는 하네스에서는 scout의 실행 전 브리프가 나오지 않는다

- 날짜: 2026-11-20
- 사용한 OneStep 버전: 0d0053a(2026-11-20)까지의 커밋. 세션별 정확한 커밋은 알 수 없음
- 관련 스킬과 지침: skills/vegabond-scout/SKILL.md (짧은 작업 브리프 제시)
- 종류: problem
- 상태: received
- 작업 맥락: 한 게임 프로젝트의 Claude Code 데스크톱 세션. 조사 요청. 프로젝트 로컬 지침 파일이 팀 지침 위에 OneStep을 얹은 구성

## 기대와 관찰

기대: scout가 실행 전에 네 항목의 브리프를 대화에 쓴다. 같은 조사 요청으로 새 세션 세 개를 관찰한 결과, 첫 조사 도구 호출 전에 브리프가 없었다. 로컬 문구 두 가지를 시도했고, 그중 하나는 "어떤 종류든 다음 도구 호출 전에"라는 관문이었다. 관문 아래에서 에이전트는 할 일 목록에 "Post work brief" 단계를 추가하고, 글을 쓰지 않은 채 완료로 표시했다. 같은 브리프는 최종 보고서 맨 위에는 안정적으로 나왔다.

## 근거와 추정 원인

assistant 글과 도구 호출 시각으로 대화 기록을 점검했다(방법: knowledge/code/K-CODE-AGENT-INSTRUCTION-AUDIT.md, 사건: records/code/R-CODE-AGENT-BRIEF-ORDER.md). 확인되지 않은 추정 원인: 하네스가 메시지마다 도구 호출을 함께 보내고 호출 사이 설명을 줄이는 방식을 선호하며, 할 일 목록 갱신을 그 단계를 채운 것으로 취급한다. 하네스 지침을 뺀 통제 비교는 하지 않았다.

## 개선 제안

브리프를 최종 보고서 맨 위에 두고 완료 조건마다 결과를 붙이는 방식을 허용하고, 모호함이 작업을 바꿀 때만 실행 전 브리프를 요구한다. 순서를 확실히 강제하는 방법은 도구 단계의 훅뿐이라는 점을 덧붙일 수 있다. 확인: 바꾼 문구로 새 세션을 돌렸을 때 보고서 맨 위 브리프와 조건별 결과가 나온다.

## 검토와 확인

관리자가 처리하면서 채운다.
