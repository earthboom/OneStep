# Generating cute characters for stationery and stickers

2026-11-25 · Research for the OneStep image skill

**Proposed first version.** Extend `vegabond-image` with a stationery and sticker reference guide. For an original mascot, establish one neutral reference with observable identifying features, derive the requested expressions or poses, and inspect the art at its actual size and in its intended layout. Use an existing design reference when the task supplies one. The proposal uses Chiikawa as a product and visual reference and uses an original mascot in the proposed trial. This is a desk study drawing on English, Japanese and Korean material. Image generation, print proofing and platform review remain untested for this workflow.

## What the current skill already covers

The image skill already distinguishes requirements from preferences, assigns roles to references, compares edits to an accepted image, checks dimensions and transparency, and repairs observed defects. Its 2D character guide checks landmarks at game display size. A previous lighthouse-mechanic trial carried the forelock and scarf from one reference into a portrait and a 64×64 sprite, while the key could read as generic gold trim at 1×. That is local evidence for inspecting identifying cues at delivery size. The subject and outputs were game assets. The new guidance should address writable space, repeated layouts, readable expressions, and vendor or platform delivery without duplicating the general checks. When an existing character is named, establish what the request takes from it. For “something like Chiikawa,” the exploratory brief can describe a compact silhouette, sparse face, everyday gestures and a gentle or bittersweet tone. Give an original mascot its own silhouette, identifying marks and behavior. If a request explicitly uses an existing identity, use the supplied design or official model sheet as the identity reference and confirm the available asset rights when the intended use involves publishing, selling or model training.

## Generation methods

| Method | When to try it | Trade-off or evidence limit |
| --- | --- | --- |
| **Text only** | Explore distinct silhouette, personality and rendering directions, or make a standalone image without a design reference. | Cheapest to start. Repeated generations may change proportions or redraw details. Use as the baseline for a series trial. |
| **One reference and one image per variant** | Default proposal for a small set. Use the accepted character image for identity. When needed, add a pose sketch or layout guide with its own role. Edit from the neutral anchor for a new pose or from the accepted variant for a local repair. | Built-in `imagegen` accepts reference images. Inspect landmarks even when the whole result looks close. An overly strong reference can retain the original pose or framing. IP-Adapter demonstrates image conditioning on compatible diffusion models, and Midjourney documents its own version-specific reference controls and detail limits. Those controls belong to their respective tools. [IP-Adapter paper](https://arxiv.org/abs/2308.06721) · [Diffusers documentation](https://huggingface.co/docs/diffusers/en/using-diffusers/ip_adapter) · [Midjourney reference documentation](https://docs.midjourney.com/hc/en-us/articles/36285124473997-Omni-Reference) |
| **Generate a sheet in one pass** | Explore a set’s visual rhythm or compare expressions at a glance. | Each cell still needs QC for cropping, overlaps, resolution, character count and local drift. Assembly from separate accepted images gives exact positions and permits single-image repair. |
| **Spatial control or shared generation** | When pose, angle or layout repeatedly fails and the chosen pipeline supports structural inputs, try a sketch, contour or mask. When many images must share a narrative identity, test a shared-generation route if available. | ControlNet demonstrates spatial conditioning. StoryDiffusion demonstrates shared attention for consistent images, including cartoons. Neither measures print or stationery usability. A small mascot can require a drawn pose guide when a human skeleton does not describe the shape. [ControlNet](https://arxiv.org/abs/2302.05543) · [StoryDiffusion paper](https://arxiv.org/abs/2405.01434) · [Author demos](https://storydiffusion.github.io/) |
| **Subject fine-tuning** | Consider for many repeated commissions after measuring recurring problems with reference editing and confirming access to representative training images. | DreamBooth adapts a generator to a subject. Diffusers documents LoRA as a lower-parameter way to fine-tune a diffusion model, including in DreamBooth workflows. Compare against reference editing on unseen poses and crops. Training adds dataset preparation, environment setup and maintenance. [DreamBooth](https://arxiv.org/abs/2208.12242) · [Diffusers LoRA training](https://huggingface.co/docs/diffusers/training/lora) |

Photographic face embeddings and aggregate image similarity can miss a missing ear notch, a mirrored mark or a changed expression on a sparse face. DreamBench++ evaluates reference-concept preservation and prompt following separately and reports disagreement between embedding scores and human ratings. GenEval motivates checking count and attribute placement individually. Use direct visual checks for these features. [DreamBench++](https://arxiv.org/abs/2406.16855) · [GenEval](https://arxiv.org/abs/2310.11513)

## Proposed production workflow

1. **Choose the deliverable.** Clarify whether the work is one character image, a set of cutouts or a composed product. Record actual display size or print dimensions if known, the requested words and any writing area, and relevant references. A standalone image can go straight to the appropriate visual and file checks.
2. **Establish the character.** For a new series, choose a neutral reference and describe a few stable cues, such as the outer contour, face placement, an asymmetrical mark or a large color block. Record what can vary, such as posture, mouth, gaze, and items introduced for a particular scene. Add a 3/4 or side view if the set needs it. Use screen-relative or anatomical directions explicitly for asymmetry.
3. **Draw distinct reactions.** Describe each image as one situation, one main action and a readable expression. Give identity, pose and layout references distinct roles. Check hands and prop contact, the number of characters and the correct placement of marks. If a local feature drifts, repair that area from an accepted image and check neighboring edges and colors again.
4. **Assemble and inspect the deliverable.** Use a layout tool for exact spacing, supplied text, gutters, dielines or repeat tiles as applicable. Inspect the set together and each export at delivery size against the intended substrate or representative light and dark backgrounds. Check identity, gesture and file requirements separately. Keep the neutral reference and accepted individual artwork when the user needs to extend the series.

| Output | What to inspect |
| --- | --- |
| **Single cutout or digital sticker set** | Check the actual transparency data by decoding the file and inspect light and dark previews for halos, stray pixels, dropped interior details and clipped marks. For chat, check the final pixel size, exact wording, file limits and platform rules. LINE’s static sticker guide lists transparent PNG, up to 370×320 px per sticker, separate main and tab images, and several set sizes. LINE’s terms allow AI labeling, and Kakao’s current operating principles restrict proposals made using generative AI. Check the selected platform at submission time. [PNG standard](https://www.w3.org/TR/png/) · [LINE static stickers](https://creator.line.me/en/guideline/sticker/) · [LINE terms](https://creator.line.me/en/terms/) · [Kakao operating principles](https://emoticonstudio.kakao.com/guideline) |
| **Printed sticker sheet or die-cut sticker** | Obtain the printer template. Verify physical size, effective PPI, color profile, bleed, safety margins and spacing between cut contours. Check that cut paths are closed and supplied in the layer or file the printer wants. Distinguish the printed outline from the cut path. PeterPrint gives a PDF/X example with 3 mm around the sheet and 2 mm per sticker. Sticker Mule’s die-cut specification and StickerYeti’s kiss-cut guide illustrate different requirements. Review an actual-size proof before claiming print readiness. [PeterPrint](https://www.peterprint.be/media/media/aanleverspecificaties/stickervellen-drukken.pdf) · [Sticker Mule](https://www.stickermule.com/ca/faqs/stickermule/what-are-your-artwork-requirements-for-stickers-and-labels) · [StickerYeti](https://www.stickeryeti.ch/media/docs/en_YUG_KissCut_2026.pdf) · [Adobe color management](https://helpx.adobe.com/photoshop/desktop/print/color-profiles-for-print-output.html) |
| **Memo pad, notebook or washi tape** | For a memo pad, place representative handwriting in the writing area and inspect contrast and overlap at size. For a cover, check trim and binding and preserve room for required text. For tape, preview the motif at the actual strip width and repeat the tile at least three times to check seams, direction and awkward gaps. A 15 mm product is one example of the space constraint. [Writable Chiikawa note](https://chiikawamarket.jp/products/4582662954526) · [Sun-Star tape examples](https://www.sun-star-st.jp/campaign/smileplus/item.html) · [Adobe bleed and trim](https://helpx.adobe.com/illustrator/desktop/save-and-export/export-files-to-different-formats/add-printers-marks-and-bleeds.html) |

## Trial before adopting the guidance

Use a genuinely original **library book cart mascot**. Its wide mint trolley body, two visible charcoal wheels in front and 3/4 views, and one coral bookmark tab on the mascot’s left identify it. Use a neutral reference with a face on the trolley body. Explore relief after shelving a book, embarrassment after dropping a card, waving hello, and a quiet thank-you. Deliver one 3/4 view and a 30 mm cutout preview. Place one accepted pose on a 70 mm memo mockup with a writing sample. The dimensions are trial conditions.

Compare the current text-only route with the proposed route. Use the same generator, user brief, target sizes and attempt allowance. In both routes, describe the same fixed landmarks. Change the use of the neutral image in the reference-based route. If inner-cell consistency is a concern, add a drafted one-pass sheet as a third route and record its yield by cell. Use several attempts per pose when estimating rates and record any differences in setup cost. Compare early results before repairs as well as final art. Keep a held-out pose that was not used to prepare the neutral reference.

| Check | Evidence to record |
| --- | --- |
| Same character | Mark contour, two visible wheels in the specified views, tab side and face placement individually. A mirrored or missing tab fails identity even if the piece looks appealing. |
| Intended emotion or action | Show the reduced art without the prompt to a reviewer. Record the first reading and conflicting readings. Ask preference and perceived cuteness separately. |
| Stationery usability | At 30 mm, check the silhouette and interior gaps. On the memo mockup, read the handwriting over the actual background. For a print deliverable, compare to the printer template and proof. |
| File and set quality | Record dimensions, real transparency, visible edge defects and clipping. If text is requested, compare the exact wording. Record first-pass yield, number and type of edits and time to accepted export. |

The smallest implementation candidate is a discovery sentence in `vegabond-image` and one focused reference for stationery and sticker characters. Adopt its defaults once the trial can show where identity, emotional clarity and product usability improve or where the added reference work costs more than it saves.
