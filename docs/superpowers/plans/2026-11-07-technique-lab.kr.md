# 기술 실험실 구현 계획과 결과

승인된 실험 프로토타입을 기존 체크아웃에서 직접 실행한다. 목표는 Unity에서 대표 기술 세 가지의 동작·성능 근거와 조건을 기록하는 것이다. [설계·통과 기준](../../../prototypes/TechniqueLab/README.kr.md).

카메라·네이티브 사격·가중 그래프 커널을 독립 검사·공통 장면 소비자와 분리한다. 에디터에서 컴파일·검사·빌드하고 MonoBehaviour에서 실제 Update·물리와 측정을 실행한다. Unity 6000.0.77f1·C#·기본 렌더러/물리·Windows Mono, 외부 레지스트리 의존성 없음.

## 제약과 검토 초점

새 프로토타입·근거·관련 지식만 바꾸고 기존 작업을 보존한다. 영문 기준·한국어 보조 문서 규칙을 지키며 번역은 읽지 않는다. 프레임 간격·CPU 연산·렌더링·게임 전체 성능을 구분한다. 실제 하드웨어·빌드·원본 표본을 남기고 다른 플랫폼·상용 결과를 보증하지 않는다.

내부 원점·벽 너머 총구, 0비용 순환·방향 비용, 거리·후속 노드 동시 무효화, 요청 FPS와 실측 FPS, 초기화/JIT/설정/로그의 측정 오염을 검토한다.

## 단계

1. 실제 엔진 확인 기록을 만든다. 막히면 해결 전에 실행했다고 주장하지 않는다.
2. 독립 검사·최소 커널로 의미 있는 실패를 실행·보관한다.
3. 세 커널을 구현해 같은 검사를 반복하고 잘못된 비교군을 남긴다.
4. 카메라·조명·장면·측정 소비자를 만들고 PlayMode·Windows 빌드·독립 실행을 반복한다.
5. 이미지·표본을 검사하고 결함 수정·재검사 뒤 실제 조건만 지식에 반영한다.

## 결과

다섯 단계 모두 실행했다. 최종 PlayMode와 순차 Windows Mono 3회에서 각각 검사 27개·실제 시간 응답 3개를 통과했다. 빌드 오류 0개, 현재 C# 해시와 실행 근거 일치. 실제 버튼은 OnGUI 없는 이미지와 별도로 확인했다. 독립 최종 검토에서 명시한 범위 안의 차단 결함은 없었다.

미완성 커널·다른 그래프의 동일 리비전·초기 오류 집계 소실은 실패 후 통과 근거를 남겼다. 타이머 문제는 약 3ms 목표 배치로 보완했으며 모든 표본이 3ms 이상이라는 뜻은 아니다. 공개 그래프 직접 변경·닫히는 문을 통과 중인 개체·네트워크·GPU·플레이 경험은 남은 한계다. [결과·재현](../../../prototypes/TechniqueLab/RESULTS.kr.md)과 기존 지식에 반영한다. 상용 통합·커밋·푸시·배포·유료 에셋/서비스는 범위 밖이다.
