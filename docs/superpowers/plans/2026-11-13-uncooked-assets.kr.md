# Uncooked 에셋 리더 구현 계획

이 번역본은 사람용이며 AI는 영문 계획을 읽습니다. 기존 승인된 인라인 실행을 사용합니다. 이 계획 자체는 위임·커밋·푸시 승인이 아닙니다.

**목표:** 확장 가능한 종류별 분석을 가진 읽기 전용 CLI.
**구조:** UAssetAPI 어댑터 → 구조/속성 투영·클래스 기반 분석 → JSON CLI.
**기술:** .NET 8, UAssetAPI 1.1.0, Python unittest 서브프로세스 검증.
**명세:** [설계](../../designs/uncooked-asset-reader.kr.md).

## 공통 제약과 검토 초점

관련 없는 변경을 보존하고 영문 지침·사람용 한국어 번역을 분리합니다. 프로젝트 위치 설정·원본 에셋 쓰기·의존성 재귀 읽기·cooked·추측한 해석값을 추가하지 않습니다. 이번 요청에는 커밋·푸시가 없습니다.

잘못된 패키지를 성공으로 표시하지 않습니다. 중첩 타입·참조 근거·raw export·네이티브 후행 바이트를 보존합니다. 정확한 선택과 원본 해시·공개 CLI 실패를 확인합니다.
