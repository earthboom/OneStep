# OneStep development glossary (pilot)

These entries apply to OneStep's own development and tests. The linked owner defines the behavior. Revisit an entry when that contract changes.

| Term and scope | Meaning at the test boundary | Why it matters here |
| --- | --- | --- |
| Individual search response time (개별 검색 응답 시간), warm-index session benchmark | Time one request at the caller. Charge launching the fresh interpreter to the first request of each round. For later requests, start before encoding the question. Stop after the client receives and decodes the complete JSON reply. Separate initial index construction from this warm-index workload. | The helper's P95 and the caller's P95 diverged in actual measurements. An early timer stop can hide an overrun during startup, transfer or decoding. [Measurement history](../knowledge/code/K-CODE-RETRIEVAL-SCALE.md) · [Session timer](../skills/vegabond-knowledge/tests/benchmark_scale.py) |
| Two-second target (2초 이내), reported across five rounds of 50 individual queries | The historical P95 target uses the 48th fastest of 50 in **each** round. The subsequent **every-response** target compares every unrounded caller duration with 2 seconds, inclusively. One overrun fails that target. Name the requested target when reporting. | The earlier run passed P95 in all five rounds while seven of 250 responses exceeded two seconds. The later request tightened the contract. [Earlier results](https://github.com/earthboom/OneStep/blob/9f553ba95ec7209a5bf3fcc6ab16b119ebeb8317/docs/research/2026-11-23-search-session-measurements.json) · [Every-response acceptance](https://github.com/earthboom/OneStep/blob/9f553ba95ec7209a5bf3fcc6ab16b119ebeb8317/docs/research/2026-11-23-search-tail-measurements.json) |
| Feedback submitted (피드백 접수·제출), delivery status in development tooling | Follow the inbox owner's delivery definition. The pair for this concern must have arrived in the configured checkout's inbox. A complete pair in the working project can support a prepared handoff. Reviewer acceptance is a separate decision. | The incident recorded feedback lines in session reports while the destination inbox lacked the reports. Test the actual destination with the delivery helper and check partial delivery and retry.
