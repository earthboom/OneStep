# Uncooked 에셋 리더 설계

로컬 개발 에셋을 읽기 전용 CLI로 읽습니다. UAssetAPI 1.1.0 어댑터 하나 위에 작은 클래스 기반 분석을 붙입니다. 패키지 구조·직렬화 속성·참조부터 시작합니다. 에셋 편집기나 런타임 동작 증명 도구가 아닙니다. 이 번역본은 사람용이며 AI는 영문을 읽습니다.

사용자는 바이너리 파서 신규 작성보다 기존 라이브러리 재사용을 선택했습니다. 직접 구현은 버전별 작업을 반복하게 되고 에디터 전용 exporter는 엔진·프로젝트 런타임 의존성을 만듭니다. 엔진 비교는 별도 테스트 경로로 두며 CLI에는 에디터가 필요하지 않습니다. 기존 `K-CODE-UE-ASSET-EXPORT-LAYOUT`, `K-CODE-UE-NATIVE-STRUCT-DECODING`은 불투명 데이터 처리에 참고하며 과거 실험과의 호환성을 주장하지 않습니다.

## 관찰 가능한 동작

- `dotnet run --project tools/unreal-assets/src -- file.uasset --engine 5.7`은 본문을 해석하지 않고 구조 JSON을 출력합니다.
- `--properties`는 속성을 해석하고 `--object NAME_OR_PATH`는 해석 전에 export를 선택합니다. `--property NAME`은 해석 후 최상위 이름으로 거릅니다.
- 버전·파일 해시·객체 인덱스/경로/클래스·import 목록·소프트 패키지 참조·한계를 함께 제공합니다. 직렬화 타입이 참조라고 식별한 정수만 객체 참조로 해석합니다.
- 클래스 식별자로 블루프린트·애니메이션·몽타주·데이터·위젯·generic을 결정합니다. 동작이나 외형을 재구성하지 않고 관찰된 구조와 관련 속성을 보고합니다.
- raw·미지원 export와 후행 데이터가 남으면 partial/1, 잘못된 입력·실패한 요청은 error/2입니다. 종료 0은 요청 범위 완료이며 모든 바이트·게임 동작의 이해가 아닙니다.

## 경계

`.uasset`만 받습니다. cooked·에디터 데이터 제거·매핑이 필요한 unversioned·알 수 없는 엔진·손상 입력·충돌하는 선택을 거부합니다. 의존성 순회·원본 수정·에디터 실행·캐시·임의 출력 파일 지정은 CLI에 넣지 않습니다. 표준 출력을 사용하며 안전한 리다이렉션은 호출자가 담당합니다. 원본 하나를 읽기 전용으로 복사하고 경로 없는 메모리 reader를 넘겨 인접 프로젝트 탐색을 막습니다. 분리 export/bulk는 범위 밖이며 빈 성공으로 표시하지 않습니다.

백엔드는 `SkipPreloadDependencyLoading`, `SkipParsingBytecode`, 최초 `SkipLoadingExports`를 사용합니다. 선택한 export는 같은 메모리 패키지에서 읽습니다. 입력 크기·export 영역을 확인하고 실제 읽기·이동도 경계로 제한합니다. 네이티브 extras 개수와 타입 정보가 있는 속성 JSON을 보존하며 외부 JSON 타입 이름으로 객체를 만들지 않습니다. 측정 전 성능을 주장하지 않습니다.

## 검증과 확장

.NET 8 기반에 의존성·잠금을 고정합니다. SHA-256을 확인한 특정 공개 커밋의 UE4.27·UE5.7 블루프린트를 검사합니다. 실제 객체·속성·참조 값, cooked·손상·잘못된 선택·버전·partial·입력 보존·종료 코드를 확인합니다. 합성 family fixture는 분류 검증이며 엔진 형식 정확도의 근거가 아닙니다.

실제 엔진 fixture 프로젝트는 tests 아래에 두어 실행 경로와 분리합니다. 격리 경로에 비기본 애니메이션·몽타주·위젯·데이터를 만들고 두 번째 에디터가 저장 없이 다시 엽니다. CLI 결과를 네이티브 관찰값과 비교하고 해시를 보존합니다. 버전 보완은 작게 유지합니다. 등록된 TextProperty 하위 클래스가 실제 커스텀 버전 조건으로 Base 이력 개발 메모를 읽고, ImportData는 선언된 스크립트 오프셋으로 속성을 찾되 접두부·후행 바이트를 보존합니다. raw 구조체를 해석된 트랙으로 간주하지 않습니다. 그래프 의미·트랙 압축 해제·위젯 렌더링·일반적인 모든 엔진 호환성은 지원 주장의 범위 밖입니다.

구현은 `tools/unreal-assets/`에 백엔드·결과 투영/분석·CLI로 둡니다. 실제 요구가 있을 때만 전문 분석을 추가합니다. 사용하는 프로젝트의 경로·보고서는 해당 작업 공간이 소유합니다.
