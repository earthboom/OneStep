# 문제 기록 검색 설계와 적용 계획

사람용 번역본이며 AI는 읽거나 검색하지 않습니다. 영문 problem-records.md가 기준입니다. vagabond가 대화에서 적용을 승인했으며 실제 형식의 기준은 [저장 절차](../../skills/vegabond-knowledge/references/storage.md)입니다.

## 목표와 방식

작업 전 조건·실패 후 증상으로 사건을 찾고 실행할 점검과 근거의 한계를 전달합니다. 전체 이력 읽기와 수정 완료를 예방 입증으로 오인하는 일을 피합니다. 본문만 강화하면 신호가 숨고 별도 데이터베이스는 기반 시설을 더하므로, 승인된 기존 저장소의 전용 헤더 확장을 사용합니다.

## 계약

공통 헤더·네 본문 구획을 유지합니다. 새·정규화 기록은 trigger(조건 또는 null), symptom(관찰), cause_status(unknown·suspected·confirmed), prevention(점검 또는 null), prevention_status(none·proposed·verified·invalidated)를 추가합니다. 문자열은 비어 있으면 안 됩니다. 지식에는 요구하지 않습니다. 하나라도 있으면 모두 필요하며 모르는 사실은 추정하지 않습니다. none은 null 예방책, 나머지는 행동을 요구하며 verified는 실제 checked_at도 필요합니다. 근거·적용 가능성은 전문 검토가 필요합니다.

모두 없는 이전 구조 기록은 경고하며 읽고 --strict에서는 오류 처리합니다. 원본과 산문 호환성을 보존하고 새 정보는 미기록으로 표시합니다. 새·수정 기록은 확장 형식이 필수지만 도구는 편집 이력을 알 수 없습니다.

색인은 식별, 요약·조건·증상, 범위·맥락, 검색어, 상태·날짜·원인·예방, 상세의 여섯 열입니다. 예방 행동과 상태를 함께 보여 주고 지식 행은 바꾸지 않습니다. 해결 사건도 검색하며 대체 사건의 보관 이력을 남깁니다. 행은 원본에서 생성합니다.

작업 전 조건·실패 후 증상·식별자로 찾고 명확한 비호환은 제외하되 불확실성은 표시합니다. 같은 증상을 같은 원인으로 단정하지 않으며 최신성보다 적용 가능성·근거를 우선합니다. 기존 요약에 ID·경로·관련 이유·점검·예방 상태·예외·공백을 담으며 새 검색 CLI를 만들지는 않습니다.

원인·조건이 뒷받침될 때만 합치고 불확실한 사례는 연결합니다. 재발에 날짜·근거·결과와 기존 점검의 누락·부족·조건 변화 여부를 짧게 남깁니다. 로그 복사 없이 이력을 유지하며 error만 확정 결함이고 제안·가설은 유형을 유지합니다.

## 적용 단계

현재 대화에서 직접 구현하며 적용 지시에 불필요한 승인 단계를 추가하지 않습니다.

- 검색 신호·잘못된 조합·미확인·과거 기록·독립 상태·분야별 검색 테스트를 먼저 추가하고 실패를 확인합니다.
- catalog.py 검사·행을 확장하되 지식 행·원본은 유지하고 전체 테스트를 실행합니다.
- 지식 스킬·저장 참조·번역을 갱신하며 이미 연결된 호출 스킬은 유지합니다. 필요할 때만 README를 보완합니다.
- 색인·변경 번역을 생성하고 엄격 검사합니다. 스킬 형식·영문 참조·번역 쌍·실제 여러 분야 검색을 확인하며 합성 사건은 실제 저장소에 넣지 않습니다.

## 중점 검토와 한계

사건 해결과 예방 검증은 독립적입니다. 미확인 조건·추정 원인은 검색·응답에 남기고 증상을 몰라도 사전 위험을 찾아야 합니다. 비호환 환경의 같은 증상으로 무조건적 수정을 권하지 않습니다. 유지 관리가 원본을 덮어쓰거나 번역을 읽어서는 안 됩니다.

도구는 구조·상태·로컬 파일만 검사합니다. 진단 진실성·예방 효과는 판단 작업까지 포함해 전문 검토 근거로 입증합니다. 구조 테스트 외 실제 검색 요청도 확인하며 설치·새 서비스·전역 저장소는 추가하지 않습니다.

## 적용 결과

구현과 AI 검증을 마쳤으며 vagabond의 검토를 기다립니다. 위 네 적용 단계가 모두 완료되었습니다. 초기 테스트에서 새 검색 필드가 무시되는 동작을 확인한 뒤 수정했고, 별도 검증에서 네 분야의 합성 기록 저장·재검색, 제안·검증·무효 예방 상태, 버전 미확인과 재발 구분을 확인했습니다. 실제 제품 테스트를 수행하거나 실제 프로젝트 사건으로 기록한 것은 아닙니다.

별도 검토에서 보존 색인 메모·루트 경로의 로컬 참조 검사 누락을 발견했습니다. 두 경우의 잘못된 통과를 재현하는 회귀 테스트를 추가하고 기존 링크 검사를 연결했습니다. 최종 전체 자동 테스트 20개가 통과했습니다. 프로젝트 엄격 검사·재생성의 무변경 확인·영문 참조·번역 존재 검사가 통과했으며 번역 내용은 읽지 않았습니다. 커밋·푸시·설치·전역 설정 변경은 하지 않았습니다.
