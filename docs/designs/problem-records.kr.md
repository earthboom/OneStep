# 문제 기록 검색의 설계 결정

상태: 구현된 설계 결정 기록. 이 문서는 선택과 당시 구현 근거를 보존하며, 진행 중인 구현 계획이 아니다. [지식 스킬](../../skills/vegabond-knowledge/SKILL.md)이 조회·기록을, [저장 지침](../../skills/vegabond-knowledge/references/storage.md)이 현행 형식과 CLI 계약을 관리한다. 사용자 수락은 이 문서의 상태가 아니라 명시적인 피드백으로만 성립한다.

## 목표와 대안

작업 전에는 발생 조건으로, 실패 뒤에는 관찰 증상으로 관련 사건을 찾고 근거의 한계가 붙은 예방 점검을 반환하는 것이 목표였다. 본문에만 있던 신호를 기록 전용 헤더 필드로 드러내고 기존 카탈로그 도구를 조금 확장했다. 별도 사건 데이터베이스는 필요성이 입증되지 않은 기반 시설을 추가하므로 기존 저장소와 6열 카탈로그를 유지했다.

## 결정과 이유

- 발생 조건과 증상은 조회 시점이 다르다. 원인 확신도와 예방 상태를 사건 해결 여부와 분리하여 결과물 수정이 예방 입증으로 해석되지 않도록 한다.
- 명시적인 미상 값과 레거시 경고로 공백을 보존한다. 기록 전용 필드는 일반 지식을 가볍게 유지한다. 현행 [기록 필드와 레거시 규칙](../../skills/vegabond-knowledge/references/storage.md#problem-retrieval-fields)은 한 곳에서 관리한다.
- 해결된 사건도 검색하고 대체된 기록의 출처를 보존한다. 같은 증상만으로 원인이 같다고 판단하지 않으며, 호환성 미상 후보를 조용히 제외하지 않는다.
- 재발은 점검 미실행, 점검 불충분, 조건 변화에 따른 무효화로 구분한다. 간결한 근거 링크로 긴 로그의 복제를 피한다.
- 카탈로그 도구는 영어 정본의 메타데이터, 명시적으로 연결된 정본 항목, 프로젝트 내부 출처 등록부의 메타데이터를 읽는다. 그 밖의 보이는 로컬 참조는 파일 존재를 확인한다. 외부 원본과 로컬 루트 설정은 읽지 않고, 상세 정본을 고치거나 사람용 번역을 읽지 않는다. 구조 검사는 진단이나 예방책의 진위를 판단하지 않는다.

## 당시 구현과 근거

검색 신호, 잘못된 필드와 미상 값, 레거시 호환성, 상태의 독립성, 범위별 카탈로그 테스트를 추가했다. 검증과 기록 투영, 스킬·저장 지침과 번역을 갱신하고 관련 카탈로그를 새로 만들었다. 현재 절차는 이 문서의 별도 세션 점검표가 아니라 해당 지침에서 관리한다.

아래는 당시 결과이며 현재 테스트 수나 새 실행 결과가 아니다.

- 기록 신호가 무시되고 카탈로그에 투영되지 않아 처음 실패했고, 구현 후 카탈로그 테스트 19개가 통과했다.
- 독립적인 4개 분야 합성 실험에서 제안·검증·무효화된 예방, 버전 미상 후보와 재발 구분을 확인했다. 정본 상세를 보존하고 엄격한 카탈로그 검사를 통과했다. 실제 제품 실행이나 실제 프로젝트 사건 생성은 수행하지 않았다.
- 독립 검토에서 카탈로그의 보존 안내와 루트 경로 안내 본문에 참조 검사가 적용되지 않은 문제가 드러났다. 두 잘못된 성공을 회귀 검사로 재현하고 기존 참조 검증을 적용하여 테스트 20개가 통과했다. 당시 프로젝트 엄격 검사, 재실행 무변경, 영어 참조와 번역 쌍 존재 확인도 번역을 읽지 않고 통과했다.

현재 테스트는 [test_catalog.py](../../skills/vegabond-knowledge/tests/test_catalog.py)에 있다. 후속 변경과 현재 검증은 역사적 개수가 아니라 현행 테스트와 실제 실행 근거로 판단한다.

## 한계

새 서비스나 전역 저장소, 의존성 설치를 도입하지 않았다. 형식 테스트와 카탈로그 검사는 의미 있는 검색, 원인 판단, 예방을 입증하지 않는다. 전문가는 원본 근거와 적용 조건을 확인해야 한다. 읽기 전용 조회는 과거 기록 수정 권한이 아니며 프로젝트 밖 원본은 허용된 출처 범위에서 별도로 검증한다.
